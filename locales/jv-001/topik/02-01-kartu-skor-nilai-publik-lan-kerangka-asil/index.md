# Topik 2.1 — Kartu Skor Nilai Publik lan Kerangka Asil

**Strategi sing dibangun ing segitiga strategis namung dadi crita bab niyat salawase sawijining organisasi durung gelem ngukur, kanthi terbuka, apa tenan dheweke wis nyiptakake legitimasi, nilai, lan kapasitas — lan Kartu Skor Nilai Publik, model logika, lan akuntabilitas adhedhasar asil iku cara-cara sing disiplin kanggo nggawe komitmen kasebut tetep kuwat.**

## Apa Sebabe Iki Wigati kanggo Nilai Publik

Umume pimpinan sektor publik lan sektor sosial bisa nyusun dokumen strategi sing lancar nyritakake bab asil. Luwih sithik sing bisa nuduhake, setaun salajengipun, bukti apa asil-asil kuwi tenan wis obah. Bedane antarane kekarone biasane dudu amarga kekurangan data — umume organisasi ngumpulake data kanthi jumlah gedhe — nanging amarga kurang struktur sing disiplin kanggo ngowahi cacahan kagiyatan mentah dadi klaim sing bisa dibela bab nilai sing wis tinitahake. Topik 1.2 — Segitiga Strategis: Legitimasi, Nilai, lan Kapasitas njlentrehake legitimasi lan dhukungan, proposisi nilai, lan kapasitas operasional minangka telung suku sing kudu dicukupi bebarengan dening strategi sawijining organisasi (waca Topik 1.2 — Segitiga Strategis: Legitimasi, Nilai, lan Kapasitas). Topik iki mbahas piranti-piranti sing ndadekake telung suku kuwi bisa diukur, ora mung diklaim.

Taruhane langsung lan bola-bali. Penyandang dana utawa lembaga legislatif takon, nalika babak anggaran sabanjure, "apa sing kita tampa saka dana iki" — lan organisasi sing mung nduweni cacahan kaluwaran (klinik sing dibukak, perkara sing diproses, sesi latihan sing dianakake) ora duwe wangsulan kanggo pitakon asil sing ana ing baline. Tim program yakin dheweke kasil amarga kagiyatane akeh lan rame, tanpa misahake kagiyatan saka owah-owahan ing donya sing dikarepake saka kagiyatan kuwi. Dewan nyetujoni inisiatif anyar amarga narasi sing mbujuk, banjur setaun candhake ora duwe dhasar sing disepakati kanggo mutusake arep nerusake, nggedhekake, utawa mungkasi inisiatif kuwi. Saben prakara kasebut yaiku kegagalan pangukuran kanthi akibat strategis, dudu kasusahan teknis belaka.

Piranti-piranti ing topik iki — Kartu Skor Nilai Publik saka Mark Moore, model logika, lan akuntabilitas adhedhasar asil karo kerabat-kerabate — ora ngrampungake saben masalah pangukuran sing diadhepi organisasi sektor publik utawa sektor sosial. Topik-topik candhake mbahas lapisan sing luwih angel lan luwih teknis: ngowahi asil dadi nilai dhuwit liwat analisis biaya-manfaat lan analisis efektivitas biaya (waca Topik 2.2 — Analisis Biaya-Manfaat Sosial lan Analisis Efektivitas Biaya), ngajeni asil sing angel didhuwitake liwat pangasilan sosial saka investasi (waca Topik 2.3 — Pangasilan Sosial saka Investasi lan Pangukuran Dampak), lan mbuktekake yen sawijining program tenan nyebabake owah-owahan sing katon liwat [evaluasi program](https://en.wikipedia.org/wiki/Program_evaluation) formal (waca Topik 2.4 — Ékonometrika Sektor Publik lan Evaluasi Program). Sing disuguhake topik iki yaiku lapisan ing sangisore telung kuwi: kosakata bebarengan lan sawetara kerangka sing awet kanggo nyatakake, sadurunge karya teknis kasebut diwiwiti, apa sing tenan arep diowahi organisasi, kanggo sapa, lan kepriye dheweke bakal ngerti.

## Konsep-Konsep Utama

**Kartu Skor Nilai Publik** yaiku usulan saka [Mark H. Moore](https://en.wikipedia.org/wiki/Mark_H._Moore) kanggo nglacak saben suku segitiga strategis nganggo set indikator dhewe-dhewe, tinimbang mung nggunakake ukuran finansial lan operasional sing bakal dipigunakake dening [balanced scorecard](https://en.wikipedia.org/wiki/Balanced_scorecard) sektor swasta. Moore nyesuekake balanced scorecard — piranti Robert Kaplan lan David Norton kanggo nglacak bisnis saka perspektif finansial, pelanggan, proses internal, lan pembelajaran — amarga garis dasar finansial tunggal ora bisa makili organisasi sing alesan utama anane yaiku nyiptakake nilai sing ora katon ing rega pasar. Kartu Skor Nilai Publik nyuwun organisasi nemtokake ukuran ing telung judhul sing nyerminake segitiga: akun legitimasi-lan-dhukungan (apa lingkungan otorisasi wis puas — penyandang dana, pengawas, masyarakat), akun nilai publik (apa proposisi nilai wis kawujud — asil kanggo warga lan klien), lan akun kapasitas operasional (apa organisasi bisa njaga lan nambah panyedhiyan layanan — staf, sistem, keuangan, kemitraan). Disiplin ana ing panolakan supaya ora ana siji akun sing dianggep makili kabeh; organisasi sing mung nglaporake efisiensi finansial, utawa mung kepuasan klien, durung nglaporake adhedhasar segitiga babar pisan.

**Model logika** menehi struktur internal marang akun nilai ing kartu skor. [Model logika](https://en.wikipedia.org/wiki/Logic_model) nggambarake rantai sebab-akibat sing diklaim dilakokake program: input (dhuwit, staf, lan sumber daya liyane sing diwajibake), kagiyatan (apa sing ditindakake organisasi nganggo input kuwi), kaluwaran (asil langsung sing bisa diitung saka kagiyatan kuwi — sesi sing diwenehake, izin sing dikeluarake, kluwarga sing dijarwani), asil (owah-owahan ing kawruh, prilaku, kahanan, utawa status sing dikarepake saka kaluwaran, biasane sajrone sawetara sasi utawa sawetara taun), lan dampak (owah-owahan jangka dawa sing asring ing tingkat populasi sing dikarepake dikontribusi dening asil, lumrahe dienggo bareng karo pelaku liya lan luwih angel disebabake marang siji program). Bedane antarane kaluwaran lan asil iku sing paling nemtokake ing topik iki: kaluwaran yaiku sing ditindakake organisasi; asil yaiku sing owah kanggo wong liya minangka akibate. Kaluwaran program latihan yaiku cacahe wong sing dilatih; asile yaiku apa sing banjur bisa ditindakake wong-wong kuwi, utawa kepriye kahanane owah, sing sadurunge ora bisa.

**Teori owah-owahan** yaiku disiplin sing raket kanggo nggawe asumsi ing mburi model logika dadi cetha, ora kari implisit — kenapa organisasi percaya yen kagiyatan A bakal nyebabake asil B, lan ing kahanan apa klaim sebab-akibat kuwi bisa gagal. [Teori owah-owahan](https://en.wikipedia.org/wiki/Theory_of_change) dudu mung model logika sing luwih rinci; dheweke nyorot nalar "yen... banjur... amarga" lan asumsi kontekstual sing biasane ora kasebut ing diagram kothak-lan-panah sawijining model logika. Topik 2.3 nggunakake teori owah-owahan minangka titik wiwitan pangukuran dampak ing sektor sosial kanthi luwih jero (waca Topik 2.3 — Pangasilan Sosial saka Investasi lan Pangukuran Dampak); ing kene, wigatine utamane minangka disiplin sing njaga model logika supaya jujur bab apa sing tenan diklaim bisa disebabake, beda karo apa sing mung diarep-arep bakal ngetutake.

**Akuntabilitas adhedhasar asil** (results-based accountability, RBA) yaiku anggota sing paling kondhang saka kulawarga kerangka adhedhasar asil sing dienggo ing pamarentah lan sektor sosial kanggo nyambungake asil tingkat populasi karo kinerja program tartamtu. Dikembangake dening Mark Friedman lan diwedharake ing bukune *Trying Hard Is Not Good Enough*, RBA misahake rong jinis akuntabilitas beda sing asring dicampur dening organisasi. Akuntabilitas populasi takon kepriye kahanan sawijining komunitas utawa yurisdiksi kabèh ing sawijining kondisi kesejahteraan — kemiskinan bocah, keamanan komunitas, pencapaian pendhidhikan — nganggo sawetara indikator utama sing ora diduweni utawa dikuasai kanthi lengkap dening siji lembaga wae. Akuntabilitas kinerja takon kepriye apike kinerja sawijining program utawa lembaga tartamtu, nganggo telung jinis [indikator kinerja](https://en.wikipedia.org/wiki/Performance_indicator) sing dipeksa dibedakake dening kerangka Friedman: pira sing ditindakake (upaya — cacahan kaluwaran), kepriye apike anggone ditindakake (mutu), lan apa ana sing luwih becik (efek — asil). Cara praktis RBA, kadhang diarani analisis "ngowahi kurva", makarya mundur saka indikator sing dipilih — takon crita apa sing dicritakake data, apa sing nyebabake crita kuwi, sapa mitra sing nduweni peran kanggo ngowahi, apa sing bakal kasil, lan apa sing diusulake organisasi kanggo ditindakake — versi sing luwih kanthi struktur saka nalar sing dirumusake kanthi kapisah dening model logika lan teori owah-owahan. RBA yaiku salah siji conto saka pola manajemen adhedhasar asil sing luwih amba, raket karo praktik rutin [pemantauan lan evaluasi](https://en.wikipedia.org/wiki/Monitoring_and_evaluation) sing dienggo ing pembangunan internasional lan administrasi publik, sing dipromosekake kanthi macem-macem wujud dening pamarentah nasional, penyandang dana filantropi, lan lembaga multilateral minangka disiplin bebarengan kanggo nyambungake pengeluaran karo asil, ora mung karo kaluwaran.

**Kaluwaran, asil, lan kartu skor bebarengan.** Alesan kerangka-kerangka iki kalebu ing siji topik, ora telu, yaiku amarga kabeh njawab pitakon dhasar sing padha ing titik beda siklus perencanaan lan pelaporan organisasi. Model logika digambar nalika desain, kanggo nyatakake klaim sebab-akibat. Akuntabilitas adhedhasar asil lan kerangka sing sepadan ditrapake nalika pelaporan, kanggo njaga ukuran kinerja tetep jujur bab bedane upaya lan efek. Kartu Skor Nilai Publik ana ing ndhuwur kekarone, minangka struktur tetep sing njamin bukti asil — kepriye wae cara nggawene — tenan tekan marang pirembugan legitimasi lan kapasitas ing papan keputusan anggaran lan mandat digawe, ora mung kari ing pelaporan tim program dhewe. Bebarengan, telung kerangka kasebut ngowahi [nilai publik](https://en.wikipedia.org/wiki/Public_value) saka klaim sing digawe organisasi bab awake dhewe dadi klaim sing bisa dibela nganggo bukti.

## Praktik Paling Apik

1. **Gambaren model logika sadurunge indikator, aja sawise.** Milih apa sing arep diukur sadurunge sarujuk apa sing diklaim bakal disebabake bakal ngasilake dhaptar apa wae sing gampang diitung; gambaren dhisik rantai saka input nganti dampak, banjur pilihen ukuran sing nguji saben sambungan ing rantai kuwi.
2. **Laporna adhedhasar telu akun kartu skor bebarengan, aja siji-siji.** Pembaruan legitimasi tanpa bukti asil, utawa laporan asil tanpa akun kapasitas bab biaya kanggo njaga, saben-saben namung nyritakake sebagian saka crita sing dibutuhake penyandang dana utawa pengawas kanggo nggawe keputusan nyata.
3. **Pisahna upaya, mutu, lan efek kanthi eksplisit ing saben laporan kinerja.** Nggunakna pambagi telung arah saka Friedman sanajan ing njaba implementasi RBA formal; laporan sing nyampur "sesi sing diwenehake" karo "urip sing apik" tanpa mbedakake bakal tansah condhong marang sing luwih gampang digedhekake.
4. **Pilihen sawetara indikator utama populasi lan pertahanna nganti pirang-pirang taun, ora mung pirang-pirang triwulan.** Kondisi tingkat populasi obah alon lan dipengaruhi dening akeh pelaku; ngganti ukuran utama saben siklus pelaporan ndadekake ora bisa dingerteni apa kurva tenan lagi diowahi.
5. **Sebutna kanthi cetha apa sing ora dikuwasani organisasi.** Model logika sing nuduhake yen siji program kanthi pepak nyebabake asil tingkat populasi ngundang skeptisisme sing ngrusak legitimasi nalika asil ora obah miturut jadwal; nyatakna faktor-faktor liya sing nyumbang wiwit wiwitan.
6. **Terbitna kerangka asil sadurunge babak anggaran, aja sawise.** Kerangka asil sing digawe kanggo mbenerake keputusan anggaran sing wis dijupuk katon kaya rasionalisasi sawise kedadeyan; sing diterbitake sadurunge babak iku bukti yen keputusan nyata lagi diuji karo kerangka kasebut.
7. **Jagaa kartu skor lan model logika minangka dokumen urip, ditinjau maneh nalika konteks owah, ora minangka artefak taunan.** Model logika sing digambar kanggo siji lingkungan kabijakan bisa meneng-menengan ora cocog maneh karo kasunyatan — hukum anyar, owah-owahan demografi, owah-owahan pendanaan — suwe sadurunge tinjauan sing dijadwalake bisa nangkep; anggepen kekarone dadi duweke tim panyedhiya layanan, dudu kegiatan kepatuhan kanggo kantor pusat.
8. **Jagaa ukuran akun kinerja tetep cedhak karo wong-wong sing bisa tumindak ing ukuran kuwi.** Tim program bisa langsung nambah ukuran mutu lan upaya; yen diwenehi target asil tingkat populasi sing ora bisa digerakake dhewe, pangukuran dadi sumber demoralisasi, dudu arah.
9. **Anggepen target asil sing ora kecandhak minangka dhawuh kanggo takon kenapa, dudu putusan sing kudu didhelikake.** Kabiasaan "ngowahi kurva" takon apa sing nyebabake tren sadurunge nyalahake njaga pelaporan asil tetep migunani; budaya sing ngukum target sing ora kecandhak ngajari staf nglindhungi angka, ora asil.
10. **Gawenen asumsi ing teori owah-owahan bisa dibuktekake salah.** Asumsi sing ditulis kanthi kabur nganti ora ana bukti sing bisa mbantah ora nambah ketelitian ing model logika; tulisen asumsi kanthi cukup tartamtu supaya evaluasi ing mbesuk bisa nuduhake yen salah.

## Pitakon kanggo Diskusi karo Tim

**Apa kita saiki bisa mbedakake, kanggo program kita sing paling wigati, kaluwaran saka asil — lan apa staf kita dhewe nggunakake kalih tembung kuwi kanthi bener?** Akeh organisasi nglaporake cacahan kagiyatan nganggo basa asil tanpa nyadari penggantine, sing meneng-menengan ngrusak bedane sing dianggep dhasar dening topik iki. Gunakna pitakon iki kanggo njupuk laporan saiki sing nyata lan mriksa, baris-baris, angka endi sing nggambarake apa sing ditindakake organisasi lan endi sing nggambarake apa sing owah kanggo wong liya. Rembugen ing ngendi basa kuwi nyimpang, lan apa nyimpange nggambarake kebingungan tenan bab logika program utawa mung amarga data asil luwih angel dipikolehi tinimbang data kaluwaran. Yen wangsulan jujure yaiku sing terakhir, kuwi dhewe temuan sing pantes dicathet, dudu alesan kanggo terus nggunakake basa kaluwaran sing dikalungi asil.

**Ing ngendi pelaporan kita saiki nggabungake upaya, mutu, lan efek dadi siji angka, lan apa sejatine sing diwenehake angka kuwi marang pamaca?** Pambagi telung arah saka Friedman ana amarga organisasi asring condhong nglaporake upaya — sing paling gampang diitung saka telu — nalika nuduhake yen wis nglaporake efek. Gunakna pitakon iki kanggo nemtokake siji metrik andalan sing saiki dilaporake organisasi lan nemtokake, bebarengan, endi saka telu sing sejatine diukur. Rembugen apa sing dibutuhake kanggo nglaporake telune kanthi kapisah kanggo metrik kuwi, lan apa nglakoni mengkono bakal ngowahi kepriye organisasi dideleng dening wong-wong sing saiki mung weruh angka campuran.

**Yen asil populasi utama kita ora obah nganti rong siklus pelaporan maneh, apa sing bakal kita tindakake kanthi beda, lan apa sing ora bakal kita owahi?** Pitakon iki nguji apa organisasi tenan nggunakake kerangka asile kanggo nyetir, utawa mung nggawe kanggo kewajiban pelaporan. Gunakna kanggo mbedakake bagean strategi saiki endi sing gumantung marang data asil lan endi sing tetep ora preduli apa sing ditudhuhake data. Rembugen kanthi jujur apa ana bagean program saiki sing bakal tetep ora owah sanajan bukti tenan nglawan, amarga kuwi bagean sing sejatine ora diatur dening kerangka.

**Apa Kartu Skor Nilai Publik kita, yen ana, nglaporake kabeh telung suku segitiga, utawa wis meneng-menengan dadi kartu skor kanggo siji suku wae?** Kerangka asil asring diwiwiti kanthi ambisi telung suku sing tenan lan nyimpang, ing sangisore tekanan pelaporan, dadi dokumen asil-wae utawa keuangan-wae. Gunakna pitakon iki kanggo ngaudit loro utawa telu laporan formal pungkasan adhedhasar struktur telung akun sing dijlentrehake topik iki. Rembugen suku endi sing asring dicopot dhisik nalika wektu cekak, lan apa sing dituduhake bab suku endi sing dianggep opsional dening organisasi kanthi implisit.

**Sapa ing njaba organisasi iki sing kudu setuju karo model logika kita supaya bisa dipercaya, lan apa kita wis tenan takon marang wong-wong kuwi?** Model logika sing digambar sakabehe dening tim program sing ngrancang intervensi bisa meneng-menengan nyimpen asumsi optimistis sing ora ana wong ing njaba ruangan sing bisa nantang. Gunakna pitakon iki kanggo nemtokake pelaku eksternal endi — penyandang dana, mitra panyedhiya layanan, wong-wong sing dilayani program — sing nduweni kepentingan ing bener orane rantai sebab-akibat, lan apa ana sing wis tenan nilik. Rembugen apa sing owah, yen ana, nalika pungkasan sudut pandang eksternal diundang menyang tinjauan kuwi.

**Apa set indikator populasi lan kinerja paling cilik sing bisa kita laporake sing isih ngidini wong njaba menilai apa organisasi iki nyiptakake nilai publik?** Sistem pangukuran condhong nglumpukake indikator luwih cepet tinimbang ngilangi, nganti kerangka dadi gedhe banget kanggo dienggo ing keputusan. Gunakna pitakon iki kanggo nyoba, minangka latihan, nyuda set indikator saiki separo tanpa kelangan kemampuan njawab pitakon akuntabilitas populasi lan akuntabilitas kinerja sing dijlentrehake topik iki. Rembugen panolakan apa sing muncul saka latihan kuwi, amarga panolakan kanggo ngilangi indikator tartamtu asring dadi tandha apa sing sejatine ditanggung organisasi, apa cocog utawa ora karo strategi sing dinyatakake.

## Ing Praktik: Conto Nilai Publik

Jaringan regional amal dhukungan kulawarga — fiktif, nggambarake pola, dudu laporan bab organisasi nyata — wis sapuluh taun mbukak program kunjungan omah kanggo wong tuwa anyar ing lingkungan berpenghasilan rendah. Laporan taunane marang penyandang dana rinci lan, miturut ukuran kaluwaran, nggumunake: ewonan kunjungan omah rampung saben taun, kehadiran dhuwur ing lokakarya parenting, skor kepuasan kuwat saka kulawarga sing melu. Adhedhasar rekam jejak kuwi, jaringan tuwuh terus-terusan, nambah cabang lokal anyar kira-kira saben rong taun.

Penyandang dana nasional anyar, sing nimbang hibah pirang-pirang taun sing cukup gedhe kanggo nglipatgandakake jangkauan jaringan, ngajokake pitakon sing durung tau resmi diajokake dening dewan jaringan dhewe marang manajemen: bukti apa sing nuduhake yen bocah-bocah ing kulawarga sing nampa kunjungan omah tenan luwih becik, mengko, tinimbang bocah sepadan sing kulawargane ora. Pimpinan jaringan nyadari, nalika nyelehake pitakon kuwi, yen pelaporane ora tau misahake upaya saka efek. Cacahan kunjungan lan skor kepuasan yaiku bukti asli yen program disuguhake lan ditampa kanthi apik; ora ana sing dadi bukti yen program ngowahi asil perkembangan bocah, sing yaiku klaim sing kalebu ing pernyataan misi jaringan dhewe lan, kanthi implisit, ing saben permohonan hibah sing tau ditulis.

Jaringan nggawe model logika saka awal, diwiwiti saka asil sing tenan dikarepake — indikator perkembangan bocah awal sing apik, kasus penelantaran bocah sing kabukten sing suda, kapercayan wong tuwa sing luwih kuwat — lan makarya mundur menyang kagiyatan lan kaluwaran sing dikarepake dadi gantungane saben-saben, kanthi nyebut asumsi ing antarane kanthi cetha. Dheweke ngadopsi struktur akuntabilitas adhedhasar asil sing disederhanakake: indikator populasi sing dilacak ing tingkat lingkungan lan dienggo bareng karo sekolah lan layanan kesehatan lokal, bebarengan karo indikator kinerja sing bisa langsung ditindakake timé dhewe — frekuensi kunjungan, rampunge lokakarya, lan kapercayan parenting miturut penilaian staf ing wulan katelu lan kaping rolas. Rong saka limang indikator asil ora obah kaya sing diarep-arep ing siji lingkungan nalika siklus pelaporan pisanan. Tinimbang nyingkirake asile, jaringan nggunakake proses "ngowahi kurva" dhewe kanggo nyelidiki, nemokake yen owah-owahan staf perawat kunjungan kesehatan lokal wis ngganggu jalur rujukan, lan nyesuekake pangaturan kemitraane, ora model intine. Penyandang dana nganyari lan nggedhekake hibah, nyebutake kejujuran pelaporan, dudu ora anane kekurangan, minangka alesan kanggo percaya.

## Papat Sudut Pandang Sektor

### Pamarentah Lokal

Kerangka asil sawijining otoritas lokal biasane ana ing njero set indikator sing ditemtokake sacara nasional sing ora dipilihe nanging kudu dilaporake, bebarengan karo ukuran sing dipilih sacara lokal sing nggambarake prioritas dewan dhewe. Struktur dobel iki tegese kartu skor lokal asring kudu ngrukunake loro pamirsa kanthi pitakon beda — inspektur nasional sing takon bab kepatuhan marang set indikator standar, lan warga lokal sing takon bab kondisi lokal tartamtu sing katon, kayata dalan utawa layanan tartamtu. Model logika ing skala pamarentah lokal biasane paling gampang digawe kanggo siji layanan (owah-owahan pengumpulan daur ulang, desain ulang perpustakaan) lan paling angel digawe kanthi bisa dipercaya kanggo asil lintas sektor kayata kohesi komunitas, ing ngendi akeh pelaku ing njaba kontrol dewan uga nyumbang.

### Pamarentah Nasional

Kerangka asil nasional makarya ing skala ing ngendi bedane akuntabilitas populasi lan akuntabilitas kinerja saka akuntabilitas adhedhasar asil dadi wajib, dudu pilihan: indikator kesehatan utawa pendhidhikan nasional dipengaruhi atusan program, mung sawetara sing didanai langsung dening siji departemen, saengga siji kementerian sing ngaku piyambak kredit utawa piyambak kesalahan kanggo tren nasional arang bisa dibela. Pamarentah nasional uga sumber paling umum kerangka asil gedhe sing diwajibake sacara pusat sing kudu diadopsi dening lembaga panyedhiya layanan ing ngisor rantai, sing nyebabake risiko bola-bali yen kerangka dirancang kanggo agregasi lan perbandingan antar departemen, ora kanggo nyetir panyedhiya layanan siji program.

### Sektor Sosial lan Nirlaba

Organisasi nirlaba lan organisasi non-pamarentah (LSM) luwih asring nggawe model logika lan teori owah-owahan dhewe saka prinsip dhasar tinimbang ngadopsi kerangka sing diturunake dening otorisator, amarga penyandang dana asring sing nyuwun kasus sebab-akibat, ora nyuguhake templat standar. Iki menehi kebebasan luwih marang organisasi sektor sosial kanggo ngrancang kerangka asil sing cocog karo logika program sing sejatine, nanging uga luwih kena kejenuhan pangukuran sing didorong penyandang dana, ing ngendi saben hibah nggawa syarat pelaporan dhewe lan organisasi pungkasane njaga sawetara kerangka asil paralel kanggo karya dhasar sing padha. Pambagi populasi-lawan-kinerja saka akuntabilitas adhedhasar asil migunani banget ing kene, amarga menehi basa marang organisasi nirlaba kanggo ngandhani penyandang dana kanthi cetha yen dheweke bisa dimintai tanggung jawab kanggo ukuran kinerja dhewe nanging ora, piyambak, kanggo indikator populasi sing uga dipengaruhi akeh pelaku liya.

### Tingkat Multilateral lan Internasional

Lembaga multilateral nglakokake manajemen adhedhasar asil ing skala ing ngendi asumsi model logika lumaku ing puluhan konteks nasional bebarengan, saengga logika intervensi sing bener ing siji negara bisa gagal meneng-menengan ing negara liya tanpa indikator global utama nuduhake konteks endi sing dadi masalah. Kerangka asil ing setelan iki asring dibangun kanggo nyukupi pirang-pirang pamarentah donor bebarengan, saben-saben nduweni preferensi pelaporan dhewe, sing nyorong menyang set indikator standar (kaya sing dipromosekake liwat panuntun manajemen adhedhasar asil internasional) kanthi ngorbanake kekhususan lokal. Jurang antarane kaluwaran sing bisa dilaporake kanthi cepet dening mitra pelaksana — latihan sing dianakake, klinik sing disuplai — lan asil sing mung katon ing survei nasional pirang-pirang taun mengko iku paling amba ing kene, saengga disiplin nyatakake rantai sebab-akibat sing dianggep kanthi eksplisit, tinimbang nganggep, dadi luwih wigati.

## Cara-Cara Kegagalan sing Umum

**Kaluwaran sing nyamar dadi asil.** Organisasi nglaporake cacahan kagiyatan nganggo basa asil — "keamanan komunitas sing luwih apik" nalika ukuran sejatine yaiku patroli sing ditindakake — apa saka campur-aduk sing tulus utawa amarga data asil luwih angel lan luwih alon dikumpulake. Biayane katon nalika pamriksa eksternal nyuwun bukti asil langsung lan mung nemokake kaluwaran ing mburi klaim, ngrusak kredibilitas organisasi luwih parah tinimbang asil sing sederhana nanging dilaporake kanthi jujur.

**Panambahan indikator sing ora kapetung.** Kartu skor utawa model logika nglumpukake ukuran luwih cepet tinimbang ngilangi, didorong saben panyuwunan pamangku kepentingan anyar sing nambah siji baris maneh, ora ngganti sing ana. Asile pungkasan yaiku kerangka sing gedhe banget kanggo digunakake manajer ing keputusan, sing meneng-menengan mbalekake organisasi menyang pertimbangan informal nalika kerangka resmi dadi artefak pelaporan sing ora ana sing nyuwun.

**Target sing ngrebut.** Ukuran kinerja, sapisan disambungake karo pendanaan utawa ganjaran, dadi sing dioptimalake staf langsung, ora asil sing dimaksudake dadi gantine — pola sing diterangake [hukum Goodhart](https://en.wikipedia.org/wiki/Goodhart%27s_law), ing ngendi ukuran sing dipigunakake minangka target ora dadi ukuran sing bisa dipercaya maneh. Papan topik iki kanggo dinamika kasebut ing sektor publik khususe, kalebu kepriye rezim mutu nyoba ndeteksi lan mbatesi, ana ing papan liya (waca Topik 3.11 — Manajemen Kualitas, Keselamatan, lan Kinerja); ing kene wigati minangka alesan kanggo njaga ukuran upaya, mutu, lan efek kapisah lan nilik maneh target sadurunge ngrusak prilaku.

**Panyalahan atribusi.** Pelaporan program nuduhake tanggung jawab sebab-akibat tunggal kanggo asil tingkat populasi sing uga dipengaruhi akeh pelaku liya, apa liwat basa sing ceroboh utawa kapercayan tulus. Nalika asil ora obah — asring amarga alasan ing njaba kontrol program — organisasi nanggung salah sing ora sepadan karo kontribusi sejatine, sing banjur nglemahake pelaporan jujur bab kekurangan ing siklus candhake.

**Kerangka tanpa umpan balik.** Organisasi mbangun model logika lan kerangka asil sing dirancang kanthi tenan apik, banjur ora nate nilik maneh adhedhasar asil nyata, saengga ngeras dadi dokumen tetep, dudu piranti manajemen urip. Strategi ing ngisore terus mlaku nganggo asumsi asli pirang-pirang taun sawise bukti mesthine mbenerake revisi, kanthi ngorbanake kemampuan adaptasi sing dikarepake saka kerangka kuwi.

## Dhaptar Pariksa

- [ ] Gambaren model logika (input, kagiyatan, kaluwaran, asil, dampak) kanggo saben program utama sadurunge ngrampungake indikatore.
- [ ] Tulisen asumsi sebab-akibat saka teori owah-owahan kanthi cukup tartamtu supaya bukti bisa mbantah.
- [ ] Pisahna ukuran upaya, mutu, lan efek ing saben laporan kinerja, sanajan ing njaba implementasi akuntabilitas adhedhasar asil formal.
- [ ] Bangunen utawa anyarana Kartu Skor Nilai Publik supaya kabeh telung suku — legitimasi, nilai, kapasitas — dilaporake bebarengan, ora kapisah.
- [ ] Pilihen set cilik lan stabil indikator utama tingkat populasi lan komitmena njagane ing pirang-pirang siklus pelaporan.
- [ ] Priksanen laporan saiki kanggo basa sing nggambarake kaluwaran nganggo tembung asil, lan benerana.
- [ ] Terbitna kerangka asil sadurunge babak anggaran utawa pendanaan sabanjure, ora minangka buntute.
- [ ] Sebutna kanthi eksplisit apa sing ora dikuwasani organisasi piyambak kanggo saben klaim tingkat populasi sing dilaporake.
- [ ] Tetepna siklus tetep kanggo nilik maneh model logika adhedhasar bukti nyata, ora mung nalika evaluasi formal sing dijadwalake.
- [ ] Tuduhna paling ora siji pamangku kepentingan eksternal kanggo nilik asumsi model logika sadurunge diputusake.
- [ ] Auditen set indikator saiki kanggo nemokake kesempatan ngilangi ukuran sing ora ana sing nggunakake ing keputusan nyata.
- [ ] Sarujuken, sadurunge, apa sing bakal ditindakake organisasi kanthi beda yen asil utama ora obah sajrone rong siklus pelaporan.
