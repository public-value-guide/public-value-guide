# ប្រធានបទ 1.1 — ការណែនាំអំពីតម្លៃសាធារណៈ

**តម្លៃសាធារណៈមានតែនៅពេលដែលអ្នកដឹកនាំអាចបង្ហាញក្នុងពេលតែមួយថា ពលរដ្ឋនឹងអនុញ្ញាតឱ្យមានការខិតខំប្រឹងប្រែងនោះ អ្វីដែលវាផលិតបានពិតជាមានតម្លៃគួរមាន និងអង្គការអាចផ្តល់ជូនវាបានពិតប្រាកដ — ជាការធ្វើតេស្តដែលទាំងតម្លៃទីផ្សារ និងលទ្ធផលបោះឆ្នោត មិនអាចឆ្លងកាត់បានដោយខ្លួនឯង។**

## ហេតុអ្វីបានជាបញ្ហានេះសំខាន់សម្រាប់តម្លៃសាធារណៈ

សូមសួរនាយកហិរញ្ញវត្ថុនៃមន្ទីរពេទ្យ ស្នងការឧទ្យាននៃទីក្រុង ឬនាយកប្រតិបត្តិនៃអង្គការសប្បុរសធម៌តូចមួយថា តើពួកគេដឹងដោយរបៀបណាថាការងាររបស់ខ្លួនគួរធ្វើ នោះអ្នកស្ទើរតែមិនដែលទទួលបានចម្លើយដែលមានទំនុកចិត្តដែលសង់លើសូចនាករតែមួយច្បាស់លាស់ឡើយ។ ក្រុមហ៊ុនឯកជនអាចចង្អុលទៅប្រាក់ចំណេញ៖ ប្រសិនបើអតិថិជនបន្តបង់ច្រើនជាងថ្លៃដើមនៃការផលិតទំនិញ ក្រុមហ៊ុនកំពុងបង្កើតតម្លៃ ហើយប្រសិនបើពួកគេឈប់បង់ ក្រុមហ៊ុនបរាជ័យ។ អង្គការវិស័យសាធារណៈ និងវិស័យសង្គមមិនមានសញ្ញាតែមួយដែលស្មើគ្នានោះទេ ព្រោះអ្វីដែលពួកគេផលិតភាគច្រើន — ផ្លូវស្អាត នីតិវិធីត្រឹមត្រូវតាមច្បាប់ កន្លែងដែលគ្រួសារអាចពឹងពាក់បាននៅពេលមានរឿងអាក្រក់កើតឡើង — គឺជា[ទំនិញសាធារណៈ](https://en.wikipedia.org/wiki/Public_good_(economics)) ដែលមិនដែលត្រូវបានលក់ក្នុងតម្លៃដែលបង្ហាញថាវាមានតម្លៃប៉ុនណាចំពោះអ្នកទទួល។

គម្លាតនេះបង្កើតភាពតានតឹងពិតប្រាកដ និងជាក់ស្តែងសម្រាប់អ្នកគ្រប់គ្រងសាធារណៈ និងអ្នកដឹកនាំវិស័យសង្គម។ រដ្ឋាភិបាល និងអង្គការក្រៅរដ្ឋាភិបាល (NGO) ត្រូវបានស្នើឱ្យ ក្នុងវដ្តថវិកាតែមួយ ប្រព្រឹត្តដូចអាជីវកម្មដែលមានប្រសិទ្ធភាព — កាត់បន្ថយថ្លៃដើមក្នុងមួយឯកតា ដេញតាមសូចនាករសមិទ្ធកម្មសំខាន់ៗ — ហើយក្នុងពេលជាមួយគ្នាប្រព្រឹត្តដូចឧបករណ៍សុទ្ធសាធនៃអាណត្តិប្រជាធិបតេយ្យ ឬអាណត្តិភាពជាអ្នកទទួលបន្ទុកទុកចិត្ត៖ ធ្វើតែអ្វីដែលផែនការឃោសនាបោះឆ្នោតបានសន្យា ឬតែអ្វីដែលជំនួយមូលនិធិស្ថាបនាបានកំណត់។ គ្មានតេស្តណាមួយតែម្នាក់ឯងអាចសម្រេចថាតើកម្មវិធីជាក់លាក់មួយសមនឹងទទួលបានថវិការបស់ខ្លួនក្នុងឆ្នាំនេះឬអត់នោះទេ។ តេស្តប្រសិទ្ធភាពតឹងរ៉ឹងមើលតម្លៃសេវាកម្មទាបពេក ដែលសេវាទាំងនោះមានដោយសារតែគ្មានទីផ្សារណាផ្តល់ជូនក្នុងតម្លៃដែលអាចទទួលយកបាន។ ចំណែកតេស្តអាណត្តិតឹងរ៉ឹងមើលតម្លៃការវិនិច្ឆ័យទាបពេក ដែលជាការវិនិច្ឆ័យដែលអ្នកគ្រប់គ្រងសាធារណៈប្រើដើម្បីបកប្រែអាណត្តិទូលំទូលាយឱ្យសមនឹងពិភពលោកដែលកំពុងផ្លាស់ប្តូរ។

ទ្រឹស្តីតម្លៃសាធារណៈមានឡើងដើម្បីបិទគម្លាតនេះ។ វាផ្តល់វាក្យសព្ទដល់អ្នកដឹកនាំវិស័យសាធារណៈ និងវិស័យសង្គមសម្រាប់ការពន្យល់ហេតុផលនៃការងាររបស់ខ្លួន ដែលមិនមែនជាសេដ្ឋកិច្ចទីផ្សារសុទ្ធសាធ ឬអាណត្តិបោះឆ្នោត ឬអាណត្តិអ្នកទទួលបន្ទុកទុកចិត្តសុទ្ធសាធទេ ប៉ុន្តែជាស្តង់ដារទីបីដែលខុសគ្នា៖ តើនេះជាអ្វីដែលពលរដ្ឋជាសមូហភាពនឹងអនុញ្ញាតឱ្យចំណាយធនធានរួមដើម្បីផលិតឬទេ? ប្រធានបទនេះណែនាំស្តង់ដារនោះ និងក្របខ័ណ្ឌដែលបានបង្កើតឡើងដើម្បីអនុវត្តវា ក្នុងកម្រិតលម្អិតគ្រប់គ្រាន់ដើម្បីប្រើបានភ្លាមៗ។ វាទុកយន្តការស៊ីជម្រៅនៃក្របខ័ណ្ឌនេះឱ្យប្រធានបទដែលដាច់ដោយឡែក (សូមមើល ប្រធានបទ 1.2 — ត្រីកោណយុទ្ធសាស្ត្រ៖ ភាពស្របច្បាប់ តម្លៃ និងសមត្ថភាព)។

## គំនិតស្នូល

**[តម្លៃសាធារណៈ](https://en.wikipedia.org/wiki/Public_value)** គឺជាអ្វីដែលអង្គការវិស័យសាធារណៈ ឬវិស័យសង្គមរួមចំណែកដល់សង្គម ដោយវិនិច្ឆ័យតាមអ្វីដែលពលរដ្ឋជាសមូហភាពចាត់ទុកថាសមនឹងធនធានរួមដែលបានចំណាយដើម្បីផលិតវា។ សាស្ត្រាចារ្យនៃសាកលវិទ្យាល័យ Harvard គឺ [Mark H. Moore](https://en.wikipedia.org/wiki/Mark_H._Moore) បានបង្កើតពាក្យនេះជាផ្នែកគូស្រករនៃវិស័យសាធារណៈចំពោះតម្លៃម្ចាស់ភាគហ៊ុន៖ ខណៈដែលក្រុមប្រឹក្សាភិបាលរបស់ក្រុមហ៊ុនសួរថាតើការវិនិយោគនឹងផ្តល់ផលតបស្នងច្រើនជាងថ្លៃដើមដែលម្ចាស់ភាគហ៊ុនត្រូវចំណាយឬអត់ អ្នកគ្រប់គ្រងសាធារណៈគួរសួរថាតើគំនិតផ្តួចផ្តើមមួយនឹងផ្តល់ផលតបស្នងច្រើនជាងថ្លៃដើមដែលពលរដ្ឋត្រូវចំណាយឬអត់ ដោយយល់ថ្លៃដើមក្នុងន័យទូលំទូលាយ រួមមានប្រាក់ អំណាច ទំនុកចិត្ត និងសេរីភាពដែលត្រូវលះបង់។ តម្លៃសាធារណៈមិនដូចគ្នានឹងប្រជាប្រិយភាពទេ — ពលរដ្ឋភាគច្រើនអាចចង់បានអ្វីមួយដែលក្រោយមកបង្ហាញថាមិនសមនឹងមាន — ហើយក៏មិនដូចគ្នានឹងតម្លៃទីផ្សារដែរ។

ឧបករណ៍របស់ Moore សម្រាប់ធ្វើឱ្យតម្លៃសាធារណៈអាចអនុវត្តបានគឺ **ត្រីកោណយុទ្ធសាស្ត្រ**៖ ផែនការរបស់អ្នកគ្រប់គ្រងសាធារណៈមានមូលដ្ឋានរឹងមាំ លុះត្រាតែវាបំពេញតេស្តបីក្នុងពេលតែមួយ។ ជ្រុងទីមួយគឺ **ភាពស្របច្បាប់ និងការគាំទ្រ** — ថាតើបុគ្គល និងស្ថាប័នដែលត្រូវនិយាយថាយល់ព្រម (អ្នកត្រួតពិនិត្យដែលជាប់ឆ្នោត អ្នកផ្តល់មូលនិធិ តុលាការ សាធារណជន) ពិតជាអនុញ្ញាតឱ្យមានការខិតខំប្រឹងប្រែងនោះឬអត់ ដែលជាសំណួរមួយដែលឈរលើគំនិតទូលំទូលាយជាងនៃ[ភាពស្របច្បាប់](https://en.wikipedia.org/wiki/Legitimacy_(political))ផ្នែកនយោបាយ និងខុសពីខ្សែ[គណនេយ្យភាព](https://en.wikipedia.org/wiki/Accountability)ជាផ្លូវការ ដែលជាប្រធានបទឯកទេស (សូមមើល ប្រធានបទ 3.4 — គណនេយ្យភាព តម្លាភាព និងភាពស្របច្បាប់)។ ជ្រុងទីពីរគឺ **សំណើតម្លៃ** — ថាតើអ្វីដែលការខិតខំប្រឹងប្រែងនោះផលិតបានពិតជាសមនឹងធនធានដែលវាប្រើប្រាស់ឬអត់។ ជ្រុងទីបីគឺ **សមត្ថភាពប្រតិបត្តិការ** — ថាតើអង្គការ ដោយខ្លួនឯង ឬតាមរយៈដៃគូ អាចផ្តល់ជូនអ្វីដែលខ្លួនស្នើបានពិតប្រាកដឬអត់។ ប្រធានបទនេះណែនាំត្រីកោណត្រឹមកម្រិតនេះប៉ុណ្ណោះ ហើយអន្តរកម្ម និងការដោះដូររបស់វាជាប្រធានបទឯកទេស (សូមមើល ប្រធានបទ 1.2 — ត្រីកោណយុទ្ធសាស្ត្រ៖ ភាពស្របច្បាប់ តម្លៃ និងសមត្ថភាព)។

1. **សូមសរសេរសំណើតម្លៃសាធារណៈចុះជាមួយប្រយោគតែមួយ មុនពេលព្រាងករណីអាជីវកម្ម។** ប្រសិនបើក្រុមមិនអាចបញ្ជាក់ថាកម្មវិធីបង្កើតតម្លៃអ្វី និងសម្រាប់នរណា ករណីអាជីវកម្មនឹងបិទបាំងគម្លាតនោះដោយគោលដៅលទ្ធផលផលិត ជំនួសឱ្យការដោះស្រាយវា។

2. **សូមបញ្ជាក់បរិយាកាសផ្តល់សិទ្ធិរបស់អ្នកឱ្យច្បាស់លាស់ មិនមែនគ្រាន់តែចំណុចថវិការបស់អ្នកប៉ុណ្ណោះទេ។** សូមរាយឈ្មោះស្ថាប័ន និងក្រុមអ្នកពាក់ព័ន្ធទាំងអស់ដែលការយល់ព្រមរបស់ពួកគេ ទាំងដោយបំណងមិនបញ្ចេញ ឬដោយបើកចំហ ទ្រទ្រង់កម្មវិធីឱ្យនៅរស់៖ នីតិបញ្ញត្តិ ក្រុមប្រឹក្សា អាជ្ញាធរបទប្បញ្ញត្តិ អ្នកផ្តល់មូលនិធិ និងអ្នកប្រើប្រាស់សេវា។

3. **សូមសួរសំណួរបីដាច់ដោយឡែកពីគ្នា កុំបញ្ចូលជាសំណួរតែមួយ។** «តើវាមានការអនុញ្ញាតឬទេ?» «តើវាសមនឹងធ្វើឬទេ?» និង «តើយើងអាចផ្តល់ជូនវាបានឬទេ?» គឺជាតេស្តដាច់ដោយឡែកពីគ្នា ដែលនីមួយៗអាចបរាជ័យដោយឯករាជ្យ ហើយការចាត់ទុកវាជារឿងតែមួយលាក់បាំងការបរាជ័យដែលត្រីកោណយុទ្ធសាស្ត្រត្រូវបានរចនាឡើងដើម្បីលាតត្រដាង។

4. **សូមចាត់ទុកភាពស្របច្បាប់ជាអ្វីដែលត្រូវរកឱ្យបានជាបន្តបន្ទាប់ មិនមែនទទួលតែម្តងនោះទេ។** ការបោះឆ្នោត ការតែងតាំង ឬជំនួយមូលនិធិស្ថាបនាផ្តល់អំណាច ត្រឹមចំណុចពេលវេលាមួយ ប៉ុន្តែមិនបញ្ជាក់ទទួលស្គាល់រាល់ការសម្រេចចិត្តជាបន្តបន្ទាប់ដោយគ្មានកំណត់ឡើយ។

5. **សូមបែងចែកបរិមាណលទ្ធផលផលិតពីតម្លៃសាធារណៈ។** ការរាប់ចំនួនដែលកើនឡើងនៃការមកពិនិត្យនៅគ្លីនិក ប័ណ្ណអនុញ្ញាតដែលបានចេញ ឬអាហារដែលបានចែក ពិពណ៌នាសកម្មភាព មិនមែនតម្លៃទេ។ សំណួរដែលពាក់ព័ន្ធគឺថា តើសកម្មភាពនោះបានផលិតលទ្ធផលដែលពលរដ្ឋនឹងវិនិច្ឆ័យថាសមនឹងថ្លៃដើមឬអត់ (សូមមើល ប្រធានបទ 2.1 — កាតពិន្ទុតម្លៃសាធារណៈ និងក្របខ័ណ្ឌលទ្ធផល)។

6. **សូមប្រើវាក្យសព្ទរួមរវាងរដ្ឋាភិបាល និងវិស័យសង្គមដោយចេតនា។** ទីភ្នាក់ងារទីក្រុង និងអង្គការមិនស្វែងរកប្រាក់ចំណេញដែលផ្តល់សេវាជាប់គ្នា ច្រើនតែពិពណ៌នាតម្លៃមូលដ្ឋានតែមួយដោយភាសាដែលមិនត្រូវគ្នា ការអនុម័តវាក្យសព្ទរួមបីជ្រុងធ្វើឱ្យការដេញថ្លៃរួមគ្នាដើម្បីទទួលមូលនិធិ និងភាពជាដៃគូងាយស្រួលចរចាដោយស្មោះត្រង់។

7. **សូមទប់ទល់នឹងការបង្រួមករណីសម្រាប់កម្មវិធីមួយឱ្យទៅជាលេខតែមួយ។** តួលេខថ្លៃដើមក្នុងមួយឯកតា ឬពិន្ទុពេញចិត្តជាភស្តុតាងមានប្រយោជន៍ ប៉ុន្តែដោះស្រាយបានយ៉ាងច្រើនតែជ្រុងមួយនៃត្រីកោណ សូមបង្ហាញទាំងបីជ្រុងទន្ទឹមគ្នា។

8. **សូមពិនិត្យសំណើតម្លៃឡើងវិញរាល់ពេលបរិយាកាសផ្តល់សិទ្ធិផ្លាស់ប្តូរយ៉ាងសំខាន់។** ការផ្លាស់ប្តូរភាពជាអ្នកដឹកនាំនយោបាយ យុទ្ធសាស្ត្រថ្មីរបស់អ្នកផ្តល់មូលនិធិ ឬការប្រែប្រួលនៃឥរិយាបថសាធារណៈ អាចធ្វើឱ្យកម្មវិធីដែលមានការអនុញ្ញាតល្អពីមុនក្លាយជាកម្មវិធីដែលមានជម្លោះក្នុងពេលមួយយប់។

9. **សូមកត់ត្រាថាអ្នកណាទទួលបានអត្ថប្រយោជន៍ និងអ្នកណាចំណាយ ជាបញ្ជីពីរដាច់ដោយឡែកពីគ្នា។** ការអះអាងអំពីតម្លៃសាធារណៈរឹងមាំបំផុតនៅពេលអ្នកដឹកនាំអាចនិយាយយ៉ាងច្បាស់ថាអ្នកណាទទួលបាន និងអ្នកណាទទួលរងថ្លៃដើម ព្រោះក្រុមទាំងពីរកម្រដូចគ្នាក្នុងការងារវិស័យសាធារណៈ និងវិស័យសង្គម។

10. **សូមចាត់ទុកការអះអាងអំពីសមត្ថភាពប្រតិបត្តិការជាអ្វីដែលអាចសាកល្បងបាន មិនមែនជាសេចក្តីប្រាថ្នានោះទេ។** «យើងអាចផ្តល់ជូនវាបាន» គឺជាការអះអាងដែលអាចបដិសេធបានអំពីបុគ្គលិក ប្រព័ន្ធ និងភាពអាចទុកចិត្តបាននៃដៃគូ ហើយគួរត្រូវបានសាកល្បងធៀបនឹងប្រវត្តិនៃការផ្តល់ជូនលើការងារស្រដៀងគ្នា មុនពេលចូលក្នុងផែនការ។

## សំណួរសម្រាប់ពិភាក្សាជាមួយក្រុម

**តើអង្គការរបស់យើងនឹងឈប់ធ្វើអ្វី ប្រសិនបើគ្រប់កម្មវិធីត្រូវតែឆ្លងកាត់តេស្តទាំងបីនៃត្រីកោណយុទ្ធសាស្ត្រ?** អង្គការភាគច្រើនមានយ៉ាងហោចណាស់សកម្មភាពមួយដែលបន្តដោយសារនិច្ចភាព ជាជាងការអនុញ្ញាតសកម្ម តម្លៃដែលបានបង្ហាញ ឬសមត្ថភាពដែលបានបញ្ជាក់។ ជាធម្មតាវារស់រានមានជីវិតព្រោះគ្មានជ្រុងតែមួយនៃត្រីកោណត្រូវបានសាកល្បងលើវាដោយផ្ទាល់ ដូច្នេះភាពខ្សោយរបស់វាមិនដែលក្លាយជាបញ្ហាដែលនរណាម្នាក់ត្រូវដោះស្រាយដោយច្បាស់លាស់ឡើយ។ ការប្រកាសវាឱ្យឮៗគឺគួរឱ្យអាម៉ាស់ ដែលជាមូលហេតុពិតប្រាកដដែលវាសមនឹងធ្វើជាលំហាត់ក្រុម ជាជាងទុកឱ្យការវិនិច្ឆ័យរបស់បុគ្គលម្នាក់។ សូមប្រើសំណួរនេះដើម្បីលើកយកបេក្ខភាព មិនមែនដើម្បីសម្រេចចុងក្រោយក្នុងកិច្ចប្រជុំតែមួយនោះទេ — គោលបំណងគឺដើម្បីកត់សម្គាល់កន្លែងដែលតេស្តទាំងបីបានឈប់ត្រូវបានសួរដោយស្ងាត់ៗ។

**តើនរណាខ្លះជាក់លាក់បង្កើតបរិយាកាសផ្តល់សិទ្ធិរបស់យើងនៅពេលនេះ ហើយតើបញ្ជីនោះបានផ្លាស់ប្តូរក្នុងរយៈពេលពីរឆ្នាំចុងក្រោយនេះឬទេ?** ក្រុមជាច្រើនអាចដាក់ឈ្មោះខ្សែរាយការណ៍ជាផ្លូវការរបស់ខ្លួនបាន ប៉ុន្តែពិបាកដាក់ឈ្មោះអ្នកទាំងអស់ដែលការយល់ព្រមជាបន្តបន្ទាប់របស់ពួកគេពិតជាសំខាន់ — ថ្នាក់ដឹកនាំថ្មីរបស់អ្នកផ្តល់មូលនិធិ ក្រុមសហគមន៍ដែលបានក្លាយជាមានសំឡេងខ្លាំងជាងមុន អាជ្ញាធរបទប្បញ្ញត្តិដែលមានអំណាចថ្មី។ បញ្ជីដែលបង្កើតពីការចងចាំក្នុងកិច្ចប្រជុំផ្ទាល់ ជាជាងចម្លងពីឯកសារចាស់ ជាធម្មតាបង្ហាញគម្លាតលឿនជាងទាំងពីរ។ សូមសរសេរបញ្ជីចាប់ពីដំបូង ជាជាងយកកំណែឆ្នាំមុនមកប្រើ ព្រោះបរិយាកាសផ្តល់សិទ្ធិរសាត់ទៅដោយស្ងាត់ៗ ហើយការរសាត់នោះងាយមើលរំលងពីខាងក្នុងអង្គការ។ សូមប្រៀបធៀបបញ្ជីថ្មីជាមួយបញ្ជីណាមួយដែលបានប្រើ (ប្រសិនបើមាន) ក្នុងពេលសម្រេចចិត្តសំខាន់ចុងក្រោយ។

**តើយើងកំពុងជំនួសតម្លៃសាធារណៈដោយរង្វាស់ទីផ្សារនៅទីណា ហើយជំនួសវាដោយអាណត្តិនៅទីណា?** ក្រុមច្រើនតែងាកទៅរកហេតុផលណាដែលងាយបង្កើតបំផុត៖ ថ្លៃដើមក្នុងមួយឯកតា ប្រសិនបើមុខងារហិរញ្ញវត្ថុរឹងមាំ ឬការយោងទៅអាណត្តិស្ថាបនា ប្រសិនបើមិនរឹងមាំ។ ការជំនួសទាំងពីរមិនខុសក្នុងការលើកឡើងទេ ប៉ុន្តែនីមួយៗមិនពេញលេញដោយខ្លួនឯង ហើយការពឹងផ្អែកតែលើមួយក្នុងចំណោមវាធ្វើឱ្យពីរជ្រុងទៀតនៃត្រីកោណមិនត្រូវបានពិនិត្យ។ សូមប្រើសំណួរនេះដើម្បីរកកន្លែងដែលជ្រុងមួយនៃត្រីកោណកំពុងធ្វើការទាំងអស់ដែលគួរចែករំលែកក្នុងចំណោមបី។ សូមជ្រើសរើសកម្មវិធីបច្ចុប្បន្នមួយ ហើយសាកល្បងឆ្លើយសំណួរសំណើតម្លៃដោយមិនប្រើផ្លូវកាត់ទាំងពីរ។

**ប្រសិនបើមាននរណាម្នាក់ប្រជែងឱ្យយើងពន្យល់ហេតុផលនៃថវិការបស់យើងដោយមិននិយាយថា «ទីផ្សារចង់បានវា» ឬ «យើងត្រូវបានបោះឆ្នោត ឬផ្តល់មូលនិធិដើម្បីធ្វើវា» តើយើងនឹងនិយាយអ្វី?** សំណួរនេះបង្ខំឱ្យជ្រុងសំណើតម្លៃលេចចេញដោយឯករាជ្យពីភាពស្របច្បាប់ និងឯករាជ្យពីតម្លៃ។ ចម្លើយល្អដាក់ឈ្មោះលទ្ធផលជាក់ស្តែងសម្រាប់ក្រុមមនុស្សជាក់លាក់មួយ ចម្លើយខ្សោយនិយាយឡើងវិញពីអត្ថិភាពរបស់អង្គការថាជាហេតុផលរបស់ខ្លួនឯង។ ការហាត់ឆ្លើយតាមពាក្យរបស់ក្រុមផ្ទាល់ ជាជាងខ្ចីសេចក្តីថ្លែងបេសកកម្ម ច្រើនតែលាតត្រដាងគម្លាតបានលឿន។ សូមឱ្យអ្នកនីមួយៗក្នុងបន្ទប់ឆ្លើយដោយឡែកពីគ្នាមុនពេលប្រៀបធៀបកំណត់ត្រា ព្រោះស្គ្រីបរួមច្រើនតែលាក់ភាពមិនស្របគ្នា ដែលសេចក្តីថ្លែងបេសកកម្មដែលបានសរសេរមិនលាតត្រដាង។

**តើសកម្មភាពបច្ចុប្បន្នណាខ្លះរបស់យើងមានភាពស្របច្បាប់រឹងមាំ ប៉ុន្តែសមត្ថភាពផ្តល់ជូនខ្សោយ ឬផ្ទុយមកវិញ?** កម្មវិធីដែលមានការគាំទ្រនយោបាយ និងមូលនិធិ ប៉ុន្តែគ្មានផែនការផ្តល់ជូនជាក់ស្តែងនៅពីក្រោយ ឬក្រុមផ្តល់ជូនដែលមានសមត្ថភាពខ្ពស់ធ្វើការលើអ្វីមួយដែលគ្មាននរណានៅខាងក្រៅអង្គការបានអនុញ្ញាតពិតប្រាកដ គឺជាករណីទូទៅទាំងពីរ ហើយទាំងពីរមានហានិភ័យតាមរបៀបខុសគ្នា។ ការបរាជ័យទាំងពីរមិនអាចមើលឃើញពីជ្រុងតែមួយនៃត្រីកោណតែម្នាក់ឯងបានទេ ដែលជាមូលហេតុដែលវាត្រូវតែសួរជាការពិនិត្យឆ្លងដោយចេតនា ជាជាងទុកឱ្យវាលេចឡើងដោយខ្លួនឯង។ សូមផ្គូផ្គងសកម្មភាពបច្ចុប្បន្នមួយចំនួនតូចជាមួយសំណួរនេះដោយស្មោះត្រង់ ដោយប្រើភស្តុតាងនៃការផ្តល់ជូនថ្មីៗ ជាជាងទំនុកចិត្តតែម្យ៉ាង។ នៅកន្លែងដែលពីរជ្រុងទាញចេញពីគ្នាខ្លាំង សូមចាត់ទុកវាជាអាទិភាពសម្រាប់វដ្តរៀបចំផែនការបន្ទាប់ មិនមែនជាកំណត់សម្គាល់ត្រឹមបាតទំព័រនោះទេ។

**តើយើងដឹងដោយរបៀបណាថាតម្លៃដែលយើងជឿថាយើងបង្កើតគឺជាតម្លៃដែលអ្នកពាក់ព័ន្ធរបស់យើងទទួលស្គាល់ពិតប្រាកដ?** អង្គការអាចជឿជាក់ដោយស្មោះត្រង់លើសំណើតម្លៃរបស់ខ្លួន ខណៈដែលអ្នកដែលត្រូវទទួលអត្ថប្រយោជន៍ ឬអ្នកដែលត្រូវអនុញ្ញាតវា ឃើញអ្វីផ្សេង។ គម្លាតនោះកម្រប្រកាសខ្លួនណាស់ វាលេចឡើងក្រោយមកជាការគាំទ្រធ្លាក់ចុះ ជំនួយដែលបានបន្តមកជាមួយលក្ខខណ្ឌថ្មី ឬការដកខ្លួនដោយស្ងាត់ៗរបស់អ្នកដែលកម្មវិធីត្រូវបម្រើ។ សូមពិភាក្សាថាតើភស្តុតាងអ្វី — មតិកែលម្អផ្ទាល់ ការវាយតម្លៃឯករាជ្យ ទិន្នន័យពាក្យបណ្តឹង ការបន្តមូលនិធិ — នឹងប្រាប់អ្នកប្រសិនបើរឿងរ៉ាវខាងក្នុងរបស់អ្នក និងរឿងរ៉ាវរបស់អ្នកពាក់ព័ន្ធបានខុសគ្នាដោយស្ងាត់ៗ។ សូមឯកភាពជាក្រុមថាតើភស្តុតាងមួយណាដែលអ្នកនឹងទុកចិត្តគ្រប់គ្រាន់ដើម្បីផ្លាស់ប្តូរទិសដៅ។

## នៅក្នុងការអនុវត្ត៖ ឧទាហរណ៍តម្លៃសាធារណៈ

សូមពិចារណារដ្ឋាភិបាលទីក្រុងទំហំមធ្យមមួយដែលកំពុងពិចារណាថាតើត្រូវផ្តល់មូលនិធិដល់កម្មវិធីការងារយុវជនថ្មីពីថវិកាអាទិភាពដែលកំពុងថយចុះឬអត់។ នាយកដ្ឋានឧទ្យាន និងការកម្សាន្តបានស្នើកម្មវិធីនេះរយៈពេលបីឆ្នាំជាប់ៗគ្នា ជារៀងរាល់ដងត្រូវបានវិនិច្ឆ័យថាជាគំនិតល្អជាគោលការណ៍ ហើយទុកចោលដោយគ្មានមូលនិធិ ព្រោះគ្មាននរណាឆ្លើយរួមគ្នាថាតើវាមានការអនុញ្ញាត សមនឹងធ្វើ និងអាចផ្តល់ជូនបានឬទេ។

ឆ្នាំនេះ នាយិកានៃនាយកដ្ឋានធ្វើការឆ្លងកាត់ជ្រុងទាំងបីនៃត្រីកោណយុទ្ធសាស្ត្រ មុនពេលសរសេរសំណើសុំមូលនិធិ។ ចំពោះភាពស្របច្បាប់ នាងគូសផែនទីបរិយាកាសផ្តល់សិទ្ធិឱ្យបានត្រឹមត្រូវ៖ ក្រុមប្រឹក្សាក្រុងបានលើកឡើងពីភាពគ្មានការងារធ្វើរបស់យុវជនក្នុងបីនៃសម័យប្រជុំសាធារណៈបួនចុងក្រោយ សម្ព័ន្ធនិយោជកក្នុងតំបន់បានផ្តល់ជូនរួមចំណែកមូលនិធិសម្រាប់ការដាក់បណ្តុះបណ្តាល ហើយអង្គការសហគមន៍មួយបានស្នើសុំកម្មវិធីនេះពិតប្រាកដអស់រយៈពេលពីរឆ្នាំ — ជាករណីដែលមានឯកសារ មិនមែនជាករណីសន្មតទេ។

ចំពោះសំណើតម្លៃ នាងមិនបង្រួមករណីទៅជា «វានឹងបង្កើតការងារនៅរដូវក្តៅ 200 កន្លែង» ទេ ប៉ុន្តែបង្ហាញជំនួសថាតើការងារទាំងនោះមានបំណងផ្លាស់ប្តូរអ្វី៖ ចលនាលើភាពគ្មានការងារធ្វើរបស់យុវជនក្នុងស្រុកទាំងពីរដែលរងផលប៉ះពាល់បំផុត និងផ្លូវដ៏ជឿជាក់មួយចូលទៅក្នុងការជួលនៅកម្រិតចាប់ផ្តើមរបស់និយោជកផ្ទាល់។ នាងបញ្ជាក់ច្បាស់ថាតម្លៃនេះមួយចំណែកពិបាកបម្លែងជាថ្លៃប្រាក់ ហើយនឹងអាចមើលឃើញតែក្រោយពីរយៈពេលជាច្រើនឆ្នាំ ជាជាងបំប៉ោងលេខតែមួយដើម្បីធ្វើឱ្យករណីមើលទៅរៀបរយជាងការពិត។

ចំពោះសមត្ថភាពប្រតិបត្តិការ នាងសង្ស័យដោយចេតនាចំពោះសមត្ថភាពរបស់នាយកដ្ឋានក្នុងការផ្តល់ជូនតែម្នាក់ឯង។ នាយកដ្ឋានបានដំណើរការគម្រោងដាក់បណ្តុះបណ្តាលតូចៗបានយ៉ាងមានសមត្ថភាព ប៉ុន្តែមិនដែលគ្រប់គ្រងទំនាក់ទំនងនិយោជកក្នុងទំហំនេះទេ ខណៈដែលអង្គការសហគមន៍មានបទពិសោធទំនាក់ទំនងនោះ ប៉ុន្តែគ្មានហេដ្ឋារចនាសម្ព័ន្ធសម្រាប់ដាក់បណ្តុះបណ្តាលឡើយ។ ជំនួសឱ្យការសន្យាហួសកម្រិត នាងស្នើភាពជាដៃគូក្នុងការផ្តល់ជូន ហើយដាក់ឈ្មោះគម្លាតសមត្ថភាពដោយផ្ទាល់ក្នុងសំណើ។

ក្រុមប្រឹក្សាអនុម័តគម្រោងសាកល្បងរយៈពេលពីរឆ្នាំ តូចជាងអ្វីដែលបានស្នើដើម្បីដំបូង ដោយមានភាពជាដៃគូ និងចំណុចរាយការណ៍ច្បាស់លាស់ដាក់បញ្ចូលតាំងពីដំបូង — ជាការសម្រេចដែលអាចធ្វើបានមិនមែនដោយសារការថ្លែងបង្ហាញដែលរឹងមាំជាងនោះទេ ប៉ុន្តែដោយសារករណីដែលបានដាក់ឈ្មោះជ្រុងទាំងបីដោយស្មោះត្រង់ រួមទាំងកន្លែងដែលវាខ្សោយ។ សេណារីយ៉ូនេះគឺសម្រាប់ជាឧទាហរណ៍តែប៉ុណ្ណោះ វាមិនពិពណ៌នាអំពីទីក្រុង នាយកដ្ឋាន ឬកម្មវិធីណាមួយពិតប្រាកដឡើយ។

## ទស្សនៈវិស័យទាំងបួន

### រដ្ឋាភិបាលមូលដ្ឋាន

អាជ្ញាធរមូលដ្ឋានស្ថិតនៅជិតបំផុតនឹងពលរដ្ឋដែលទាំងអនុញ្ញាត និងទទួលសេវា ដែលធ្វើឱ្យជ្រុងភាពស្របច្បាប់មើលឃើញច្បាស់ និងផុយស្រួយខុសពីធម្មតា៖ កិច្ចប្រជុំសាធារណៈតែមួយដែលដោះស្រាយមិនបានល្អអាចផ្លាស់ប្តូរបរិយាកាសផ្តល់សិទ្ធិក្នុងពេលមួយយប់ តាមរបៀបដែលក្រសួងជាតិកម្រជួបប្រទះយ៉ាងមុតស្រួចបែបនេះ។ អ្នកដឹកនាំមូលដ្ឋានក៏មានគម្លាតសម្រាប់កំហុសប្រតិបត្តិការតូចបំផុត ព្រោះគម្លាតសមត្ថភាពលេចឡើងភ្លាមៗជាការបរាជ័យសេវាកម្មដែលមើលឃើញ ជាជាងការសម្រេចបានតិចតួចនៃគោលនយោបាយអរូបី។

### រដ្ឋាភិបាលជាតិ

រដ្ឋាភិបាលជាតិជាទូទៅមានអាណត្តិផ្លូវការស៊ីជម្រៅបំផុត និងមូលដ្ឋានធនធានទូលំទូលាយបំផុត ដែលធ្វើឱ្យមានការល្បួងឱ្យចាត់ទុកភាពស្របច្បាប់ថាត្រូវបានដោះស្រាយដោយការបោះឆ្នោតចុងក្រោយ ហើយផ្តោតស្ទើរតែទាំងស្រុងលើតម្លៃ និងសមត្ថភាព។ ការល្បួងនោះជាអន្ទាក់មួយ៖ អាណត្តិជាតិទូលំទូលាយ ព្រោះវាមិនត្រូវបានសរសេរដោយគិតដល់កម្មវិធីជាក់លាក់ណាមួយឡើយ ដូច្នេះករណីដែលអាចការពារបានសម្រាប់គំនិតផ្តួចផ្តើមជាក់លាក់មួយនៅតែត្រូវការតេស្តបីជ្រុងពេញលេញ ក្នុងទំហំដែលការបរាជ័យសមត្ថភាពអាចប៉ះពាល់មនុស្សរាប់លាននាក់ក្នុងពេលតែមួយ។

### វិស័យសង្គម និងវិស័យមិនស្វែងរកប្រាក់ចំណេញ

អ្នកដឹកនាំអង្គការមិនស្វែងរកប្រាក់ចំណេញ និង NGO ច្រើនតែមានសំណើតម្លៃច្បាស់លាស់បំផុតក្នុងចំណោមទស្សនៈទាំងបួន ដែលបង្ហាញក្នុងសេចក្តីថ្លែងបេសកកម្ម ប៉ុន្តែជាញឹកញាប់មានបរិយាកាសផ្តល់សិទ្ធិមិនសូវស្ថិរភាពបំផុត ព្រោះអ្នកផ្តល់មូលនិធិ ក្រុមប្រឹក្សា និងសហគមន៍អ្នកទទួលផលនីមួយៗអាចដកការគាំទ្រដោយឯករាជ្យ និងតាមកាលវិភាគខុសគ្នា (សូមមើល ប្រធានបទ 3.8 — ការគ្រប់គ្រងវិស័យសង្គម និងអង្គការមិនស្វែងរកប្រាក់ចំណេញ)។ ការខ្វះទាំងតម្លៃទីផ្សារ និងអាណត្តិបោះឆ្នោត ធ្វើឱ្យត្រីកោណយុទ្ធសាស្ត្រមានប្រយោជន៍ជាពិសេសនៅទីនេះ៖ វាផ្តល់ភាសាដល់ក្រុមប្រឹក្សាអង្គការមិនស្វែងរកប្រាក់ចំណេញសម្រាប់ការត្រួតពិនិត្យ ដែលមិនត្រូវបានខ្ចីដោយអសមស្របពីការអនុវត្តរបស់សាជីវកម្ម ឬរដ្ឋាភិបាល។

### កម្រិតពហុភាគី និងអន្តរជាតិ

ស្ថាប័នពហុភាគី និងអន្តរជាតិប្រតិបត្តិការដោយមានបរិយាកាសផ្តល់សិទ្ធិដែលបែងចែកក្នុងចំណោមរដ្ឋសមាជិកដែលមានផលប្រយោជន៍ខុសគ្នា ហើយជួនកាលប៉ះទង្គិចគ្នា ដែលធ្វើឱ្យភាពស្របច្បាប់ក្លាយជាបញ្ហានៃការទូតជាបន្តបន្ទាប់ ជាជាងអាណត្តិក្នុងស្រុកតែមួយ។ សមត្ថភាពប្រតិបត្តិការច្រើនតែត្រូវបានផ្តល់ជូនដោយប្រយោល តាមរយៈរដ្ឋាភិបាលជាតិ ឬ NGO មូលដ្ឋាន ជាជាងបុគ្គលិករបស់ស្ថាប័នផ្ទាល់ ដូច្នេះជ្រុងសមត្ថភាពត្រូវបានវាយតម្លៃឆ្លងកាត់ខ្សែសង្វាក់ផ្តល់ជូនទាំងមូល មិនមែនគ្រាន់តែលេខាធិការដ្ឋានដែលបានរចនាកម្មវិធីនោះទេ។

## ទម្រង់នៃការបរាជ័យដែលជួបញឹកញាប់

**ការត្រួតត្រាតម្លៃដោយគណនេយ្យថ្លៃដើម។** នៅពេលអង្គការមិនអាចវាស់សំណើតម្លៃរបស់ខ្លួនបានដោយងាយ វាងាយល្បួងឱ្យទុកអ្វីដែលងាយរាប់បំផុត — ថ្លៃដើមក្នុងមួយឯកតា បរិមាណដំណើរការ ពេលវេលាឆ្លើយតប — ឈរជំនួសតម្លៃផ្ទាល់។ នេះធ្វើឱ្យអង្គការខិតខំធ្វើឱ្យប្រសើរតែសូចនាករជំនួសដែលបានវាស់ ដោយចំណាយលទ្ធផលដែលវាមានបំណងតំណាង ហើយវាធ្វើឱ្យអង្គការបាត់បង់សមត្ថភាពក្នុងការកត់សម្គាល់ថា នៅពេលណាការផ្តល់ជូនប្រកបដោយប្រសិទ្ធភាពកំពុងផលិតអ្វីខុសបានយ៉ាងល្អ។

**ការចាប់យកភាពស្របច្បាប់។** បរិយាកាសផ្តល់សិទ្ធិអាចបង្រួមដោយស្ងាត់ៗទៅរកក្រុមណាដែលមានសំឡេងខ្លាំងបំផុត ឬមានការរៀបចំល្អបំផុត ខណៈដែលផលប្រយោជន៍សាធារណៈទូលំទូលាយជាងដែលអង្គការត្រូវបម្រើមិនត្រូវបានឮ។ នេះធ្វើឱ្យកម្មវិធីរសាត់ទៅរកចំណូលចិត្តរបស់ក្រុមដែលត្រូវបានចាប់យក ហើយវាធ្វើឱ្យអង្គការបាត់បង់ភាពស្របច្បាប់ទូលំទូលាយជាងរបស់ខ្លួន នៅពេលដែលផលប្រយោជន៍របស់ក្រុមនោះខុសពីអ្នកផ្សេងទាំងអស់។

**ការសម្តែងសមត្ថភាព។** អង្គការជួនកាលអះអាងសមត្ថភាពផ្តល់ជូនដែលខ្លួនមិនមាន ដោយពឹងផ្អែកលើសុទិដ្ឋិនិយម ឬការសន្យាដែលមិនទាន់បញ្ជាក់របស់ដៃគូ ជាជាងប្រវត្តិនៃការផ្តល់ជូន។ នេះធ្វើឱ្យមានការសន្យាដែលមិនអាចបំពេញបាន ហើយធ្វើឱ្យអង្គការបាត់បង់ភាពជឿជាក់ ដែលថ្លៃជាងច្រើនក្នុងការកសាងឡើងវិញ ជាងការផ្តល់មូលនិធិដល់កម្មវិធីដើមឱ្យបានត្រឹមត្រូវ។

**ការច្រលំអាណត្តិ។** ការចាត់ទុកលទ្ធផលបោះឆ្នោតតែមួយ លិខិតជំនួយ ឬច្បាប់ស្ថាបនាជាហេតុផលអចិន្ត្រៃយ៍ដែលបន្តដោយខ្លួនឯងសម្រាប់រាល់ការសម្រេចចិត្តបន្តបន្ទាប់ គឺច្រលំចំណុចពេលនៃភាពស្របច្បាប់ជាមួយភាពស្របច្បាប់ជាបន្តបន្ទាប់។ នេះធ្វើឱ្យអង្គការបន្តដំណើរការកម្មវិធីយូរក្រោយពេលកាលៈទេសៈដែលបានអនុញ្ញាតវាបានផ្លាស់ប្តូរ ហើយវាធ្វើឱ្យពួកគេបាត់បង់សមត្ថភាពក្នុងការកត់សម្គាល់ថានៅពេលណាការគាំទ្របានផុតកំណត់ដោយស្ងាត់ៗ។

**តម្លៃដោយបញ្ជាផ្តាច់ការ។** អ្នកដឹកនាំម្តងម្កាលប្រកាសថាកម្មវិធីមួយមានតម្លៃដោយអំណាចនៃជំនឿ ឬឋានន្តរសក្តិ ដោយមិនសាកល្បងភាពស្របច្បាប់ ឬសមត្ថភាពសោះ។ នេះធ្វើឱ្យអង្គការបាត់បង់វិន័យដែលត្រីកោណយុទ្ធសាស្ត្រមានដើម្បីផ្តល់ជូន៖ ការរកឃើញមុនពេលប្តេជ្ញា ជាជាងក្រោយពេលបរាជ័យ ថាជ្រុងមួយនៃករណីមិនដែលត្រូវបានពិនិត្យពិតប្រាកដ។

## បញ្ជីត្រួតពិនិត្យ

- [ ] សូមបញ្ជាក់សំណើតម្លៃសាធារណៈរបស់អង្គការអ្នកក្នុងប្រយោគតែមួយ។
- [ ] សូមរាយសមាជិកទាំងអស់នៃបរិយាកាសផ្តល់សិទ្ធិរបស់អ្នកតាមឈ្មោះ ឬតួនាទី មិនមែនគ្រាន់តែខ្សែរាយការណ៍ជាផ្លូវការនោះទេ។
- [ ] សូមបែងចែក «តើវាមានការអនុញ្ញាតឬទេ» «តើវាសមនឹងធ្វើឬទេ» និង «តើយើងអាចផ្តល់ជូនវាបានឬទេ» ជាចម្លើយបីដាច់ដោយឡែកពីគ្នាសម្រាប់កម្មវិធីសំខាន់ៗរបស់អ្នក។
- [ ] សូមកំណត់យ៉ាងហោចណាស់កន្លែងមួយដែលរង្វាស់ទីផ្សារ ឬការអះអាងអាណត្តិកំពុងឈរជំនួសករណីតម្លៃសាធារណៈពេញលេញ។
- [ ] សូមពិនិត្យការអះអាងអំពីសមត្ថភាពប្រតិបត្តិការធៀបនឹងប្រវត្តិនៃការផ្តល់ជូនពិតប្រាកដ មិនមែនសេចក្តីប្រាថ្នានោះទេ។
- [ ] សូមកត់ត្រាថាអ្នកណាទទួលអត្ថប្រយោជន៍ពីកម្មវិធីសំខាន់ៗនីមួយៗ និងអ្នកណាចំណាយសម្រាប់វា ជាបញ្ជីពីរដាច់ដោយឡែកពីគ្នា។
- [ ] សូមបញ្ជាក់ថាក្រុមរបស់អ្នកចែករំលែកវាក្យសព្ទរួមសម្រាប់ «តម្លៃសាធារណៈ» ឆ្លងកាត់នាយកដ្ឋាន ឬដៃគូផ្តល់ជូន។
- [ ] សូមកំណត់សកម្មភាពមួយដែលបន្តដោយសារនិច្ចភាព ជាជាងការអនុញ្ញាតសកម្ម តម្លៃដែលបានបង្ហាញ ឬសមត្ថភាពដែលបានបញ្ជាក់។
