# ប្រធានបទ 3.2 — គោលនយោបាយសាធារណៈ និងវដ្តគោលនយោបាយ

**គោលនយោបាយសាធារណៈកម្រត្រូវបានបង្កើតតាមលំដាប់រៀបរយដូចសៀវភៅសិក្សាពណ៌នាទេ គឺត្រូវបានបង្កើតតាមរយៈរង្វិលជុំ ការចាប់ផ្តើមខុស និងឱកាសបើកចំហភ្លាមៗ ហើយមេដឹកនាំដែលចាត់ទុកវដ្តគោលនយោបាយជាផែនទីនៃរបៀបដែលការសម្រេចចិត្តកើតឡើងពិតប្រាកដ ជាជាងជាបញ្ជីត្រួតពិនិត្យដើម្បីធ្វើឱ្យការសម្រេចចិត្តកើតឡើងបានល្អប្រសើរជាង នឹងមានការភ្ញាក់ផ្អើលម្តងហើយម្តងទៀតចំពោះអង្គការរបស់ខ្លួនផ្ទាល់។**

## ហេតុអ្វីបានជាបញ្ហានេះសំខាន់សម្រាប់តម្លៃសាធារណៈ

មេដឹកនាំសាធារណៈគ្រប់រូបទទួលមរតកនូវដំណើរការសម្រេចចិត្តមួយ ដែលមើលពីចម្ងាយ ហាក់ដូចជាបំពង់បង្ហូរសាមញ្ញមួយ គឺមានបញ្ហាមួយត្រូវបានកត់សម្គាល់ ជម្រើសត្រូវបានថ្លឹងថ្លែង ការសម្រេចចិត្តត្រូវបានធ្វើ ការសម្រេចចិត្តនោះត្រូវបានអនុវត្ត ហើយនរណាម្នាក់ពិនិត្យថាតើវាបានដំណើរការឬទេ។ ក្នុងការអនុវត្តជាក់ស្តែង បញ្ហាដែលត្រូវបានកត់សម្គាល់កម្រជាបញ្ហាធ្ងន់ធ្ងរបំផុតណាស់ ជម្រើសនៅលើតុកម្រជាសំណុំពេញលេញនៃអ្វីដែលមាន ហើយការសម្រេចចិត្តដែលត្រូវបានធ្វើជារឿយៗអាស្រ័យលើថារបៀបវារៈរបស់រដ្ឋមន្ត្រីណាមានចន្លោះទំនេរក្នុងសប្តាហ៍នោះ ដូចគ្នានឹងអាស្រ័យលើគុណសម្បត្តិនៃករណីដែរ។ ការយល់ដឹងពីមូលហេតុដែលកំណែរៀបរយគ្រាន់តែជាការសម្រួលហួសហេតុ និងកន្លែងដែលវាដួលរលំ មិនមែនជាភាពឆ្ងាញ់ឆ្ងល់ខាងសិក្សាទេ គឺជាអ្វីដែលអនុញ្ញាតឱ្យមេដឹកនាំស្គាល់ឱកាសពិតប្រាកដដើម្បីធ្វើសកម្មភាពនៅពេលវាលេចឡើង ជាជាងរង់ចាំដំណើរការដែលនឹងមិនមកដល់ក្នុងទម្រង់ដែលដ្យាក្រាមសន្យា។

ទ្រឹស្តីតម្លៃសាធារណៈចាត់ទុកភាពរញ៉េរញ៉ៃនេះជាឧបសគ្គនៃការរចនា មិនមែនជាការបរាជ័យដែលត្រូវលុបបំបាត់ដោយវិស្វកម្មនោះទេ។ ភាពស្របច្បាប់ និងការគាំទ្ររបស់គោលនយោបាយអាស្រ័យលើការដែលវាបានឆ្លងកាត់ដំណើរការមួយ ដែលអ្នកពាក់ព័ន្ធទទួលស្គាល់ថាយុត្តិធម៌ ទោះបីដំណើរការនោះមានជម្លោះ និងមិនមែនជាលំដាប់ត្រង់ក៏ដោយ (សូមមើល ប្រធានបទ 1.2 — ត្រីកោណយុទ្ធសាស្ត្រ៖ ភាពស្របច្បាប់ តម្លៃ និងសមត្ថភាព)។ សមត្ថភាពប្រតិបត្តិការរបស់គោលនយោបាយក្នុងការផ្តល់ផលអាស្រ័យលើជម្រើសដែលបានធ្វើនៅដំណាក់កាលរៀបចំ និងរចនាឧបករណ៍ យូរមុនការអនុវត្តចាប់ផ្តើម ដែលមានន័យថាមេដឹកនាំដែលចូលរួមតែនៅពេលគោលនយោបាយមកដល់តុរបស់ខ្លួនដើម្បីផ្តល់ផល បានបាត់បង់ឱកាសរួចទៅហើយក្នុងការជះឥទ្ធិពលថាតើវាអាចផ្តល់ផលបានឬអត់។ ការស្គាល់វដ្ត និងដែនកំណត់របស់វា គឺជារបៀបដែលមេដឹកនាំរកឃើញចំណុចដែលមានអានុភាពអតិបរមា ជាជាងមកដល់បន្ទាប់ពីការសម្រេចចិត្តសំខាន់ៗទាំងអស់ត្រូវបានធ្វើរួចទៅហើយ។

មូលហេតុមួយទៀតដែលបញ្ហានេះសំខាន់ឥឡូវនេះគឺថា បញ្ហាគោលនយោបាយកាន់តែមិនគោរពព្រំដែននៃឧបករណ៍តែមួយ។ វិធីសាស្ត្ររបស់ទីក្រុងមួយក្នុងការកាត់បន្ថយការកកស្ទះចរាចរណ៍ អាចរួមបញ្ចូលបទប្បញ្ញត្តិ ថ្លៃសេវា ឧបត្ថម្ភធនសម្រាប់ជម្រើសផ្សេង និងយុទ្ធនាការផ្សព្វផ្សាយព័ត៌មានសាធារណៈ ហើយការធ្វើឱ្យបានត្រឹមត្រូវនូវបន្សំនោះគឺជាជំនាញដាច់ដោយឡែកពីការធ្វើឱ្យឧបករណ៍មួយណាត្រឹមត្រូវដោយឡែក។ មេដឹកនាំដែលគិតតែពី "តើយើងត្រូវការច្បាប់អ្វី" ឬ "តើយើងគួរចំណាយប៉ុន្មាន" មើលរំលងការពិតថាគោលដៅគោលនយោបាយដដែលអាចសម្រេចបានជារឿយៗក្នុងតម្លៃថោកជាង ឬស្របច្បាប់ជាង តាមរយៈឧបករណ៍ផ្សេង ឬបន្សំផ្សេងទាំងស្រុង។

## គំនិតស្នូល

**វដ្តគោលនយោបាយ** គឺជាគំរូស្តាយលីសមួយអំពីរបៀបដែលការសម្រេចចិត្តសាធារណៈត្រូវបានធ្វើ ជាទូទៅចែកជាដំណាក់កាល៖ ការកំណត់របៀបវារៈ ការរៀបចំ ការអនុម័ត (ឬការផ្តល់ភាពស្របច្បាប់) ការអនុវត្ត និងការវាយតម្លៃ ដែលជារឿយៗបង្ហាញជារង្វិលជុំជាជាងបន្ទាត់ ព្រោះការវាយតម្លៃជាប្រចាំបើកឡើងវិញនូវរបៀបវារៈ (សូមមើល [គោលនយោបាយសាធារណៈ](https://en.wikipedia.org/wiki/Public_policy))។ តម្លៃរបស់វាគឺខាងការបង្រៀន គឺវាផ្តល់វាក្យសព្ទរួមសម្រាប់និយាយអំពីដំណើរការដែលមិនដូច្នោះនឹងត្រូវបានពណ៌នាតាមរបៀបច្រើនដូចចំនួនមនុស្សដែលពណ៌នា។ គ្រោះថ្នាក់របស់វាគឺថារង្វិលជុំដ៏រៀបរយនេះអញ្ជើញអ្នកអានឱ្យសន្មតថាការសម្រេចចិត្តពិតប្រាកដឆ្លងកាត់ដំណាក់កាលតាមលំដាប់ម្តងដោយស្អាតស្អំ ដែលកម្រកើតឡើង។

Lindblom](https://en.wikipedia.org/wiki/Charles_E._Lindblom))។ នេះមិនមែនជាយោបល់នៃការកំសាកទេ៖ Lindblom បានអះអាងថានិទ្ទេសនិយមជារឿយៗជាយុទ្ធសាស្ត្រដែលអាចការពារបានជាងក្រោមភាពមិនប្រាកដប្រជាពិតប្រាកដ មិនមែនគ្រាន់តែជាផ្លូវដែលមានភាពធន់តិចបំផុតទេ ទោះបីអ្នករិះគន់បានចង្អុលបង្ហាញជាយូរមកហើយថានិទ្ទេសនិយមសុទ្ធសាធក៏អាចបង្កប់ស្ថានភាពអាក្រក់ដែលមានស្រាប់ដោយមិនដែលសួរថាតើវិធីសាស្ត្រទាំងមូល មិនមែនគ្រាន់តែគែមរបស់វា ខុសឬអត់។

**គំរូធុងសំរាម** ដែលអភិវឌ្ឍដោយ Michael Cohen, James March និង Johan Olsen ដើម្បីពណ៌នាអំពីការសម្រេចចិត្តក្នុងអ្វីដែលពួកគេហៅថា "អនាធិបតេយ្យដែលមានការរៀបចំ" ទៅឆ្ងាយជាងនេះទៀត៖ វាបង្ហាញបញ្ហា ដំណោះស្រាយ អ្នកចូលរួម និងឱកាសជ្រើសរើស ជាលំហូរបួនដែលស្ទើរតែឯករាជ្យ អណ្តែតវិលវល់ជុំវិញអង្គការ ដោយការសម្រេចចិត្តកើតឡើងនៅពេលណាដែលឱកាសជ្រើសរើសមួយចៃដន្យនាំបីផ្សេងទៀតមកជួបគ្នា ជាជាងដំណោះស្រាយត្រូវបានរចនាដោយចេតនាសម្រាប់បញ្ហាជាក់លាក់មួយ (សូមមើល [គំរូធុងសំរាម](https://en.wikipedia.org/wiki/Garbage_can_model))។ ក្របខ័ណ្ឌលំហូរច្រើនរបស់ Kingdon គឺជាកូនចៅផ្ទាល់ដែលជាក់លាក់ចំពោះគោលនយោបាយនៃគំរូនេះ។ នៅពេលអានជាមួយគ្នា និទ្ទេសនិយម និងគំរូធុងសំរាមទាំងពីរអះអាងថាវដ្តដ៏រៀបរយ ដែលមានហេតុផលតាមលំដាប់ គឺនៅជិតរឿងនិទានផ្តល់ភាពស្របច្បាប់ដែលអង្គការប្រាប់អំពីការសម្រេចចិត្តរបស់ខ្លួនក្រោយពេលកើតហេតុ ជាជាងការពណ៌នាអំពីរបៀបដែលការសម្រេចចិត្តទាំងនោះត្រូវបានឈានដល់ពិតប្រាកដ ដែលខ្លួនវាផ្ទាល់មានប្រយោជន៍សម្រាប់មេដឹកនាំដឹង ព្រោះវាផ្លាស់ប្តូរទម្ងន់ដែលត្រូវដាក់លើ "ប៉ុន្តែនោះមិនមែនជារបៀបដែលផ្លូវលំហូរនិយាយថាវាគួរដំណើរការទេ" ជាការជំទាស់ចំពោះការសម្រេចចិត្តពិតប្រាកដ។

ពាក់កណ្តាលទីពីរនៃដែនសិក្សានៃប្រធានបទនេះគឺ**ឧបករណ៍គោលនយោបាយ**៖ ឧបករណ៍ជាក់លាក់ដែលប្រើដើម្បីបកប្រែគោលនយោបាយដែលត្រូវបានអនុម័តទៅជាឥទ្ធិពល។ អ្នកវិទ្យាសាស្ត្រនយោបាយអង់គ្លេស **Christopher Hood** បានផ្តល់ប្រភេទវិទ្យាដែលស្ថិតស្ថេរបំផុត ដោយបែងចែកឧបករណ៍តាមធនធានរបស់រដ្ឋាភិបាលដែលនីមួយៗទាញយក៖ **ចំណុចកណ្តាលព័ត៌មាន** (nodality) (ព័ត៌មាន និងទីតាំងរបស់រដ្ឋាភិបាលនៅចំកណ្តាលបណ្តាញ) **សិទ្ធិអំណាច** (ឥទ្ធិពលផ្លូវច្បាប់ដើម្បីតម្រូវ ហាមឃាត់ ឬអនុញ្ញាត) **ទ្រព្យ** (ប្រាក់ ទោះបីចំណាយ ឬប្រមូល) និង**អង្គការ** (បុគ្គលិក ដី និងសម្ភារៈរបស់រដ្ឋាភិបាលផ្ទាល់) ដែលជារឿយៗត្រូវបានកាត់ឈ្មោះដោយអក្សរដំបូងនៃធនធានទាំងបួន (សូមមើល [Christopher Hood](https://en.wikipedia.org/wiki/Christopher_Hood))។ សៀវភៅនេះដាក់ក្រុមប្រភេទរបស់ Hood ជាក្រុមគ្រួសារបួនដែលត្រូវនឹងរបៀបដែលមេដឹកនាំសាធារណៈភាគច្រើននិយាយអំពីការជ្រើសរើសឧបករណ៍ពិតប្រាកដ៖ **បទប្បញ្ញត្តិ** (សិទ្ធិអំណាច ដែលជាច្បាប់ដែលតម្រូវ ហាមឃាត់ ឬអនុញ្ញាតអាកប្បកិរិយាមួយ ដោយមានការអនុវត្តច្បាប់ជាខ្នងទ្រទ្រង់) (សូមមើល [បទប្បញ្ញត្តិ](https://en.wikipedia.org/wiki/Regulation)); **ការចំណាយ** រួមទាំងការផ្តល់ដោយផ្ទាល់ ជំនួយឥតសំណង និង**ឧបត្ថម្ភធន** ដែលបន្ថយថ្លៃដើមនៃអាកប្បកិរិយា ឬទំនិញដែលគេពេញចិត្ត (សូមមើល [ឧបត្ថម្ភធន](https://en.wikipedia.org/wiki/Subsidy)); **ពន្ធដារ** ដែលប្រមូលចំណូលប៉ុន្តែអាចត្រូវបានរចនាដើម្បីទប់ស្កាត់អាកប្បកិរិយាដូចគ្នា ដូចជា **ពន្ធលើទំនិញគ្រោះថ្នាក់** (sin tax) លើថ្នាំជក់ ស្រា ឬស្ករ (សូមមើល [ពន្ធលើទំនិញគ្រោះថ្នាក់](https://en.wikipedia.org/wiki/Sin_tax)); និង**ព័ត៌មាន ឬការបញ្ចុះបញ្ចូល** ចាប់ពីយុទ្ធនាការផ្សព្វផ្សាយការយល់ដឹងសាធារណៈ រហូតដល់បច្ចេកទេសអាកប្បកិរិយាដែលមានគោលដៅជាក់លាក់ជាងនៃ**ទ្រឹស្តីជំរុញ** (nudge theory) ដែលរចនាបរិយាកាសនៃការជ្រើសរើសឡើងវិញ ជាជាងបង្ខំ បង់ប្រាក់ ឬពន្យល់លទ្ធផលដែលគេពេញចិត្ត (សូមមើល [ទ្រឹស្តីជំរុញ](https://en.wikipedia.org/wiki/Nudge_theory); សូមមើល ប្រធានបទ 4.1 — គោលនយោបាយសាធារណៈផ្នែកអាកប្បកិរិយា សម្រាប់ក្រមសីលធម៌ និងយន្តការនៃក្រុមឧបករណ៍នេះយ៉ាងស៊ីជម្រៅ)។ គោលនយោបាយពិតប្រាកដស្ទើរតែតែងតែរួមបញ្ចូលឧបករណ៍ពីក្រុមច្រើនជាងមួយ ដូចជាថ្លៃថង់ប្លាស្ទិកគឺជាពន្ធ និងជាសញ្ញាព័ត៌មានក្នុងពេលតែមួយ ហើយការបង្ខំចាក់វ៉ាក់សាំងគឺជាបទប្បញ្ញត្តិដែលពង្រឹងដោយព័ត៌មានសាធារណៈ ហើយសំណួររចនាឧបករណ៍ពិតប្រាកដរបស់មេដឹកនាំកម្រជា "ឧបករណ៍តែមួយណា" ប៉ុន្តែជា "បន្សំអ្វី តាមលំដាប់អ្វី ក្នុងតម្លៃនៃភាពស្របច្បាប់ប៉ុន្មាន"។

## ការអនុវត្តល្អបំផុត

## សំណួរសម្រាប់ពិភាក្សាជាមួយក្រុម

**តើយើងពិតជាដឹងថាគំនិតផ្តួចផ្តើមសំខាន់ៗបច្ចុប្បន្នរបស់យើងស្ថិតនៅដំណាក់កាលណានៃវដ្ត ឬយើងកំពុងអនុវត្តសៀវភៅយុទ្ធសាស្ត្រតែមួយទៅលើទាំងអស់ដោយមិនគិតពីអ្វី?** សូមដើរកាត់គំនិតផ្តួចផ្តើមដែលកំពុងដំណើរការធំបំផុតបីឬបួនរបស់អ្នក ហើយដាក់នីមួយៗលើដំណាក់កាលកំណត់របៀបវារៈ រៀបចំ អនុម័ត អនុវត្ត ឬវាយតម្លៃ ដោយស្មោះត្រង់ ជាជាងតាមទីតាំងដែលតារាងរចនាសម្ព័ន្ធអង្គការនិយាយ។ សូមពិភាក្សាថាតើឧបករណ៍ និងកិច្ចប្រជុំដែលអ្នកកំពុងប្រើត្រូវនឹងដំណាក់កាលនោះឬអត់ ឬថាតើគំនិតផ្តួចផ្តើមដែលនៅតែតស៊ូដើម្បីទទួលបានការយកចិត្តទុកដាក់ កំពុងត្រូវបានចាត់ទុកដូចជាវាគ្រាន់តែត្រូវការផែនការផ្តល់ផលល្អជាងមុន។ សូមឯកភាពថាអ្វីនឹងផ្លាស់ប្តូរអំពីរបៀបផ្តល់ធនធានដល់គំនិតផ្តួចផ្តើមនីមួយៗ ប្រសិនបើការវាយតម្លៃដំណាក់កាលត្រឹមត្រូវ។

**តើដំណោះស្រាយរួចរាល់អ្វីខ្លះកំពុងស្ថិតក្នុងលំហូរគោលនយោបាយរបស់យើងឥឡូវនេះ រង់ចាំបង្អួចដែលយើងមិនបានតាមដាន?** សូមឱ្យក្រុមនីមួយៗដាក់ឈ្មោះជម្រើសមួយដែលពួកគេជឿថាត្រូវបានអភិវឌ្ឍយ៉ាងល្អ ប៉ុន្តែមិនដែលរកឃើញពេលវេលានយោបាយដើម្បីអនុម័ត។ សូមពិភាក្សាថាត្រូវមានអ្វីកើតឡើង ដូចជាព្រឹត្តិការណ៍មួយ ការផ្លាស់ប្តូរថ្នាក់ដឹកនាំ ឬការប្រែប្រួលអារម្មណ៍សាធារណជន ដើម្បីឱ្យបង្អួចនោះបើក ហើយតើជម្រើសនោះពិតជារួចរាល់ឬអត់ប្រសិនបើវាបើក។ សូមពិចារណាថាតើអង្គការមានការអនុវត្តអចិន្ត្រៃយ៍ណាមួយសម្រាប់រក្សាជម្រើសទាំងនោះឱ្យទាន់សម័យ ឬថាតើពួកវាហួសសម័យដោយស្ងាត់ស្ងៀមពេលរង់ចាំ។

**ពេលយើងរចនាគោលនយោបាយចុងក្រោយ តើយើងបានជ្រើសរើសឧបករណ៍មុន ហើយគោលដៅទីពីរឬទេ?** សូមតាមដានត្រឡប់ទៅការសម្រេចចិត្តថ្មីៗមួយ ហើយសួរដោយស្មោះត្រង់ថាតើ "យើងត្រូវការច្បាប់" ឬ "យើងត្រូវចំណាយបន្ថែម" ត្រូវបានសម្រេចមុនគោលដៅមូលដ្ឋាន និងឧបករណ៍ជំនួសត្រូវបានថ្លឹងថ្លែងបានត្រឹមត្រូវឬអត់។ សូមពិភាក្សាថាការសន្ទនាជ្រើសរើសឧបករណ៍ពិតប្រាកដនឹងមើលទៅដូចម្តេច ដោយប្រៀបធៀបបទប្បញ្ញត្តិ ការចំណាយ ពន្ធដារ និងព័ត៌មាន ទៅនឹងគោលដៅដូចគ្នា។ សូមឯកភាពលើជំហានស្តង់ដារក្នុងដំណើរការរចនាគោលនយោបាយរបស់អ្នក ដែលបង្ខំឱ្យមានការប្រៀបធៀបនេះមុនពេលការព្រាងចាប់ផ្តើម។

**តើការអនុវត្តបានរចនាគោលនយោបាយដែលយើងគិតថាបានសម្រេចរួចឡើងវិញដោយស្ងាត់ស្ងៀមនៅត្រង់ណា?** សូមកំណត់គោលនយោបាយដែលឥទ្ធិពលលើដីពិតខុសគ្នាគួរឱ្យកត់សម្គាល់ពីអ្វីដែលបានសរសេរ និងអនុម័ត ហើយពិភាក្សាថាឧត្តមានុភាពអ្វីដែលបុគ្គលិកជួរមុខប្រើដើម្បីបង្កើតចន្លោះនោះ។ សូមពិចារណាថាតើឧត្តមានុភាពនោះជាបញ្ហាដែលត្រូវបិទ ឬជាការសម្របខ្លួនសមហេតុផលដែលគោលនយោបាយផ្លូវការគួរត្រូវបានធ្វើបច្ចុប្បន្នភាពឱ្យឆ្លុះបញ្ចាំង។ សូមសម្រេចថានរណាទទួលខុសត្រូវក្នុងការកត់សម្គាល់ការរសាត់បែបនេះ និងក្នុងការសម្រេចចិត្តរាល់ពេលថាការឆ្លើយតបណាក្នុងចំណោមទាំងពីរគឺត្រឹមត្រូវ។

**តើយើងកំពុងចាត់ទុកការវាយតម្លៃជាមតិកែលម្អចូលរបៀបវារៈបន្ទាប់ ឬជារបាយការណ៍ដែលត្រូវបានរក្សាទុកនៅពេលកម្មវិធីបញ្ចប់?** សូមពិនិត្យមើលថាតើអ្វីបានកើតឡើងចំពោះលទ្ធផលនៃការវាយតម្លៃធំៗពីរចុងក្រោយរបស់អ្នក៖ តើវាបានផ្លាស់ប្តូរការសម្រេចចិត្តដែលកំពុងដំណើរការ ផ្តល់ព័ត៌មានដល់ជុំរៀបចំបន្ទាប់ ឬស្ថិតក្នុងឯកសារដែលគ្មាននរណាពិនិត្យឡើងវិញ (សូមមើល ប្រធានបទ 2.6 — ការសំយោគភស្តុតាង និងអ្វីដែលមានប្រសិទ្ធភាព)? សូមពិភាក្សាថាត្រូវផ្លាស់ប្តូរអ្វីខាងរចនាសម្ព័ន្ធ ដូចជាពេលវេលា ភាពជាម្ចាស់ វេទិកាអចិន្ត្រៃយ៍ ដើម្បីឱ្យការវាយតម្លៃបិទរង្វិលជុំពិតប្រាកដ ជាជាងគ្រាន់តែបិទឯកសារ។ សូមឯកភាពលើការផ្លាស់ប្តូរជាក់ស្តែងមួយដែលអ្នកនឹងធ្វើមុនការវាយតម្លៃបន្ទាប់ដល់កំណត់។

**តើវិធីសាស្ត្របច្ចុប្បន្នរបស់យើងក្នុងវិស័យគោលនយោបាយនេះជាយុទ្ធសាស្ត្រនិទ្ទេសនិយមដោយចេតនា ឬជាទម្លាប់ដែលមិនទាន់ត្រូវបានពិនិត្យ?** សូមជ្រើសរើសវិស័យគោលនយោបាយដែលអង្គការរបស់អ្នកបានកែសម្រួលបន្តិចបន្តួចឆ្នាំនេះឆ្នាំនោះ ដោយគ្មានការពិនិត្យឡើងវិញទូលំទូលាយ ហើយពិភាក្សាដោយស្មោះត្រង់ថាការអានណាមួយក្នុងចំណោមពីររបស់ Lindblom អនុវត្តបាន៖ ការប្រុងប្រយ័ត្នសមហេតុផលក្រោមភាពមិនប្រាកដប្រជាពិតប្រាកដ ឬលំនាំដើមស្រួលស្រូលដែលបានស្ងាត់ស្ងៀមលើសពីហេតុផលរបស់វា។ សូមពិចារណាថាការពិនិត្យឡើងវិញចាប់ពីគោលការណ៍ដំបូងពិតប្រាកដនឹងចំណាយពេលវេលា និងដើមទុននយោបាយប៉ុន្មាន ហើយថ្លឹងថ្លែងវាយ៉ាងច្បាស់លាស់ប្រឆាំងនឹងតម្លៃនៃការបន្តដើរទាំងងងឹត។ សូមសម្រេចថាតើការពិនិត្យនោះគួរស្ថិតនៅក្នុងរបៀបវារៈឆ្នាំក្រោយឬអត់។

## នៅក្នុងការអនុវត្ត៖ ឧទាហរណ៍តម្លៃសាធារណៈ

រដ្ឋាភិបាលទីក្រុងឆ្នេរមធ្យមមួយបានចំណាយពេលជាច្រើនឆ្នាំពិភាក្សាអំពីកាកសំណល់ប្លាស្ទិកប្រើតែម្តងលើឆ្នេរ និងផ្លូវទឹករបស់ខ្លួន ដោយមិនបានបង្កើតគោលនយោបាយផ្លូវការ។ ក្រុមបរិស្ថានបានលើកបញ្ហានេះនៅកិច្ចប្រជុំក្រុមប្រឹក្សាអស់ច្រើនឆ្នាំ។ ក្រមសុទ្ធចិត្តដែលសុំឱ្យអ្នកលក់រាយកាត់បន្ថយការចែកថង់ប្លាស្ទិក បានបង្កើតការធ្លាក់ចុះតែបន្តិចបន្តួច។ ហើយសំណើដែលព្រាងដោយការិយាល័យនិរន្តរភាពរបស់ទីក្រុង ដើម្បីរួមបញ្ចូលថ្លៃលក់រាយជាមួយយុទ្ធនាការផ្សព្វផ្សាយការយល់ដឹងសាធារណៈ បានស្ថិតនៅក្នុងថតអស់ជាង១ឆ្នាំ ទោះបីបានរៀបចំពេញលេញក៏ដោយ ដោយមិនអាចទាក់ទាញការយកចិត្តទុកដាក់ផ្នែកនយោបាយគ្រប់គ្រាន់ដើម្បីទៅដល់ការបោះឆ្នោត។

ស្ថានភាពបានផ្លាស់ប្តូរភ្លាមៗបន្ទាប់ពីរលកព្យុះធ្ងន់ធ្ងរមិនធម្មតាមួយបានជះសំណល់ប្លាស្ទិកក្នុងបរិមាណច្រើនមកលើឆ្នេរទេសចរណ៍ចម្បងរបស់ទីក្រុងពីរសប្តាហ៍មុនការចាប់ផ្តើមរដូវក្តៅ បង្កើតការផ្សាយតាមសារព័ត៌មានក្នុងតំបន់យ៉ាងទូលំទូលាយ និងការត្អូញត្អែរជាច្រើនដល់សមាជិកក្រុមប្រឹក្សាដែលជាប់ឆ្នោត។ សមាជិកក្រុមប្រឹក្សាដែលទើបជាប់ឆ្នោតថ្មី ដែលបានឃោសនាមួយផ្នែកលើបញ្ហាបរិស្ថាន បានឃើញពេលវេលានោះ ហើយរុញសំណើដែលមានស្រាប់របស់ការិយាល័យនិរន្តរភាពចូលរបៀបវារៈក្នុងរយៈពេលពីរបីថ្ងៃ ដោយភ្ជាប់លំហូរគោលនយោបាយដែលអសកម្មទៅនឹងលំហូរនយោបាយ និងបញ្ហាដែលទើបបើកថ្មី ស្ទើរតែយ៉ាងពិតប្រាកដដូចក្របខ័ណ្ឌរបស់ Kingdon ព្យាករណ៍។ សំណើដែលបានរង់ចាំការយកចិត្តទុកដាក់អស់មួយឆ្នាំ ត្រូវបានអនុម័តក្នុងរយៈពេលប្រាំមួយសប្តាហ៍ក្រោយព្យុះ មិនមែនព្រោះវាបានប្រសើរឡើងទេ ប៉ុន្តែព្រោះបង្អួចមួយបានបើក។

គោលនយោបាយដែលត្រូវបានអនុម័តបានរួមបញ្ចូលឧបករណ៍បួនដោយចេតនា ជាជាងពឹងផ្អែកលើឧបករណ៍តែមួយ។ បទប្បញ្ញត្តិមួយហាមឃាត់អ្នកលក់រាយមិនឱ្យផ្តល់ថង់ប្លាស្ទិកប្រើតែម្តងនៅចំណុចលក់ (សិទ្ធិអំណាច)។ ថ្លៃតិចតួចមួយត្រូវបានអនុវត្តចំពោះថង់ក្រដាស ឬថង់ដែលអាចធ្វើជីកំប៉ុស្តិ៍បានណាមួយដែលអតិថិជននៅតែចង់បាន (ទ្រព្យ ដែលដំណើរការជាការបង្អាក់ស្រាលបែបពន្ធលើទំនិញគ្រោះថ្នាក់ ជាជាងវិធានការចំណូល)។ ឧបត្ថម្ភធនមួយបានផ្តល់មូលនិធិសម្រាប់ថង់ប្រើឡើងវិញដោយឥតគិតថ្លៃដែលចែកចាយតាមមជ្ឈមណ្ឌលសហគមន៍នៅតំបន់ចំណូលទាបរបស់ទីក្រុង ដើម្បីការពារកុំឱ្យថ្លៃធ្លាក់លើអ្នករស់នៅដែលមានលទ្ធភាពស្រូបយកតិចបំផុតខ្លាំងជាងគេ។ យុទ្ធនាការផ្សព្វផ្សាយព័ត៌មានសាធារណៈមួយ ដែលបានអភិវឌ្ឍជាមួយក្រុមវិទ្យាសាស្ត្រអាកប្បកិរិយារបស់សាកលវិទ្យាល័យក្នុងតំបន់ បានរចនាសារជំរុញនៅកន្លែងគិតលុយឡើងវិញនៅអ្នកលក់រាយដែលចូលរួម ដូច្នេះការបដិសេធថង់ក្លាយជាជម្រើសលំនាំដើម ជាជាងអ្វីដែលអតិថិជនត្រូវស្នើដោយសកម្ម ដែលជាការជំរុញដាក់ជាស្រទាប់លើបទប្បញ្ញត្តិ និងថ្លៃ មិនមែនជាការជំនួសទាំងពីរនោះទេ។

ការអនុវត្តបានលើកឡើងនូវចន្លោះប្រហោងដែលការរចនាដើមមិនបានគ្រោងទុក៖ អ្នកត្រួតពិនិត្យផ្សារដែលទទួលខុសត្រូវក្នុងការអនុវត្តច្បាប់ហាមឃាត់លក់រាយ មានឧត្តមានុភាពលើរបៀបអនុវត្តវាយ៉ាងតឹងរ៉ឹងប៉ុណ្ណាចំពោះតូបតូចៗដែលគ្រួសារធ្វើនៅតំបន់ផ្សារចាស់របស់ទីក្រុង ហើយការអនុវត្តច្បាប់ដែលមិនផ្លូវការដំបូងប្រែប្រួលខ្លាំងពីអ្នកត្រួតពិនិត្យម្នាក់ទៅម្នាក់។ ជំនួសឱ្យការចាត់ទុកនេះជាការបរាជ័យនៃការអនុលោមដែលត្រូវផ្តន្ទាទោស ការិយាល័យនិរន្តរភាពបានធ្វើការជាមួយអ្នកត្រួតពិនិត្យដើម្បីធ្វើឱ្យវិធីសាស្ត្រតាមលំដាប់ទៅជាផ្លូវការ គឺការព្រមានមុន ការផាកពិន័យតែបន្ទាប់ពីការរំលោភម្តងហើយម្តងទៀត ដែលអ្នកត្រួតពិនិត្យបានអនុវត្តរួចហើយតាមរយៈការវិនិច្ឆ័យផ្ទាល់ខ្លួន។ គោលនយោបាយផ្លូវការត្រូវបានកែសម្រួលដើម្បីត្រូវនឹងការអនុវត្តដែលអ្នកអនុវត្តកម្រិតផ្លូវរបស់ខ្លួនបានរកឃើញថាអាចដំណើរការបាន។

ការវាយតម្លៃដប់ប្រាំបីខែក្រោយមកបានរកឃើញការថយចុះយ៉ាងសំខាន់នៃសំណល់ប្លាស្ទិកនៅឆ្នេរ ការថយចុះតូចជាងប៉ុន្តែពិតប្រាកដនៃការចែកថង់ប្រើតែម្តងសរុប និងឥទ្ធិពលចែកចាយដែលភាគច្រើនអព្យាក្រឹត នៅពេលគិតបញ្ចូលថង់ប្រើឡើងវិញដែលមានឧបត្ថម្ភធន។ ការវាយតម្លៃក៏បានចង្អុលបង្ហាញថាការយល់ដឹងអំពីថ្លៃថង់ក្រដាសបានរសាត់បាត់តាមពេលវេលា ធ្វើឱ្យឥទ្ធិពលអាកប្បកិរិយារបស់វាចុះខ្សោយ ហើយបានណែនាំឱ្យធ្វើឱ្យយុទ្ធនាការព័ត៌មានស្រស់ស្រាយឡើងវិញ ជាជាងសន្មតថាការចាប់ផ្តើមតែម្តងនឹងទ្រទ្រង់ខ្លួនឯងដោយគ្មានកំណត់ ដែលបានផ្តល់មតិកែលម្អដោយផ្ទាល់ចូលរបៀបវារៈសម្រាប់វដ្តថវិកាបន្ទាប់។ ឧទាហរណ៍នេះជារឿងប្រឌិតសម្រាប់បង្ហាញ មិនពណ៌នាអំពីគោលនយោបាយប្លាស្ទិក ឬការសម្រេចចិត្តរបស់ក្រុមប្រឹក្សាទីក្រុងពិតប្រាកដណាមួយឡើយ។

## ទស្សនៈវិស័យទាំងបួន

### រដ្ឋាភិបាលមូលដ្ឋាន

អាជ្ញាធរមូលដ្ឋានជាធម្មតាស្ថិតនៅជិតការអនុវត្តបំផុត ហេតុនេះឃើញចន្លោះប្រហោងរវាងគោលនយោបាយដែលបានអនុម័ត និងការពិតកម្រិតផ្លូវរបស់វាលឿនជាងកម្រិតរដ្ឋាភិបាលផ្សេងទៀត ប៉ុន្តែជាធម្មតាមានសំណុំឧបករណ៍តូចចង្អៀតបំផុតដើម្បីធ្វើការជាមួយ ព្រោះពន្ធដារធំៗ និងសិទ្ធិអំណាចបទប្បញ្ញត្តិជាច្រើនស្ថិតនៅជាមួយរដ្ឋាភិបាលជាតិ ឬតំបន់។ ជំនាញលក្ខណៈរបស់មូលដ្ឋានគឺការរួមបញ្ចូលសំណុំឧបករណ៍មានកំណត់ គឺបទប្បញ្ញត្តិមូលដ្ឋាន ថ្លៃ និងកម្រៃតិចតួច ការចំណាយដោយផ្ទាល់ និងព័ត៌មានដែលមានគោលដៅក្នុងមូលដ្ឋាន ដោយច្នៃប្រឌិតគ្រប់គ្រាន់ដើម្បីសម្រេចវឌ្ឍនភាពពិតប្រាកដលើបញ្ហាដែលអានុភាពធំបំផុតរបស់វាជាកម្មសិទ្ធិរបស់អ្នកដទៃ។

### រដ្ឋាភិបាលជាតិ

រដ្ឋាភិបាលជាតិជាធម្មតាកាន់សំណុំឧបករណ៍ទូលំទូលាយបំផុត រួមទាំងសមត្ថភាពក្នុងការបង្កើតច្បាប់ ប្រមូលពន្ធ និងចំណាយក្នុងមាត្រដ្ឋានធំ ដែលធ្វើឱ្យការរចនាបន្សំឧបករណ៍ក្លាយជាសិប្បកម្មជាតិពិតប្រាកដ ជាជាងការច្នៃប្រឌិតភ្លាមៗ។ ហានិភ័យជាតិលក្ខណៈគឺផ្ទុយពីហានិភ័យមូលដ្ឋាន៖ ដោយមានឧបករណ៍ទាំងអស់មានតាមបច្ចេកទេស ការរៀបចំគោលនយោបាយជាតិអាចរសាត់ទៅរកឧបករណ៍ធំបំផុត ឬអាចមើលឃើញច្បាស់បំផុត គឺច្បាប់ថ្មី ពន្ធដែលគេនិយាយដល់ ខណៈដែលបន្សំតូចជាង ថោកជាង នឹងសម្រេចតម្លៃសាធារណៈដូចគ្នាក្នុងតម្លៃទាបជាងនៃភាពស្របច្បាប់ និងហានិភ័យទាបជាងនៃឥទ្ធិពលមិនបានគ្រោងទុក។

### វិស័យសង្គម និងវិស័យមិនស្វែងរកប្រាក់ចំណេញ

អង្គការមិនស្វែងរកប្រាក់ចំណេញ និងអង្គការក្រៅរដ្ឋាភិបាលកម្រកាន់សិទ្ធិអំណាចឧបករណ៍គោលនយោបាយផ្លូវការដោយខ្លួនឯង ប៉ុន្តែពួកគេជារឿយៗជាសហគ្រិនគោលនយោបាយដែលភ្ជាប់ដំណោះស្រាយរួចរាល់ទៅនឹងបង្អួចនយោបាយដែលកំពុងបើក ហើយពួកគេជារឿយៗជាអង្គការដែលនៅជិតបំផុតនឹងរបៀបដែលគោលនយោបាយធ្លាក់ពិតប្រាកដលើមនុស្សដែលវាមានបំណងជួយ។ ការរួមចំណែកដាច់ដោយឡែករបស់ពួកគេចំពោះវដ្តគឺការកំណត់របៀបវារៈ និងមតិកែលម្អការអនុវត្ត៖ ការលើកកម្ពស់ភាពអាចមើលឃើញនៃបញ្ហាយូរមុនការយកចិត្តទុកដាក់របស់រដ្ឋាភិបាលមកដល់ និងការរាយការណ៍ដោយគួរឱ្យជឿជាក់ និងលឿន នៅពេលឥទ្ធិពលកម្រិតផ្លូវរបស់គោលនយោបាយខុសពីការរចនាដែលបានគ្រោងទុក (សូមមើល ប្រធានបទ 3.8 — ការគ្រប់គ្រងវិស័យសង្គម និងអង្គការមិនស្វែងរកប្រាក់ចំណេញ)។

### កម្រិតពហុភាគី និងអន្តរជាតិ

ស្ថាប័នពហុភាគី និងអន្តរជាតិកម្រកាន់សិទ្ធិអំណាចក្នុងស្រុកដែលចងភ្ជាប់ ពន្ធដារ ឬការចំណាយ ដូចរដ្ឋាភិបាលជាតិទេ ដូច្នេះឧបករណ៍លក្ខណៈរបស់ពួកគេគឺចំណុចកណ្តាលព័ត៌មាន និងអង្គការតាមន័យរបស់ Hood គឺការកោះប្រជុំ ការកំណត់ស្តង់ដារ ការបោះពុម្ពផ្សាយភស្តុតាងប្រៀបធៀប និងការសម្របសម្រួលមូលនិធិដែលរដ្ឋាភិបាលជាតិបន្ទាប់មកដាក់ឱ្យប្រើតាមរយៈបន្សំឧបករណ៍ផ្ទាល់ខ្លួន។ ដោយសារពួកគេដំណើរការឆ្លងកាត់យុត្តាធិការដែលមានសមត្ថភាពរដ្ឋបាលខុសគ្នាខ្លាំង ចន្លោះប្រហោងនៃការអនុវត្តរវាងក្របខ័ណ្ឌដែលត្រូវបានអនុម័តជាអន្តរជាតិ និងឥទ្ធិពលរបស់វានៅលើដី ជារឿយៗធំបំផុតក្នុងចំណោមកម្រិតណាមួយដែលគ្របដណ្តប់ក្នុងប្រធានបទនេះ ហើយដំណាក់កាលកំណត់របៀបវារៈ និងវាយតម្លៃនៃវដ្តជាធម្មតាសំខាន់ជាងការអនុម័ត ឬការអនុវត្តដោយផ្ទាល់សម្រាប់ការងាររបស់ពួកគេ។

## ទម្រង់នៃការបរាជ័យដែលជួបញឹកញាប់

**ការច្រឡំដ្យាក្រាមជាដំណើរការ។** ក្រុមមួយរចនាអភិបាលកិច្ចផ្ទៃក្នុងរបស់ខ្លួនដូចជារាល់ការសម្រេចចិត្តនឹងឆ្លងកាត់ការកំណត់របៀបវារៈ ការរៀបចំ ការអនុម័ត ការអនុវត្ត និងការវាយតម្លៃដោយស្អាតស្អំតាមលំដាប់តឹងរ៉ឹង ហើយបន្ទាប់មកចាត់ទុករាល់ការសម្រេចចិត្តពិតប្រាកដដែលមិនធ្វើតាមលំដាប់នោះជាភាពមិនប្រក្រតីដែលត្រូវការកែតម្រូវ ជាជាងជាការបង្កើតគោលនយោបាយធម្មតា។ នេះបង្កើតដំណើរការអភិបាលកិច្ចដែលធ្វើឱ្យបង្អួចឱកាសពិតប្រាកដដែលសហគ្រិនគោលនយោបាយត្រូវធ្វើសកម្មភាពយឺតជាង ដោយមិនធ្វើឱ្យការសម្រេចចិត្តចុងក្រោយមានព័ត៌មានល្អជាងឡើយ។

**ការរចនាឧបករណ៍ជាមុន។** បញ្ហាគោលនយោបាយមកដល់ដោយស្លៀកពាក់ជាឧបករណ៍ដែលគេពេញចិត្តរួចហើយ ដូចជា "យើងត្រូវការច្បាប់ថ្មី" ឬ "យើងត្រូវចំណាយបន្ថែម" ហើយដំណាក់កាលរៀបចំក្លាយជាការស្វែងរកហេតុផលបញ្ជាក់ ជាជាងការប្រៀបធៀបពិតប្រាកដនៃបទប្បញ្ញត្តិ ការចំណាយ ពន្ធដារ និងព័ត៌មានទៅនឹងគោលដៅ។ នេះធ្វើឱ្យអង្គការបាត់បង់បន្សំដែលថោកជាង បង្ខំតិចជាង ឬមានប្រសិទ្ធភាពជាង ដែលមិនដែលត្រូវបានពិចារណាយ៉ាងម៉ឺងម៉ាត់ ព្រោះឧបករណ៍ត្រូវបានជ្រើសរើសមុនការវិភាគចាប់ផ្តើម។

**ការរចនាសម្រាប់អ្នកអនុវត្តដ៏ល្អឥតខ្ចោះ។** គោលនយោបាយត្រូវបានរៀបចំជុំវិញការសន្មតថាជួរមុខអនុលោមពេញលេញ មានពេលវេលាបុគ្គលិកគ្រប់គ្រាន់ និងគ្មានអាទិភាពមូលដ្ឋានប្រកួតប្រជែង ដែលគ្មានអ្វីមួយឆ្លុះបញ្ចាំងពីការិយាធិបតេយ្យកម្រិតផ្លូវដែលនឹងផ្តល់វាពិតប្រាកដ។ ចន្លោះប្រហោងនៃការអនុវត្តដែលជាលទ្ធផលត្រូវបានស្តីបន្ទោសទៅបុគ្គលិកជួរមុខថា "មិនធ្វើតាមគោលនយោបាយឱ្យបានត្រឹមត្រូវ" ទោះបីមូលហេតុជ្រៅជាងនោះគឺការរចនាដែលមិនដែលសួរថាការអនុវត្តត្រូវការអ្វីពិតប្រាកដ។

**ការវាយតម្លៃជាចុងបញ្ចប់ ជាជាងរង្វិលជុំមតិកែលម្អ។** ការវាយតម្លៃត្រូវបានចាត់តាំង បញ្ចប់ និងរក្សាទុក ដោយគ្មានយន្តការអចិន្ត្រៃយ៍ភ្ជាប់លទ្ធផលរបស់វាត្រឡប់ទៅជុំបន្ទាប់នៃការកំណត់របៀបវារៈ ឬការរៀបចំ។ នេះថ្លៃទ្វេដង៖ ម្តងក្នុងថ្លៃនៃការវាយតម្លៃខ្លួនឯង និងម្តងទៀតក្នុងថ្លៃនៃវដ្តគោលនយោបាយបន្ទាប់ដែលរកឃើញម្តងទៀតពីដំបូងនូវមេរៀនដែលការវាយតម្លៃបានបង្កើតរួចហើយ។

**និទ្ទេសនិយមដែលបានរឹងទៅជាភាពអសកម្ម។** វិស័យគោលនយោបាយទទួលបានតែការកែសម្រួលបន្តិចបន្តួចឆ្នាំនេះឆ្នាំនោះ ព្រោះនោះជារបៀបដែលអង្គការតែងតែចូលទៅជិតវា មិនមែនព្រោះការប្រៀបធៀបពិតប្រាកដជាមួយការរចនាឡើងវិញដ៏ទូលំទូលាយជាងត្រូវបានធ្វើឡើងឡើយ។ ថ្លៃដើមមើលមិនឃើញរហូតដល់វិបត្តិ ឬបង្អួចគោលនយោបាយបង្ហាញថាផ្លូវនិទ្ទេសនិយមបានធ្លាក់ក្រោយវិធីសាស្ត្រដែលមានចេតនាជាងឆ្ងាយប៉ុណ្ណា។

**ការមិនអើពើនឹងបង្អួចនយោបាយដែលធ្វើឱ្យការសម្រេចចិត្តអាចទៅរួច។** អង្គការមួយចាត់ទុកគោលនយោបាយដែលបានអនុម័តដូចជាវាកើតពីគុណសម្បត្តិបច្ចេកទេសសុទ្ធសាធនៃសំណើ ដោយភ្លេចព្រឹត្តិការណ៍បង្ក សហគ្រិន ឬការតម្រឹមនយោបាយដែលធ្វើឱ្យការអនុម័តអាចទៅរួចពិតប្រាកដ។ នៅពេលបញ្ហាស្រដៀងគ្នាបន្ទាប់កើតឡើងដោយគ្មានការតម្រឹមដូចគ្នា អង្គការភ្ញាក់ផ្អើលដែលសំណើដែលបានរចនាល្អដូចគ្នាមិនត្រូវបានអនុម័ត ដោយបានច្រឡំការភ្ជាប់លំហូរដ៏សំណាងជាដំណើរការដែលអាចធ្វើឡើងវិញបាន។

## បញ្ជីត្រួតពិនិត្យ

- [ ] សូមកំណត់ដំណាក់កាលបច្ចុប្បន្ននៃគំនិតផ្តួចផ្តើមគោលនយោបាយនីមួយៗដែលកំពុងដំណើរការ (កំណត់របៀបវារៈ រៀបចំ អនុម័ត អនុវត្ត វាយតម្លៃ) ដោយស្មោះត្រង់។
- [ ] សូមរក្សាបញ្ជីខ្លីនៃជម្រើសគោលនយោបាយរួចរាល់ដែលបានស្រាវជ្រាវ ដោយឯករាជ្យពីបញ្ហាដែលកំពុងកើតឡើងណាមួយ។
- [ ] សូមកត់ត្រាការប្រៀបធៀបឧបករណ៍ (បទប្បញ្ញត្តិ ការចំណាយ ពន្ធដារ ព័ត៌មាន) មុនពេលការព្រាងចាប់ផ្តើម។
- [ ] សូមពិនិត្យឥទ្ធិពលចែកចាយនៃឧបករណ៍នីមួយៗក្នុងបន្សំដែលបានស្នើ មិនមែនគ្រាន់តែឥទ្ធិពលសរុបទេ។
- [ ] សូមវាយតម្លៃសមត្ថភាពផ្តល់សេវាជួរមុខ និងឧត្តមានុភាពដែលអាចកើតមាន មុនពេលគោលនយោបាយត្រូវបានធ្វើឱ្យចុងក្រោយ។
- [ ] សូមកំណត់ផែនការវាយតម្លៃ និងរង្វាស់ជោគជ័យនៅដំណាក់កាលរៀបចំ មិនមែនក្រោយការអនុម័តទេ។
- [ ] សូមបញ្ជាក់ថាមានផ្លូវដែលលទ្ធផលវាយតម្លៃ និងមតិកែលម្អការអនុវត្តទៅដល់ជុំកំណត់របៀបវារៈបន្ទាប់។
- [ ] សូមកត់ត្រាបង្អួចនយោបាយ ឬកាលៈទេសៈដែលអនុញ្ញាតឱ្យមានការអនុម័តថ្មីៗ ខណៈពេលដែលវានៅច្បាស់។
- [ ] សូមពិនិត្យជាប្រចាំលើវិស័យនៃការកែសម្រួលបន្តិចម្តងៗដែលបន្តយូរ ថាតើការរចនាឡើងវិញទូលំទូលាយមានភាពសមស្របឥឡូវនេះឬអត់។
- [ ] សូមពិនិត្យឧបករណ៍អាកប្បកិរិយា ឬផ្អែកលើព័ត៌មានធៀបនឹង ប្រធានបទ 4.1 — គោលនយោបាយសាធារណៈផ្នែកអាកប្បកិរិយា សម្រាប់ដែនកំណត់ខាងក្រមសីលធម៌ មុនពេលដាក់ឱ្យប្រើ។
- [ ] សូមបង្ហាញ និងវាយតម្លៃកញ្ចប់ឧបករណ៍រួមជាគោលនយោបាយសម្របសម្រួលតែមួយ មិនមែនជាគំនិតផ្តួចផ្តើមដែលមិនទាក់ទងគ្នាទេ។
