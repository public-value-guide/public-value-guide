# ប្រធានបទ 3.3 — ហិរញ្ញវត្ថុសាធារណៈ និងការធ្វើថវិកា

**ថវិកាមិនមែនជាការព្យាករណ៍អំពីអ្វីដែលអង្គការមានបំណងចំណាយទេ ប៉ុន្តែជាចំណុចដែលអាទិភាពសាធារណៈប្រកួតប្រជែងគ្នាត្រូវបានដាក់តាមលំដាប់ ធ្វើឱ្យមានអានុភាពអនុវត្តតាមច្បាប់ និងបើកចំហឱ្យមានការជំទាស់ ដូច្នេះរបៀបដែលថវិកាត្រូវបានបង្កើតកំណត់ភាពស្របច្បាប់របស់វា ក៏ដូចជាការគណនារបស់វាកំណត់ភាពត្រឹមត្រូវរបស់វាដែរ។**

## ហេតុអ្វីបានជាបញ្ហានេះសំខាន់សម្រាប់តម្លៃសាធារណៈ

នាយកហិរញ្ញវត្ថុគ្រប់រូបដែលបាននាំជុំចំណាយទៅកាន់គណៈរដ្ឋមន្ត្រី ក្រុមប្រឹក្សា ឬគណៈកម្មការ បានឃើញលំនាំដូចគ្នា៖ នាយកដ្ឋានមកដល់ជាមួយសំណូមពរច្រើនជាងអ្វីដែលស្រោមសំបុត្រអាចផ្ទុក ដែលនីមួយៗអាចការពារបានតាមលក្ខខណ្ឌរបស់ខ្លួន ហើយនរណាម្នាក់ត្រូវសម្រេចថាអ្នកណាចាញ់។ ការសម្រេចចិត្តនោះមិនមែនជាសំណល់បច្ចេកទេសដែលនៅសល់បន្ទាប់ពីគោលនយោបាយត្រូវបានកំណត់ទេ គឺជាកន្លែងដែលគោលនយោបាយក្លាយជាការពិត។ កម្មវិធីដែលមានតែក្នុងឯកសារយុទ្ធសាស្ត្រមិនបានទាមទារអ្វីពីនរណាទេ ប៉ុន្តែកម្មវិធីដែលមានបន្ទាត់ក្នុងថវិកាដែលបានអនុម័តបានទាមទារ ហើយបន្ទាត់នោះអាចត្រូវបានតាមដាន សវនកម្ម និងការពារ ឬវាយប្រហារ។

នេះក៏ជាកន្លែងដែលត្រីកោណយុទ្ធសាស្ត្រឈប់ជានិយាមអរូបី។ សំណើចំណាយអាចមានភាពស្របច្បាប់ និងការគាំទ្រខ្លាំង សំណើតម្លៃដ៏គួរឱ្យជឿជាក់ និងសមត្ថភាពប្រតិបត្តិការពិតប្រាកដ ហើយនៅតែចាញ់ក្នុងជុំថវិកាចំពោះសំណើដែលមានតិចជាងទាំងបីនោះ ប៉ុន្តែមានទីតាំងល្អជាងក្នុងប្រតិទិននយោបាយ (សូមមើល ប្រធានបទ 1.2 — ត្រីកោណយុទ្ធសាស្ត្រ៖ ភាពស្របច្បាប់ តម្លៃ និងសមត្ថភាព)។ ហិរញ្ញវត្ថុសាធារណៈ និងការធ្វើថវិកាគឺជាសង្វៀនដែលភាពមិនត្រូវគ្នានោះត្រូវបានកែតម្រូវ តាមរយៈដំណើរការមានវិន័យដែលសាកល្បងសំណូមពរតាមគុណសម្បត្តិរបស់វា ឬត្រូវបានបង្កប់ តាមរយៈដំណើរការដែលផ្តល់រង្វាន់ដល់អ្នកស្រែកខ្លាំងបំផុត ឬមកដល់មុនគេ។

ផលប៉ះពាល់បានកាន់តែខ្លាំងសម្រាប់ស្ទើរតែគ្រប់ប្រភេទអង្គការសាធារណៈ និងវិស័យសង្គម។ កំណើនយឺតជាង ថ្លៃដើមបង់បំណុលខ្ពស់ជាង ប្រជាជនចាស់ជរា និងថ្លៃដើមសម្របតាមអាកាសធាតុ បានធ្វើឱ្យស្រោមសំបុត្រចង្អៀតនៅក្នុងយុត្តាធិការភាគច្រើន ពិតជាពេលដែលពលរដ្ឋរំពឹងបានច្រើនពីវា ដូច្នេះគុណភាពនៃដំណើរការថវិកា មិនត្រឹមតែបរិមាណប្រាក់ក្នុងនោះទេ កាន់តែកំណត់ថាតើអង្គការនៅតែអាចបង្កើតតម្លៃសាធារណៈក្នុងលទ្ធភាពរបស់ខ្លួនឬអត់។ ការធ្វើឱ្យបានត្រឹមត្រូវមិនមែនជាការកត់ត្រាបញ្ជីដែលភ្ជាប់បន្ថែមលើការងារពិតប្រាកដនៃការគ្រប់គ្រងសាធារណៈទេ៖ ការយកពន្ធ និងការចំណាយខ្លួនឯងជាឧបករណ៍ដ៏មានអានុភាពបំផុតពីររបស់ស្ថាប័នសាធារណៈក្នុងការបង្កើតតម្លៃសាធារណៈ ហើយថវិកាគឺជាឯកសារដែលសម្រេចថាតើវាត្រូវបានប្រើយ៉ាងដូចម្តេច។

## គំនិតស្នូល

**ថវិកា** គឺជាផែនការមួយ ជាទូទៅគ្របដណ្តប់ឆ្នាំសារពើពន្ធមួយ ដែលកំណត់ចំណូលដែលរំពឹងទុក និងការចំណាយដែលបានអនុញ្ញាតសម្រាប់រដ្ឋាភិបាល ទីភ្នាក់ងារ ឬអង្គការ។ អត្ថបទ[ថវិការដ្ឋាភិបាល](https://en.wikipedia.org/wiki/Government_budget)នៅលើ Wikipedia ដាក់វាជាការព្យាករណ៍ដែលជាឧបករណ៍គោលនយោបាយផងដែរ ជាលក្ខណៈទ្វេដែលរត់កាត់ប្រធានបទនេះ។ **ហិរញ្ញវត្ថុសាធារណៈ** គឺជាផ្នែកទូលំទូលាយជាងដែលសិក្សាអំពីរបៀបដែលរដ្ឋាភិបាលប្រមូលចំណូល បែងចែកវា និងគ្រប់គ្រងបំណុល និងរបៀបដែលជម្រើសទាំងនោះប៉ះពាល់ដល់ស្ថិរភាព និងការចែកចាយទូទាំងសង្គម (សូមមើល [ហិរញ្ញវត្ថុសាធារណៈ](https://en.wikipedia.org/wiki/Public_finance))។ ប្រធានបទនេះផ្តោតលើយន្តការប្រតិបត្តិការតូចចង្អៀតជាង គឺដំណើរការថវិកាខ្លួនឯង។

**វដ្តថវិកា** មានដំណាក់កាលបួនដែលកើតឡើងម្តងហើយម្តងទៀត ហើយការបរាជ័យភាគច្រើនក្នុងហិរញ្ញវត្ថុសាធារណៈតាមដានត្រឡប់ទៅភាពខ្សោយក្នុងដំណាក់កាលជាក់លាក់មួយ ជាជាងប្រព័ន្ធទាំងមូល។ **ការរៀបចំ** គឺជាដំណាក់កាលស្ថាប័នប្រតិបត្តិ៖ ក្រសួងហិរញ្ញវត្ថុ ឬរតនាគារកំណត់ពិដានសារពើពន្ធ ស្ថាប័នចំណាយដេញថ្លៃប្រឆាំងនឹងវា ហើយស្ថាប័នប្រតិបត្តិចរចាសំណើក្នុងផ្ទៃក្នុងមុនពេលវាក្លាយជាសាធារណៈ។ **ការអនុម័ត** គឺជាដំណាក់កាលនីតិប្បញ្ញត្តិ៖ សំណើត្រូវបានត្រួតពិនិត្យ កែប្រែ និងអនុម័តជាច្បាប់ ជាទូទៅតាមរយៈ[វិក្កយបត្រចែកចាយថវិកា](https://en.wikipedia.org/wiki/Appropriation_bill) ដែលក្នុងប្រព័ន្ធភាគច្រើន បើគ្មានវាទេ ប្រាក់មិនអាចចាកចេញពីរតនាគារស្របច្បាប់បាន។ កន្លែងដែលស្ថាប័នតំណាងខកខានកាលកំណត់នេះ យុត្តាធិការជាច្រើនប្រើដំណោះស្រាយបន្តឬសមមូល ដើម្បីរក្សាការចំណាយឱ្យមានការអនុញ្ញាតនៅកម្រិតឆ្នាំមុន។ **ការប្រតិបត្តិ** គឺជាដំណាក់កាលដែលថវិកាដែលបានអនុម័តត្រូវបានចំណាយពិតប្រាកដ៖ មូលនិធិត្រូវបានបញ្ចេញ ការប្តេជ្ញាចិត្តត្រូវបានតាមដានធៀបនឹងដែនកំណត់ដែលបានអនុញ្ញាត ហើយការកែសម្រួលក្នុងឆ្នាំត្រូវបានធ្វើនៅពេលកាលៈទេសៈផ្លាស់ប្តូរ។ **សវនកម្ម** បិទវដ្ត ដោយពិនិត្យថាតើប្រាក់ត្រូវបានចំណាយតាមដែលបានអនុញ្ញាត ហើយកាន់តែច្រើនឡើង ថាតើវាសម្រេចបានអ្វីដែលបានសន្យា។ ប្រធានបទនេះចាត់ទុកសវនកម្មត្រឹមជាដំណាក់កាលបិទ ព្រោះស្ថាបត្យកម្មគណនេយ្យភាពជុំវិញវាគឺជាដែនមូលដ្ឋាននៃ ប្រធានបទ 3.4 — គណនេយ្យភាព តម្លាភាព និងភាពស្របច្បាប់ (សូមមើល ប្រធានបទ 3.4 — គណនេយ្យភាព តម្លាភាព និងភាពស្របច្បាប់)។

**វិន័យសារពើពន្ធ** គឺជាឧបសគ្គជាលេខលើសរុបថវិកា ដែលកំណត់ក្នុងច្បាប់ រដ្ឋធម្មនុញ្ញ ឬគោលនយោបាយចងភ្ជាប់ ដែលមានបំណងការពារទំនោរចំពោះឱនភាពជាប់លាប់ គឺទំនោរដែលបានកត់ត្រាយ៉ាងល្អរបស់រដ្ឋាភិបាលក្នុងការចំណាយច្រើនជាងអ្វីដែលខ្លួនប្រមូលបាន ជាពិសេសក្នុងឆ្នាំបោះឆ្នោត។ នាយកដ្ឋានកិច្ចការសារពើពន្ធរបស់មូលនិធិរូបិយវត្ថុអន្តរជាតិ (IMF) បែងចែកវិន័យសារពើពន្ធជាប្រភេទធំៗបួន៖ វិន័យតុល្យភាពថវិកាដែលតម្រូវឱ្យមាន[ថវិកាមានតុល្យភាព](https://en.wikipedia.org/wiki/Balanced_budget) ឬកំណត់ឱនភាព វិន័យបំណុលដែលកំណត់ពិដាន[បំណុលរដ្ឋាភិបាល](https://en.wikipedia.org/wiki/Government_debt) ដែលជារឿយៗបង្ហាញជា[សមាមាត្របំណុលទៅផលិតផលក្នុងស្រុកសរុប](https://en.wikipedia.org/wiki/Debt-to-GDP_ratio) (ផលិតផលក្នុងស្រុកសរុប ឬ GDP ជារង្វាស់ស្តង់ដារនៃលទ្ធផលសេដ្ឋកិច្ចសរុបរបស់ប្រទេសមួយ) វិន័យចំណាយដែលកំណត់ពិដានកំណើនការចំណាយ និងវិន័យចំណូលដែលគ្រប់គ្រងចំណូលហួសការរំពឹងទុក ឬខ្វះខាត។ យុត្តាធិការខ្លះបង្កប់តម្រូវការថវិកាមានតុល្យភាពដោយផ្ទាល់ក្នុងច្បាប់រដ្ឋធម្មនុញ្ញ ដែលជា "វិសោធនកម្មថវិកាមានតុល្យភាព" តាមពាក្យដែលប្រើនៅកន្លែងដែលរឿងនេះត្រូវបានពិភាក្សាជាសាធារណៈបំផុត ខណៈដែលខ្លះទៀតពឹងផ្អែកលើច្បាប់ធម្មតា ឬការប្តេជ្ញាចិត្តនយោបាយ។

**ការដោះដូរនៅក្នុងវិន័យសារពើពន្ធនីមួយៗ** គឺរវាងភាពជឿជាក់ និងភាពបត់បែន។ វិន័យរឹងងាយអនុវត្តជាង ហើយពិបាករំលោភជាង ដែលជាមូលហេតុដែលវាធ្វើឱ្យអ្នកឱ្យខ្ចី និងអ្នកបង់ពន្ធជឿជាក់ថាបំណុលនឹងមិនកើនឡើងកាត់ទប់មិនបាន។ ប៉ុន្តែវិន័យដែលបង្ខំឱ្យកាត់បន្ថយ ឬបង្កើនពន្ធពិតជាពេលសេដ្ឋកិច្ចខ្សោយ ធ្វើឱ្យគោលនយោបាយសារពើពន្ធ**តាមវដ្តសេដ្ឋកិច្ច** (procyclical) ដែលពង្រឹងវដ្តអាជីវកម្ម ជាជាងប្រឆាំងវដ្ត ដែលជាលំនាំដែលគេពេញចិត្តជាទូទៅសម្រាប់[ស្ថិរភាពម៉ាក្រូសេដ្ឋកិច្ច](https://en.wikipedia.org/wiki/Procyclical_and_countercyclical_variables)។ ដំណោះស្រាយធម្មតាគឺ**លក្ខខណ្ឌលើកលែង**ដែលបានកំណត់ទុកជាមុន៖ លក្ខខណ្ឌដែលបានបញ្ជាក់ ដូចជាវិបត្តិសេដ្ឋកិច្ច ឬអាសន្នដែលបានប្រកាស ដែលក្រោមនោះវិន័យត្រូវបានផ្អាកជាផ្លូវការជាជាងមិនអើពើដោយស្ងាត់ស្ងៀម ដូច្នេះភាពបត់បែនរស់រានមានជីវិតដោយមិនបំផ្លាញភាពជឿជាក់សម្រាប់ការប៉ះទង្គិចបន្ទាប់។

**ក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យម (MTEF)** ភ្ជាប់ថវិកាឆ្នាំតែមួយទៅនឹងផែនការសារពើពន្ធច្រើនឆ្នាំរំកិល ជាធម្មតាបីទៅប្រាំឆ្នាំ ដូច្នេះការសម្រេចចិត្តឆ្នាំនេះត្រូវបានធ្វើដោយមើលឃើញផលវិបាករបស់វាក្នុងឆ្នាំបន្តបន្ទាប់។ ក្នុងទម្រង់ស្តង់ដារ MTEF រួមបញ្ចូលស្រោមសំបុត្រធនធានពីលើចុះក្រោម គឺអ្វីដែលរដ្ឋអាចចំណាយបានដោយសមហេតុផល ដោយផ្អែកលើវិន័យសារពើពន្ធ និងការព្យាករណ៍ចំណូលរបស់ខ្លួន ជាមួយការគិតថ្លៃពីក្រោមឡើងលើនៃការប្តេជ្ញាចិត្តបច្ចុប្បន្ន ដោយផ្សះផ្សាទាំងពីរមុនពេលបែងចែកចន្លោះទំនេរទៅអាទិភាពថ្មី។ អាហ្វ្រិកខាងត្បូងបានណែនាំ MTEF ដំបូងគេមួយដែលអភិវឌ្ឍដោយឯករាជ្យពីសម្ពាធអ្នកផ្តល់ជំនួយ ក្នុងថវិកាឆ្នាំ 1998 របស់ខ្លួន ហើយធនាគារពិភពលោកបានបញ្ចូលវិធីសាស្ត្រនេះក្នុងការណែនាំហិរញ្ញវត្ថុសាធារណៈស្តង់ដាររបស់ខ្លួនសម្រាប់រដ្ឋាភិបាលជាទូទៅក្រោយមក។ បើគ្មានវា ថវិកាអាចអនុម័តកម្មវិធីដែលមិនអាចទទួលបានក្នុងឆ្នាំទីបីនៃការប្តេជ្ញាចិត្តប្រាំឆ្នាំ ព្រោះគ្មានអ្វីក្នុងដំណើរការត្រូវបានរចនាដើម្បីកត់សម្គាល់។

**ការធ្វើថវិកាបន្តិចម្តងៗ** យកការបែងចែកឆ្នាំមុនជាចំណុចចាប់ផ្តើម ហើយចរចាតែទំហំនៃការផ្លាស់ប្តូរ ជាជាងបញ្ជាក់មូលដ្ឋានឡើងវិញ។ [និទ្ទេសនិយម](https://en.wikipedia.org/wiki/Incrementalism)ត្រូវបានកត់ត្រាយ៉ាងល្អក្នុងការធ្វើថវិកាសាធារណៈ ព្រោះវាថោកខាងរដ្ឋបាល និងគ្រប់គ្រងបានខាងនយោបាយ គឺកម្មវិធីដែលបានបង្កើតរាល់មួយមានអ្នកការពារ ហើយការចរចាតែគែមជៀសវាងការបើកការប្រយុទ្ធគ្រប់យ៉ាងឡើងវិញរៀងរាល់ឆ្នាំ ប៉ុន្តែវាក៏អនុញ្ញាតឱ្យកម្មវិធីហួសសម័យ នៅពេលបង្កប់ក្នុងមូលដ្ឋានហើយ រស់រានមានជីវិតដោយគ្មានកំណត់ ព្រោះគ្មានផ្នែកណាមួយនៃដំណើរការសួរថាតើវាគួរមានទាល់តែសោះឬអត់។

**ការធ្វើថវិកាចាប់ពីសូន្យ** ឆ្លើយតបនឹងភាពខ្សោយនោះ ដោយតម្រូវឱ្យគ្រប់កម្មវិធី តាមគោលការណ៍ បញ្ជាក់ពីការផ្តល់មូលនិធិពេញលេញរបស់ខ្លួនចាប់ពីមូលដ្ឋានសូន្យរៀងរាល់វដ្ត ជាជាងត្រឹមតែការកើនឡើងរបស់វា។ ត្រូវបានអភិវឌ្ឍជាបច្ចេកទេសគ្រប់គ្រងក្នុងទសវត្សរ៍ឆ្នាំ 1970 (សូមមើល [ការធ្វើថវិកាចាប់ពីសូន្យ](https://en.wikipedia.org/wiki/Zero-based_budgeting)) វាមានអានុភាព ប៉ុន្តែថ្លៃក្នុងការដំណើរការឱ្យបានត្រឹមត្រូវលើថវិកាទាំងមូលរៀងរាល់ឆ្នាំ ដូច្នេះអង្គការភាគច្រើនដែលប្រើវាយ៉ាងម៉ឺងម៉ាត់អនុវត្តវាដោយជ្រើសរើស ទៅលើវិស័យមួយតាមវេនគ្នា ជាជាងលើអ្វីៗទាំងអស់ក្នុងពេលតែមួយ។

**ការធ្វើថវិកាតាមកម្មវិធី និងតាមសមិទ្ធកម្ម** ចាត់ថ្នាក់ការចំណាយតាមអ្វីដែលវាមានបំណងសម្រេច គឺកម្មវិធី ឬលទ្ធផល ជាជាងត្រឹមតែតាមតារាងគណនីតាមធាតុបន្ទាត់បែបប្រពៃណី (ប្រាក់ខែ សម្ភារៈ មូលធន)។ [ការធ្វើថវិកាផ្អែកលើសមិទ្ធកម្ម](https://en.wikipedia.org/wiki/Performance-based_budgeting) ភ្ជាប់កម្រិតមូលនិធិ យ៉ាងហោចណាស់តាមន័យ ទៅនឹងលទ្ធផលដែលរំពឹងទុក ឬសម្រេចបាន ដោយផ្លាស់ប្តូរការសន្ទនាពី "តើនេះចំណាយប៉ុន្មាន" មក "តើនេះទិញបានអ្វី" ទោះបីតំណរវាងទិន្នន័យសមិទ្ធកម្ម និងការសម្រេចចិត្តបែងចែកជាក់ស្តែងជារឿយៗរលុងជាងស្លាកបញ្ជាក់ ហើយអាចបង្កើតបញ្ហាការលើកទឹកចិត្តបង្ខូចដែល ប្រធានបទ 3.11 — ការគ្រប់គ្រងគុណភាព សុវត្ថិភាព និងសមិទ្ធកម្ម ពិនិត្យយ៉ាងស៊ីជម្រៅ (សូមមើល ប្រធានបទ 3.11 — ការគ្រប់គ្រងគុណភាព សុវត្ថិភាព និងសមិទ្ធកម្ម)។

**ពន្ធ និងការចំណាយជាឧបករណ៍ មិនមែនគ្រាន់តែជាធាតុគណនេយ្យ** គឺជាក្របខ័ណ្ឌដែលប្រធានបទនេះទទូចពេញមួយប្រធានបទ។ [គោលនយោបាយសារពើពន្ធ](https://en.wikipedia.org/wiki/Fiscal_policy) ចាត់ទុកទាំងសងខាងនៃថវិកាជាដងថ្លឹងសកម្ម៖ ឥណទានពន្ធសម្រាប់ការថែទាំកុមារ និងកម្មវិធីចំណាយដោយផ្ទាល់សម្រាប់ការថែទាំកុមារ អាចស្វែងរកគោលដៅតម្លៃសាធារណៈដូចគ្នាតាមរយៈឧបករណ៍ផ្សេងគ្នា ហើយដំណើរការថវិកាដែលមានសមត្ថភាពប្រៀបធៀបពួកវាតាមមូលដ្ឋាននោះ ជាជាងចាត់ទុកពន្ធជាផ្ទៃខាងក្រោយថេរនៃការសម្រេចចិត្តចំណាយ។ **ការចំណាយឱនភាព** ដែលការចំណាយលើសចំណូលក្នុងរយៈពេលមួយ គឺជាដងថ្លឹងមួយបែបនោះ ជាជាងគ្រាន់តែជាការបរាជ័យនៃវិន័យ។ ការជជែកដែលពិតប្រាកដ ដែលឆ្លុះបញ្ចាំងក្នុងអត្ថបទ Wikipedia អំពី[ការចំណាយឱនភាព](https://en.wikipedia.org/wiki/Deficit_spending) គឺអំពីពេលណា និងប៉ុន្មានដែលសមស្រប មិនមែនថាតើវាតែងតែខុសឬអត់។

## ការអនុវត្តល្អបំផុត

1. **សូមកំណត់ពិដានរយៈពេលមធ្យមមុនការប្រយុទ្ធបែងចែកចាប់ផ្តើម។** សូមឯកភាពលើស្រោមសំបុត្រធនធានពីលើចុះក្រោម ធៀបនឹងវិន័យសារពើពន្ធ និងការព្យាករណ៍ចំណូលជាមុនសិន ដើម្បីឱ្យនាយកដ្ឋានចរចាចំណែកនៃចំនួនសរុបដែលស្គាល់ ជាជាងចាត់ទុកចំនួនសរុបខ្លួនឯងជាអ្វីដែលអាចចរចាបាន។
2. **សូមសរសេរលក្ខខណ្ឌលើកលែងពិតប្រាកដចូលក្នុងវិន័យសារពើពន្ធនីមួយៗ មុនពេលត្រូវការ។** វិន័យដែលត្រូវបានផ្អាកដោយមិនផ្លូវការក្នុងវិបត្តិ ដោយគ្មានកត្តាបង្កដែលបានឯកភាពជាមុន បំផ្លាញភាពជឿជាក់ច្រើនជាងវិន័យដែលមានការលើកលែងច្បាស់លាស់ តូចចង្អៀត និងបានចែងជាមុន។
3. **សូមគិតថ្លៃការប្តេជ្ញាចិត្តគោលនយោបាយថ្មីក្នុងរយៈពេលមធ្យមពេញលេញ មិនមែនត្រឹមតែឆ្នាំដំបូងទេ។** សំណើដែលមើលទៅអាចទទួលបានក្នុងឆ្នាំទីមួយ និងមិនអាចទទួលបានក្នុងឆ្នាំទីបី គួរតែអាចមើលឃើញថាបែបនោះមុនការអនុម័ត មិនមែនរកឃើញក្នុងវដ្តបន្ទាប់ទេ។
4. **សូមតម្រូវឱ្យមានករណីសេដ្ឋកិច្ចសម្រាប់ការចំណាយថ្មីសំខាន់ៗ ដែលកសាងតាមវិន័យដូចគ្នានឹងករណីអាជីវកម្មមូលធន។** សូមបញ្ជូនកម្មវិធីថ្មីសំខាន់ៗតាមវិធីសាស្ត្រវាយតម្លៃដែល ប្រធានបទ 2.5 — ករណីអាជីវកម្ម និងតម្លៃសមស្របនឹងថវិកា ចែងទុក ដើម្បីឱ្យសំណើចំណាយ និងសំណើវិនិយោគប្រឈមនឹងការត្រួតពិនិត្យប្រៀបធៀបបាន (សូមមើល ប្រធានបទ 2.5 — ករណីអាជីវកម្ម និងតម្លៃសមស្របនឹងថវិកា)។
5. **សូមចាត់ថ្នាក់ការចំណាយតាមកម្មវិធី និងលទ្ធផលជាមួយតារាងគណនីតាមធាតុបន្ទាត់បែបប្រពៃណី។** សូមរក្សាចំណាត់ថ្នាក់គណនេយ្យសម្រាប់ការត្រួតពិនិត្យ និងសវនកម្ម ប៉ុន្តែបន្ថែមទិដ្ឋភាពកម្មវិធី ដើម្បីឱ្យអ្នកសម្រេចចិត្តឃើញថាការបែងចែកមួយមានបំណងសម្រេចអ្វី មិនត្រឹមតែអ្វីដែលវានឹងត្រូវចំណាយទៅលើនោះទេ។
6. **សូមធ្វើការពិនិត្យចាប់ពីសូន្យពិតប្រាកដលើវិស័យចំណាយសំខាន់យ៉ាងតិចមួយរៀងរាល់វដ្ត តាមវេនគ្នា។** ការពិនិត្យអ្វីៗទាំងអស់ពីសូន្យរៀងរាល់ឆ្នាំកម្រមានលទ្ធភាព។ ការមិនពិនិត្យអ្វីពីសូន្យសោះ មិនដែល អនុញ្ញាតឱ្យកម្មវិធីហួសសម័យរស់រានដោយសារភាពអសកម្មតែម្យ៉ាង។
7. **សូមផ្តល់ភាពបត់បែនក្នុងឆ្នាំពិតប្រាកដដល់អ្នកកាន់ថវិកាក្នុងដែនកំណត់ច្បាស់លាស់។** ការផ្ទេរមូលនិធិសមហេតុផល គឺសិទ្ធិផ្លាស់ប្តូរមូលនិធិរវាងបន្ទាត់ថវិកាដោយមិនត្រូវការការចែកចាយថ្មី អនុញ្ញាតឱ្យអ្នកគ្រប់គ្រងឆ្លើយតបនឹងលក្ខខណ្ឌផ្លាស់ប្តូរ ដោយមិនរំលោភការគ្រប់គ្រងរបស់នីតិប្បញ្ញត្តិលើចំនួនសរុប។
8. **សូមតាមដានការប្រតិបត្តិធៀបនឹងថវិកាដែលបានអនុម័តជារៀងរាល់ខែ មិនត្រឹមតែនៅចុងឆ្នាំទេ។** ចន្លោះធំរវាងអ្វីដែលបានអនុម័ត និងអ្វីដែលបានចំណាយពិតប្រាកដ ដែលរកឃើញតែក្នុងសវនកម្ម គឺជាការបរាជ័យអភិបាលកិច្ចដែលការរាយការណ៍ប្រចាំខែក្នុងឆ្នាំនឹងចាប់បានទាន់ពេលដើម្បីកែតម្រូវ។
9. **សូមតម្រឹមការប៉ាន់ស្មានចំណាយពន្ធជាមួយចំនួនសរុបនៃការចំណាយដោយផ្ទាល់ ក្នុងឯកសារតែមួយ។** ការបន្ធូរបន្ថយពន្ធដែលកាត់បន្ថយចំណូលចំនួនដូចគ្នានឹងថ្លៃកម្មវិធីចំណាយមួយ គឺជាការសម្រេចចិត្តចំណាយតាមខ្លឹមសារ។ ការបោះពុម្ពផ្សាយវាដោយឡែកលាក់ទំហំពិតប្រាកដរបស់វាពីការត្រួតពិនិត្យ។
10. **សូមផ្សះផ្សាលទ្ធផលជាក់ស្តែងធៀបនឹងថវិកាដើមដែលបានអនុម័ត ហើយបោះពុម្ពផ្សាយភាពខុសគ្នា។** ចន្លោះដែលបានបោះពុម្ពផ្សាយ និងពន្យល់រវាងអ្វីដែលបានអនុម័ត និងអ្វីដែលបានចំណាយ គឺជាវិន័យមានប្រយោជន៍បំផុតតែមួយសម្រាប់ធ្វើឱ្យការរៀបចំឆ្នាំក្រោយប្រសើរឡើង។

## សំណួរសម្រាប់ពិភាក្សាជាមួយក្រុម

**តើដំណើរការរបស់យើងកំណត់ស្រោមសំបុត្រសរុបមុនពេលនាយកដ្ឋានប្រកួតប្រជែងគ្នាដើម្បីចំណែករបស់វា ឬថាតើផលបូកនៃការដេញថ្លៃរបស់នាយកដ្ឋានក្លាយជាស្រោមសំបុត្រដោយប្រសិទ្ធភាព?** ដំណើរការថវិកាជាច្រើនអះអាងថាធ្វើការពីលើចុះក្រោម ប៉ុន្តែដំណើរការពីក្រោមឡើងលើ ព្រោះក្រសួងហិរញ្ញវត្ថុខ្វះទម្ងន់នយោបាយដើម្បីរក្សាពិដានប្រឆាំងនឹងការដេញថ្លៃដែលមានការតាំងចិត្ត។ ប្រសិនបើស្រោមសំបុត្រមានរន្ធ វិន័យសារពើពន្ធនៅពីក្រោយវាក៏មានរន្ធដែរ ទោះបីមើលទៅរឹងមាំលើក្រដាសក៏ដោយ។ សូមប្រើសំណួរនេះដើម្បីតាមដានអ្វីដែលបានកើតឡើងពិតប្រាកដចំពោះពិដានក្នុងវដ្តពីរចុងក្រោយ៖ តើវាត្រូវបានរក្សា ឬបានផ្លាស់ប្តូរដើម្បីសម្របតាមការដេញថ្លៃដែលមកដល់។ សូមពិភាក្សាថាត្រូវផ្លាស់ប្តូរអ្វី ខាងនយោបាយច្រើនដូចខាងបច្ចេកទេស ដើម្បីឱ្យវារក្សាបានលើកក្រោយ។

**តើអ្វីនឹងបង្កឱ្យលក្ខខណ្ឌលើកលែងនៃវិន័យសារពើពន្ធរបស់យើង ហើយនរណាមានសិទ្ធិអំណាចក្នុងការអំពាវនាវវា?** វិន័យដែលគ្មានកត្តាបង្កដែលបានចែង មានទំនោរត្រូវបានផ្អាកដោយមិនផ្លូវការក្រោមសម្ពាធ ដែលធ្វើឱ្យវាបាត់បង់ភាពជឿជាក់សម្រាប់វិបត្តិបន្ទាប់ ទោះបីការផ្អាកខ្លួនឯងសមហេតុផលក៏ដោយ។ សូមប្រើសំណួរនេះដើម្បីរកពាក្យពិតប្រាកដ ប្រសិនបើមាន ហើយសាកល្បងវាជាមួយការប៉ះទង្គិចដែលអាចកើតមាននាពេលខ្លីខាងមុខ គឺវិបត្តិសេដ្ឋកិច្ច គ្រោះមហន្តរាយធម្មជាតិ ឬការខ្វះខាតចំណូលភ្លាមៗ។ សូមពិភាក្សាថាតើកត្តាបង្កជាក់លាក់គ្រប់គ្រាន់ដើម្បីអំពាវនាវបានលឿន និងតូចចង្អៀតគ្រប់គ្រាន់មិនឱ្យក្លាយជាចន្លោះប្រហោងអចិន្ត្រៃយ៍ ហើយថាតើនរណាមានសិទ្ធិអំណាចទាញវាបច្ចុប្បន្ន។

**តើថវិកាឆ្នាំនេះប៉ុន្មានជាហេតុផលថ្មីពិតប្រាកដ ហើយប៉ុន្មានជាមូលដ្ឋានឆ្នាំមុនដែលយកមកបន្ត?** ការធ្វើថវិកាបន្តិចម្តងៗមិនមែនជាការបរាជ័យដោយស្វ័យប្រវត្តិទេ គឺមានប្រសិទ្ធភាពខាងរដ្ឋបាល ហើយជារបៀបដែលអង្គការភាគច្រើនធ្វើការពិតប្រាកដភាគច្រើនពេលវេលា ប៉ុន្តែថវិកាដែលស្ទើរតែទាំងស្រុងជាមូលដ្ឋានបូកការកើនឡើងតិចតួច មិនបានសាកល្បងការចំណាយភាគច្រើនរបស់ខ្លួនធៀបនឹងអាទិភាពបច្ចុប្បន្នអស់ច្រើនឆ្នាំ។ សូមប្រើសំណួរនេះដើម្បីប៉ាន់ប្រមាណ ទោះបីប្រហាក់ប្រហែល ថាភាគរយណានៃថវិកាបច្ចុប្បន្នត្រូវបានបើកឡើងវិញយ៉ាងសំខាន់ក្នុងវដ្តនេះធៀបនឹងត្រូវបានរំកិលទៅមុខ។ សូមពិភាក្សាថាកម្មវិធីណាមិនទាន់មានការសាកល្បងការកំណត់អាទិភាពឡើងវិញពិតប្រាកដយូរបំផុត ហើយថាតើនោះជាជម្រើសដោយចេតនា ឬជាចៃដន្យនៃការរចនាដំណើរការ។

**តើផ្នែកសេដ្ឋកិច្ចនៃករណីអាជីវកម្មធ្លាក់ទៅឯណាក្នុងការសម្រេចចិត្តថវិការបស់យើង ហើយតើដំណើរការថវិកាធ្លាប់បដិសេធវាឬទេ?** ករណីសេដ្ឋកិច្ចម៉ត់ចត់ ដែលកសាងតាមរបៀបដែល ប្រធានបទ 2.5 — ករណីអាជីវកម្ម និងតម្លៃសមស្របនឹងថវិកា ពណ៌នា នៅតែអាចចាញ់សំណើដែលមានការវិភាគខ្សោយជាង ប៉ុន្តែមានការគាំទ្រនយោបាយខ្លាំងជាង ហើយនោះពេលខ្លះជាលទ្ធផលត្រឹមត្រូវ ហើយពេលខ្លះជាសញ្ញាថាដំណើរការថវិកាមិនពិតជាប្រើការវិភាគដែលខ្លួនបានបញ្ជាទេ។ សូមប្រើសំណួរនេះដើម្បីរកករណីថ្មីៗដែលចំណាត់ថ្នាក់សេដ្ឋកិច្ច និងការសម្រេចចិត្តផ្តល់មូលនិធិខុសគ្នា ហើយកំណត់មូលហេតុ។ សូមពិភាក្សាថាតើភាពខុសគ្នានោះត្រូវបានធ្វើឱ្យច្បាស់ និងអាចការពារបាននៅពេលនោះ ឬគ្រាន់តែត្រូវបានស្រូបយកដោយគ្មានមតិយោបល់។

**ប្រសិនបើសមាជិកសភា សមាជិកក្រុមប្រឹក្សា ឬពលរដ្ឋសួរថាតើការចំណាយរបស់កម្មវិធីជាក់លាក់មួយប្រៀបធៀបនឹងអ្វីដែលវាបានផ្តល់យ៉ាងដូចម្តេច តើយើងអាចឆ្លើយក្នុងរយៈពេលប៉ុន្មានថ្ងៃ ដោយប្រើទិន្នន័យពីឆ្នាំថវិកានេះ មិនមែនសវនកម្មឆ្នាំមុនទេ?** ទិន្នន័យប្រតិបត្តិដែលអាចមើលឃើញតែនៅចុងឆ្នាំ តាមរយៈវដ្តសវនកម្មដែល ប្រធានបទ 3.4 — គណនេយ្យភាព តម្លាភាព និងភាពស្របច្បាប់ ពិនិត្យ មកដល់យឺតពេលពេកដើម្បីផ្លាស់ប្តូរអ្វីអំពីឆ្នាំដែលវាពណ៌នា។ សូមប្រើសំណួរនេះដើម្បីសាកល្បងថាតើទិន្នន័យចំណាយ និងសមិទ្ធកម្មក្នុងឆ្នាំរបស់អង្គការថ្មីប៉ុណ្ណា ក្នុងការអនុវត្ត មិនមែនក្នុងគោលនយោបាយ។ សូមពិភាក្សាថាត្រូវមានអ្វីដើម្បីឱ្យប្រព័ន្ធហិរញ្ញវត្ថុ និងរបាយការណ៍សមិទ្ធកម្មអាចផ្តល់ចម្លើយនោះក្នុងរយៈពេលប៉ុន្មានថ្ងៃ ជាជាងប៉ុន្មានខែ។

**តើយើងយល់អំពីគន្លងសារពើពន្ធរយៈពេលមធ្យមរបស់យើងគ្រប់គ្រាន់ ដើម្បីឱ្យការសម្រេចចិត្តឆ្នាំនេះមិនបិទជម្រើសឆ្នាំក្រោយដោយស្ងាត់ស្ងៀមឬ?** ការប្តេជ្ញាចិត្តដែលអាចទទួលបានឆ្នាំនេះ នៅតែអាចប្រើប្រាស់ចន្លោះទំនេរឆ្នាំក្រោយច្រើនពេក ដល់កម្រិតលុបបំបាត់ជម្រើសមុនពេលមាននរណាសម្រេចយ៉ាងច្បាស់លាស់ថាលុបបំបាត់។ សូមប្រើសំណួរនេះដើម្បីមើលការគិតថ្លៃច្រើនឆ្នាំ ប្រសិនបើមាន សម្រាប់ការប្តេជ្ញាចិត្តធំបំផុតពីរឬបីក្នុងថវិកាបច្ចុប្បន្ន។ សូមពិភាក្សាថាតើមាននរណាក្នុងបន្ទប់ថ្ងៃនេះនឹងធ្វើការសម្រេចចិត្តដូចគ្នាដោយដឹងថ្លៃដើមរយៈពេលមធ្យមពេញលេញនៅពេលនោះឬអត់ ហើយប្រសិនបើការគិតថ្លៃច្រើនឆ្នាំមិនមាន សូមពិភាក្សាថាត្រូវការអ្វីដើម្បីកសាងវា។

## នៅក្នុងការអនុវត្ត៖ ឧទាហរណ៍តម្លៃសាធារណៈ

នាយកដ្ឋានហិរញ្ញវត្ថុរបស់ទីក្រុងឆ្នេរមធ្យមមួយ ដែលជារឿងប្រឌិតសម្រាប់បង្ហាញលំនាំដែលកើតឡើងម្តងហើយម្តងទៀត មិនមែនជារបាយការណ៍អំពីក្រុងពិតប្រាកដណាមួយទេ បានប្រឈមនឹងបញ្ហារចនាសម្ព័ន្ធមួយនៅពេលចូលដល់វដ្តថវិកាប្រចាំឆ្នាំរបស់ខ្លួន៖ ចំណូលពន្ធអចលនទ្រព្យ ដែលជាប្រភពធំបំផុតរបស់ទីក្រុង បានកើនឡើងយឺតជាងថ្លៃដើមអស់បីឆ្នាំជាប់គ្នា ខណៈដែលវិន័យថវិកាមានតុល្យភាពកម្រិតរដ្ឋបានហាមឃាត់ទីក្រុងមិនឱ្យយកឱនភាពទៅឆ្នាំសារពើពន្ធបន្ទាប់។ ទីក្រុងបានអនុម័តក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យមបីឆ្នាំពីរវដ្តមុន ដែលមានន័យថាការខ្វះខាតអាចមើលឃើញយូរមុនវាក្លាយជាវិបត្តិ ជាជាងរកឃើញក្នុងអំឡុងពេលរៀបចំខ្លួនឯង។

ដំណើរការរៀបចំរបស់ស្ថាប័នប្រតិបត្តិបានចាប់ផ្តើមជាមួយជម្រើសដ៏ធ្ងន់ធ្ងរមួយ៖ រក្សាវិន័យថវិកាមានតុល្យភាពដោយកាត់បន្ថយការចំណាយតាមឆន្ទានុសិទ្ធិគ្រប់ផ្នែក ឬអំពាវនាវលក្ខខណ្ឌលើកលែងតូចចង្អៀតនៃវិន័យ ដែលមានតែសម្រាប់អាសន្នសារពើពន្ធដែលរដ្ឋប្រកាស ហើយទីក្រុងមិនធ្លាប់ប្រើពីមុន និងដំណើរការឱនភាពមានកម្រិតមួយឆ្នាំ ខណៈរៀបចំរចនាសម្ព័ន្ធថ្លៃដើមឡើងវិញ។ ការកាត់បន្ថយគ្រប់ផ្នែកងាយខាងរដ្ឋបាល ប៉ុន្តែក្រុមរបស់នាយកហិរញ្ញវត្ថុបានធ្វើគំរូឥទ្ធិពលរបស់វាលើកម្មវិធីពីរ៖ ផ្លូវដឹកជញ្ជូនមានឧបត្ថម្ភធនបម្រើតំបន់ចំណូលទាបដែលមានម្ចាស់រថយន្តតិច និងការដំឡើងប្រព័ន្ធបង្ហូរទឹកភ្លៀងដែលយឺតពីរឆ្នាំរួចហើយ បន្ទាប់ពីជុំកាត់បន្ថយឯកសណ្ឋានបែបនេះពិតប្រាកដកាលពីមុន។

ជំនួសឱ្យការធ្វើម្តងទៀតនូវវិធីសាស្ត្រកាត់បន្ថយឯកសណ្ឋាន ទីក្រុងបានធ្វើការពិនិត្យចាប់ពីសូន្យលើផលប័ត្រដឹកជញ្ជូន និងហេដ្ឋារចនាសម្ព័ន្ធរបស់ខ្លួន ដែលជាលំហាត់ចាប់ពីសូន្យពិតប្រាកដលើកដំបូងរបស់ខ្លួន ខណៈដែលក្រុមដាច់ដោយឡែកមួយបានកសាងករណីសេដ្ឋកិច្ចសម្រាប់ការដំឡើងប្រព័ន្ធបង្ហូរទឹកភ្លៀងតាមវិន័យដូចគ្នាដែលករណីអាជីវកម្មមូលធនរបស់ខ្លួនតម្រូវរួចហើយ។ ការពិនិត្យបានរកឃើញថាឧបត្ថម្ភធនដឹកជញ្ជូន ដែលត្រូវបានវាយតម្លៃពីសូន្យជាជាងពីមូលដ្ឋានដែលមានស្រាប់ នៅតែមានភាពសមស្របលើមូលដ្ឋានសមធម៌ សូម្បីក្រោមហិរញ្ញវត្ថុតឹងតែង ខណៈដែលផ្លូវពីរដែលមានអ្នកដំណើរតិច បានបន្ថែមបន្តិចម្តងៗក្នុងឆ្នាំមុនៗ លែងបំពេញតម្រូវការដែលមានឯកសារណាមួយ ហើយគ្រាន់តែមិនដែលត្រូវបានបើកឡើងវិញដើម្បីត្រួតពិនិត្យ។ ការបញ្ចប់ផ្លូវទាំងពីរបានដោះលែងថវិកាគ្រប់គ្រាន់ដើម្បីបិទចន្លោះដែលនៅសល់ ដោយមិនចាំបាច់អំពាវនាវលក្ខខណ្ឌលើកលែង ហើយការដំឡើងប្រព័ន្ធបង្ហូរទឹកភ្លៀងបានដំណើរការតាមកាលកំណត់។

ក្រុមប្រឹក្សាបានអនុម័តថវិកាដែលរក្សាវិន័យថវិកាមានតុល្យភាព ផ្តល់មូលនិធិពេញលេញដល់ផ្លូវដឹកជញ្ជូនដែលមានភាពសមស្របខាងសមធម៌ បញ្ចប់ផ្លូវពីរដែលការសាកល្បងចាប់ពីសូន្យមិនអាចបញ្ជាក់បាន និងរក្សាគម្រោងហេដ្ឋារចនាសម្ព័ន្ធតាមកាលកំណត់។ របាយការណ៍របស់នាយកហិរញ្ញវត្ថុជូនក្រុមប្រឹក្សាបានសរសើរលទ្ធផលចំពោះភាពអាចមើលឃើញរយៈពេលមធ្យមនៃនិន្នាការចំណូលយូរមុនវាក្លាយជាវិបត្តិ និងដំណើរការចាប់ពីសូន្យដែលម៉ត់ចត់គ្រប់គ្រាន់ដើម្បីបែងចែកកម្មវិធីដែលសមនឹងការពារ ពីកម្មវិធីដែលគ្រាន់តែមិនដែលត្រូវបានស្នើឱ្យបញ្ជាក់ខ្លួនម្តងទៀត។

## ទស្សនៈវិស័យទាំងបួន

### រដ្ឋាភិបាលមូលដ្ឋាន

អាជ្ញាធរមូលដ្ឋានជាធម្មតាមិនអាចខ្ចីដើម្បីគ្របដណ្តប់ឱនភាពប្រតិបត្តិការបានដូចរដ្ឋាភិបាលជាតិទេ ហើយជាច្រើនដំណើរការក្រោមតម្រូវការថវិកាមានតុល្យភាពច្បាស់លាស់ដែលដាក់ដោយថ្នាក់រដ្ឋាភិបាលខ្ពស់ជាង ដែលធ្វើឱ្យការដោះដូរវិន័យសារពើពន្ធរវាងភាពជឿជាក់ និងភាពបត់បែន ផ្ទាល់ និងមូលដ្ឋានមិនធម្មតា។ ចំណូលជារឿយៗប្រមូលផ្តុំក្នុងប្រភពមួយឬពីរ ជាទូទៅពន្ធអចលនទ្រព្យ ឬការផ្ទេរជាតិរួម ដូច្នេះការធ្លាក់ចុះក្នុងមួយណាក៏ដោយមានឥទ្ធិពលភ្លាមៗ ដែលមូលដ្ឋានពន្ធជាតិចម្រុះជាងអាចស្រូបយកបានពេលខ្លះ។ វិន័យប្រតិបត្តិសំខាន់ខ្លាំង ព្រោះទុនបម្រុងស្តើង៖ អាជ្ញាធរមូលដ្ឋានដែលរកឃើញភាពខុសគ្នាធំធៀបនឹងថវិកាដែលបានអនុម័តនៅចុងឆ្នាំ មានកន្លែងគ្រប់គ្រងតិចជាងរតនាគារជាតិដែលមានទុនបម្រុង និងសមត្ថភាពខ្ចីជ្រៅជាងឆ្ងាយ។

### រដ្ឋាភិបាលជាតិ

រដ្ឋាភិបាលជាតិជាធម្មតាជាកន្លែងដែលយន្តការពេញលេញនៃប្រធានបទនេះអភិវឌ្ឍបំផុត គឺក្រសួងហិរញ្ញវត្ថុ ឬរតនាគារដាច់ដោយឡែក វិន័យសារពើពន្ធតាមច្បាប់ ឬរដ្ឋធម្មនុញ្ញ ក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យមផ្លូវការ និងស្ថាប័នសារពើពន្ធឯករាជ្យដែលវាយតម្លៃការអនុលោម។ ហានិភ័យនៅទីនេះមិនមែនថាយន្តការអវត្តមានទេ ប៉ុន្តែថាវាក្លាយជាគោលដៅដោយខ្លួនឯង៖ ក្របខ័ណ្ឌទំនើបអាចបង្កើតរូបរាងនៃវិន័យ ខណៈដែលយានក្រៅថវិកា បំណុលតាមលក្ខខណ្ឌ ឬការព្យាករណ៍ចំណូលសុទិដ្ឋិនិយម ធ្វើឱ្យខូចលេខដែលវារាយការណ៍ដោយស្ងាត់ស្ងៀម។ រដ្ឋាភិបាលជាតិក៏ជាកន្លែងដែលតួនាទីរបស់គោលនយោបាយសារពើពន្ធជាឧបករណ៍ម៉ាក្រូសេដ្ឋកិច្ច មិនមែនគ្រាន់តែជាលំហាត់គណនេយ្យ អាចមើលឃើញច្បាស់បំផុត ព្រោះការសម្រេចចិត្តពន្ធ និងចំណាយរបស់ជាតិផ្លាស់ប្តូរសេដ្ឋកិច្ចទូលំទូលាយ តាមរបៀបដែលថវិការបស់អាជ្ញាធរមូលដ្ឋានតែមួយកម្របានតែម្នាក់ឯង។

### វិស័យសង្គម និងវិស័យមិនស្វែងរកប្រាក់ចំណេញ

អង្គការមិនស្វែងរកប្រាក់ចំណេញ និងអង្គការក្រៅរដ្ឋាភិបាលមិនអនុម័តវិក្កយបត្រចែកចាយថវិកាតាមរយៈស្ថាប័នតំណាងទេ ប៉ុន្តែប្រឈមនឹងបញ្ហាស្រដៀងគ្នាតាមរចនាសម្ព័ន្ធ៖ ប្រាក់ជារឿយៗត្រូវបានដាក់កំហិតដោយជំនួយឥតសំណងនីមួយៗ ឬកិច្ចព្រមព្រៀងម្ចាស់ជំនួយ មកដល់តាមវដ្តរបស់ម្ចាស់មូលនិធិនីមួយៗ ជាជាងឆ្នាំសារពើពន្ធរបស់អង្គការ ហើយអាចទុកអង្គការឱ្យមានសាធនភាពតាមបច្ចេកទេស ខណៈពេលដែលមិនអាចចំណាយលើសកម្មភាពតែមួយដែលត្រូវការមូលនិធិបំផុត។ អង្គការមិនស្វែងរកប្រាក់ចំណេញស្រដៀងនឹងក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យម គឺទិដ្ឋភាពបំពង់បង្ហូរមូលនិធិច្រើនឆ្នាំដែលតាមដានចំណូលដែលបានប្តេជ្ញា ទំនង និងប្រថុយ ធៀបនឹងការប្តេជ្ញាចិត្តច្រើនឆ្នាំ ព្រោះថវិកាឆ្នាំតែមួយអាចមើលទៅមានតុល្យភាព ខណៈលាក់ជ្រោះមូលនិធិឆ្នាំបន្ទាប់ពីឆ្នាំក្រោយ ដែលជាភាពខុសគ្នាដែល ប្រធានបទ 3.8 — ការគ្រប់គ្រងវិស័យសង្គម និងអង្គការមិនស្វែងរកប្រាក់ចំណេញ ស្វែងយល់ពីផ្នែកគំរូមូលនិធិ (សូមមើល ប្រធានបទ 3.8 — ការគ្រប់គ្រងវិស័យសង្គម និងអង្គការមិនស្វែងរកប្រាក់ចំណេញ)។ ទុនបម្រុងគ្មានកំហិតដំណើរការ តាមពិត ជាលក្ខខណ្ឌលើកលែងរបស់វិស័យនេះ៖ អង្គការដែលមានទុនបម្រុងសំខាន់អាចស្រូបយកការប៉ះទង្គិចមូលនិធិដោយមិនកាត់បន្ថយកម្មវិធីភ្លាមៗ ខណៈដែលអង្គការដែលគ្មានទុនបម្រុងមិនមានសមាសធាតុការពារស្មើគ្នា។

### កម្រិតពហុភាគី និងអន្តរជាតិ

ស្ថាប័នពហុភាគីជាធម្មតាផ្តល់មូលនិធិដល់ប្រតិបត្តិការស្នូលតាមជុំបំពេញបន្ថែមតាមកាលកំណត់ ដែលរដ្ឋសមាជិកចរចាវិភាគទានច្រើនឆ្នាំក្នុងពេលតែមួយ ដែលជាក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យមដែលចរចាក្នុងចំណោមម្ចាស់មូលនិធិអធិបតេយ្យ ជាជាងកំណត់ក្នុងផ្ទៃក្នុងដោយក្រសួងហិរញ្ញវត្ថុ។ ការអនុម័តស្ថិតនៅជាមួយក្រុមប្រឹក្សាភិបាលដែលតំណាងឱ្យរដ្ឋសមាជិក ជាជាងស្ថាប័ននីតិប្បញ្ញត្តិក្នុងស្រុក ដែលផ្លាស់ប្តូរថាមវន្តភាពស្របច្បាប់ដែល ប្រធានបទ 1.2 — ត្រីកោណយុទ្ធសាស្ត្រ៖ ភាពស្របច្បាប់ តម្លៃ និងសមត្ថភាព ពណ៌នា ដោយមិនលុបបំបាត់ភាពតានតឹងមូលដ្ឋានរវាងស្រោមសំបុត្រថេរ និងសំណូមពរប្រកួតប្រជែងលើវា។ ដោយសារវិភាគទានជាស្ម័គ្រចិត្តជាជាងការយកពន្ធបង្ខំ វិន័យសារពើពន្ធមានប្រសិទ្ធភាពរបស់ស្ថាប័នពហុភាគីគឺជាឧបសគ្គភាពជឿជាក់ជាជាងពិដានផ្លូវច្បាប់៖ អង្គការដែលត្រូវបានមើលឃើញថាបានប្រើមូលនិធិអតីតកាលមិនបានល្អ រកឃើញជុំបំពេញបន្ថែមបន្ទាប់ពិបាកជាង ដែលជាទម្រង់វិន័យក្រោយហេតុការណ៍ដែលការធ្វើថវិកាជាតិសម្រេចបានតាមរយៈច្បាប់ជំនួសវិញ។

## ទម្រង់នៃការបរាជ័យដែលជួបញឹកញាប់

**ការវារឡើងនៃមូលដ្ឋាន។** ការចរចាបន្តិចម្តងៗ ដែលធ្វើម្តងទៀតឆ្នាំនេះឆ្នាំនោះ អនុញ្ញាតឱ្យកម្មវិធីហួសសម័យ ឬមានសមិទ្ធកម្មអន់ រស់រានដោយគ្មានកំណត់ ព្រោះគ្មានដំណាក់កាលណានៃដំណើរការសួរថាតើវាគួរមានឬអត់ គ្រាន់តែសួរថាការបែងចែករបស់វាគួរផ្លាស់ប្តូរប៉ុន្មាន។ ថ្លៃដើមគឺថវិកាដែលឆ្លុះបញ្ចាំងពីប្រវត្តិប្រមូលផ្តុំនៃការផ្សះផ្សានយោបាយកន្លងមក ច្រើនជាងអាទិភាពបច្ចុប្បន្ន ដែលរកឃើញតែនៅពេលការប៉ះទង្គិចសារពើពន្ធបង្ខំចុងក្រោយនូវសំណួរដែលគ្មានវដ្តធម្មតាណាបានសួរ។
