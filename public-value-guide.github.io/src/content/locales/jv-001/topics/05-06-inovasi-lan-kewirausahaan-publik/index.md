# Topik 5.6 — Inovasi lan Kewirausahaan Publik

**Nilai publik tuwuh nalika wong ing njero organisasi sektor publik utawa sosial nyadari kesempatan sing durung ana sing ngaku lan ngupayakaké kanthi inisiatif wirausahawan, nanging amarga wong iku mbelanjakaké wewenang kolektif, dudu modal pribadi, upaya iku mung nggawé nilai sing langgeng yen isih lulus ujian legitimasi, nilai, lan kapasitas sing padha kaya strategi publik liyané — lan pilot sing lulus ing sawijining panggonan ora kanthi otomatis lulus ing panggonan candhaké.**

## Apa Sebabe Iki Wigati kanggo Nilai Publik

Akèh organisasi sektor publik lan sosial bisa nuduhaké paling ora siji tim cilik, sing ndhelik ing pojok bagan organisasi, sing diidinaké makarya kanthi cara béda: lab inovasi, unit digital, program "skunkworks", pilot sing didanai yayasan. Unit-unit iki ana amarga administrasi publik rutin iku, kanthi rancangan, ati-ati — dibangun ing preseden, jejak audit, lan perlakuan sing padha, kabèh iku ndadèkaké alon nyoba bab sing pancèn anyar (waca Topik 3.1 — Sistem lan Model Administrasi Publik bab kenapa kekuwatan Administrasi Publik Tradisional lan sikap ati-atiné iku ciri sing padha). Isih kudu ana wong sing nggawé ide anyar, nyobané kanthi murah, lan nggawa liwat skeptisisme organisasi dhéwé, lan iku karya kewirausahaan sanajan ora ana sing nyebut mangkono.

Masalah sing luwih angel dudu miwiti; iku apa sing kelakon candhaké. Sawijining kutha nyoba pilot skema transportasi miturut panjaluk, departemen omah ngrancang ulang proses penerimaané, organisasi nirlaba nguji model manajemen kasus anyar — lan pilot kasil, ditulis, menang penghargaan, banjur umumé tetep ing panggonan lair. Organisasi sing ora mbangun iku arang nggunakaké kabèh, sanajan buktiné apik lan kabutuhané padha. Celah antarané pilot sing apik lan panyebarané iku dudu utamané kegagalan komunikasi; iku ketidakcocokan wewenang hukum, kondisi politik, lan kapasitas pangiriman antarané panggonan sing berinovasi lan panggonan sing dijaluk nutugaké.

Taruhané nyata amarga kegagalan publik ora padha karo kegagalan swasta. Start-up sing gagal kanthi meneng bali modal investoré lan nutup; pilot publik sing gagal kanthi katon bisa ngregedi mandat pejabat kapilih, kredibilitas sekretaris tetep, lan ruang pembaru candhaké kanggo nyoba maneh. Organisasi sing ora tau nglindhungi ruang kanggo eksperimen mandheg ing mburi masalah sing ora bisa ditangani nganggo piranti sing wis ana. Organisasi sing nglindhungi ruang iku tanpa disiplin ngentekaké legitimasi ing pilot sing ora bakal nyukupi warga, lan loro-lorone kegagalan bisa dihindari nganggo metode dhasar sing padha: anggepen inovasi minangka strategi sing kudu diuji, dudu tumindak iman sing kudu didanai.

## Konsep-Konsep Utama

**Inovasi**, ing pangertèn umum sing dadi titik wiwitan topik iki, yaiku implementasi praktis saka ide sing nggawé utawa nambah barang, layanan, utawa proses — beda saka mung panemuan, sing mandheg ing ide dhéwé (waca [inovasi](https://en.wikipedia.org/wiki/Innovation)). Ing sektor publik khususé, inovasi biasané tegesé cara anyar ngrumusaké masalah, ngrancang layanan, utawa ngirim asil sing sadurungé ora dienggo organisasi, apa ide dhasaré anyar kanggo donya utawa ora.

**Lab inovasi sektor publik** yaiku tim, unit, utawa dana khusus — ing njero pamarentah, nempel marang pamarentah, utawa didanai bareng karo pamarentah dening yayasan — sing tujuan eksplisité kanggo nyusun lan nanemaké metode inovasi, kayata desain layanan, analisis data, pembuatan prototipe, lan pangujian cepet, kanggo ngupayakaké masalah publik utawa sosial. Yayasan inovasi Inggris [Nesta (charity)](https://en.wikipedia.org/wiki/Nesta_(charity)), sing wis nglakokaké, ngrancang, lan nyinaoni unit kaya mangkono ing akèh negara, njlentrehaké yen unit-unit iku wis pindhah "saka pinggiran menyang arus utama" sajrone kira-kira sepuluh taun kepungkur, kanthi pamarentah saya kerep ngelembagakaké apa sing biyen proyek pilot sepisan dadi unit tetep. Sing mbédakaké lab saka tim kabijakan utawa pangiriman biasa yaiku insulasi parsial: lab biasané diwènèhi idin eksplisit, pos anggaran kapisah, utawa mandat sing dilindhungi sing ngidinake nanggung risiko pangiriman luwih akèh tinimbang departemen garis biasané bisa, persis amarga organisasi liyané dioptimalaké kanggo konsistensi lan audit, dudu kanggo nyoba sepuluh bab lan ngarep-arep sawetara gagal (waca Topik 3.10 — Regulasi lan Manajemen Risiko Publik bab kepriyé selera risiko ditetepaké lan dikelola sacara luwih umum). Insulasi lab sengaja parsial, ora mutlak — iku isih tanggung jawab, pungkasané, marang struktur legitimasi lan akuntabilitas sing padha karo organisasi liyané; lab sing diinsulasi saka akuntabilitas, ora mung saka proses rutin, dudu inovasi sing dilindhungi, iku birokrasi paralel sing ora dikelola.

**Kewirausahaan publik** yaiku nerapaké watak wirausaha — nyadari kesempatan sing durung ana liyané sing ngaku, ngerteni cara nggayuh, lan banjur nglakoni — kanggo ngupayakaké nilai publik tinimbang bathi pribadi. Istilah lan artikulasi paling cetha loro-lorone runut menyang Mark H. [Moore](https://en.wikipedia.org/wiki/Mark_H._Moore), sing *Creating Public Value: Strategic Management in Government* (1995) mratelakaké yen manajer publik butuh apa sing diarani imajinasi sing ora tau tenang lan nggoleki nilai: panelusuran aktif kanggo kesempatan nggawé nilai publik, ora administrasi pasif saka mandat sing wis ana. Wirausahawan publik Moore beda saka sing swasta ing siji bab sing mutlak: wirausahawan swasta mungkasi njawab apa pelanggan gelem mbayar lan investor gelem mbiayai; wirausahawan publik njawab apa lingkungan otorisasi bakal maringi lan njaga idin, apa proposisi nilai pancèn pantes karo sumber daya kolektif sing dibutuhaké, lan apa organisasi bisa pancèn ngirimaké. Mangkono, manajer publik sing wirausaha ora bebas saka segitiga strategis — legitimasi lan dhukungan, proposisi nilai, lan kapasitas operasional — nanging kudu nyukupi katelu-telune sakaligus, kanthi wektu nyata, kerep nalika ide dhéwé isih dibentuk (waca Topik 1.2 — Segitiga Strategis: Legitimasi, Nilai, lan Kapasitas). Wirausahawan publik sing oleh kapasitas lan mbangun kasus nilai sing kuwat nanging ora tau njamin otorisasi iku ora berinovasi; dheweke makarya freelance nganggo wewenang publik, lan bédané wigati sepira apik wae ide iku.

**Intrapreneurship** iku sedulur paling cedhak ing sektor swasta: prilaku wirausaha dening individu sing makarya ing njero organisasi gedhé sing wis ana, ora ngedegaké sing anyar (waca [intrapreneurship](https://en.wikipedia.org/wiki/Intrapreneurship)). Iku perbandingan sing migunani persis amarga nuduhaké apa sing ora bisa dipindhah: intrapreneur korporat biasané dijaluk, pungkasané, miturut kasus bisnis sing bakal divalidasi pasar, déné kasus wirausahawan publik mung bisa divalidasi sacara politik lan sosial, liwat lingkungan otorisasi sing diterangaké ing ndhuwur.

**Kewirausahaan sosial** yaiku konsep sing cedhak ing sektor sosial: individu utawa organisasi sing ngembangaké, mbiayai, lan nglakokaké solusi marang masalah sosial, budaya, utawa lingkungan, kerep nggabungaké model komersial utawa pendapatan usaha karo misi sosial sing eksplisit (waca [kewirausahaan sosial](https://en.wikipedia.org/wiki/Social_entrepreneurship)). Akèh inovasi sektor publik sing asli asalé saka sektor sosial — pilot organisasi nirlaba, diuji ing skala cilik nganggo dana filantropi lan paparan risiko politik luwih sithik tinimbang sing bakal ditolèrir departemen pamarentah, sing banjur diadopsi lembaga publik, didanai skala gedhé, utawa diserep menyang penyediaan statutori.

**Difusi inovasi** yaiku teori, sing dikembangaké dening sarjana komunikasi Amerika Everett [Rogers](https://en.wikipedia.org/wiki/Everett_Rogers) lan pisanan diterbitaké ing taun 1962, sing nerangaké kepriyé, kenapa, lan kanthi kacepetan apa ide utawa praktik anyar nyebar liwat sistem sosial. Rogers njlentrehaké populasi sing ngadopsi inovasi minangka dipilah, saka wektu menyang wektu, dadi urutan sing bisa dikenali — inovator, pengadopsi awal, mayoritas awal, mayoritas pungkasan, lan sing keri — pola sing biasané divisualisasiaké minangka kurva lonceng [siklus urip adopsi teknologi](https://en.wikipedia.org/wiki/Technology_adoption_life_cycle), lan mratelakaké yen adopsi nyebar liwat saluran komunikasi tartamtu ing njero sistem sosial, ora mung amarga kaluwihan intrinsik sawijining ide. Karya Rogers sing candhaké ngluwihi teori iku kanthi eksplisit marang kabijakan: kepriyé inovasi institusional diadopsi, utawa ora, dening institusi liya ing tingkat lokal, negara bagian, utawa nasional. Topik iki nganggep difusi lintas yurisdiksi minangka teori iki sing ditrapaké marang organisasi publik khususé — pitakonan apa sing ndadèkaké pilot sing kasil ing siji kutha, lembaga, utawa negara pancèn bisa mlaku menyang liyané, beda saka mung dadi kondhang ing kana.

**Difusi lintas yurisdiksi dudu masalah sing padha karo difusi ing pasar.** Pengecer sing kasil ing siji negara kerep bisa ngembang menyang negara liya kanthi nirokaké modelé kanthi panyesuaian lokal, amarga lingkungan hukum lan komersial sing dhasar — hukum perusahaan, aturan persaingan, mata uang — umumé bisa dibandhingaké lan pengecer dhéwé ngontrol ekspansiné. Pilot sektor publik ora ngontrol ekspansiné dhéwé: yurisdiksi sing ngadopsi kudu duwé (utawa oleh) wewenang statutori kanggo nglakoni bab sing padha, kudu mbangun utawa wis nyekel dhukungan politik dhéwé kanggo iku, beda saka dhukungan sing diraih yurisdiksi asal, lan kudu duwé kapasitas operasional sing sebanding — staf, sistem, pendanaan — kanggo nglakokaké, ora mung katrangan kepriyé asal nglakokaké (waca Topik 3.9 — Hubungan Antarpamarentah lan Federalisme bab kepriyé wewenang hukum pancèn dibagi antarané tingkat pamarentahan, sing dianggep topik iki ana, ora diturunaké maneh). Pilot sing katon kaya masalah desain nalika gagal nyebar kerep, yen dipriksa, iku masalah lingkungan otorisasi utawa wewenang hukum sing nganggo busana masalah desain.

**Living lab** iku pola sing gegandhèngan nanging béda: lingkungan inovasi terbuka lan berpusat marang panganggo ing ngendi peneliti, bisnis, badan pamarentah, lan warga nggawé lan nguji solusi bareng ing setelan donya nyata, ora ing laboratorium sing dikontrol (waca [living lab](https://en.wikipedia.org/wiki/Living_lab)). Yen lab inovasi sektor publik biasané tim ing njero institusi, living lab biasané ruang fisik utawa virtual bareng — lingkungan, bangsal rumah sakit, platform online — ing ngendi pirang-pirang institusi lan warga nggawé lan nguji intervensi bareng, pola sing gegandhèngan cetha karo produksi bareng sacara luwih umum (waca Topik 1.5 — Pamangku Kapentingan, Warga, lan Produksi Bareng).

**Design thinking** yaiku sakumpulan metode — ngrumusaké ulang masalah, riset panganggo, prototipe cepet, pangujian iteratif — sing dienggo paling akèh lab inovasi sektor publik minangka cara kerjané, dijupuk lan disesuaikan saka desain produk komersial (waca [design thinking](https://en.wikipedia.org/wiki/Design_thinking)). Iku metode, dudu strategi: design thinking bisa ngasilaké prototipe sing elegan lan diuji kanthi apik sing isih gagal ing segitiga strategis yen ora ana sing njamin legitimasiné utawa mriksa apa organisasi bisa njaga sawisé pilot.

## Praktik Paling Apik

1. **Wènèhana saben lab utawa pilot mandat kanthi tanggal kadaluwarsa, dudu pengecualian permanèn saka evaluasi.** Ruang sing dilindhungi kanggo eksperimen iku sumber daya sing sacara implisit disubsidi organisasi liyané, lan kudu dianyari adhedhasar bukti, ora dianggep terus kanthi baku.
2. **Insulasia risiko pangiriman, dudu akuntabilitas.** Lab bisa dikecualiaké saka sawetara garis wektu pengadaan utawa lapisan persetujuan supaya obah luwih cepet; ora bisa dikecualiaké saka ujian legitimasi lan nilai sing padha sing diadhepi saben inisiatif liyané, utawa mandheg dadi inovasi sing dilindhungi lan dadi pengecualian sing ora dikelola.
3. **Danai pilot awal kanggo sinau, dudu kanggo mbuktèkaké kesimpulan sing wis ditemtokaké.** Pilot sing dirancang supaya mung asil positif sing bisa dilaporaké dudu ujian; nyatakna sadurungé asil apa sing bakal ndadèkaké panjenengan mandheg.
4. **Dokumentasi wewenang hukum, dhukungan politik, lan kapasitas sing dianggep dienggo pilot nalika lagi mlaku, ora sawisé wong liya njaluk ngadopsi.** Kondisi-kondisi iki biasané ora katon marang wong sing mbangun pilot persis amarga dheweke wis nduweni; tulisen sadurungé dadi prasyarat sing ilang kanggo wong liya.
5. **Nilai usulan wirausahawan publik marang katelu sikil segitiga strategis sadurungé ndhukung, ora mung marang kasus nilai.** Ide sing nyenengaké kanthi proposisi nilai kuwat isih gagal yen ora ana sing nguji apa lingkungan otorisasi bakal pancèn maringi ruang, utawa apa organisasi bisa ngirimaké ngluwihi pilot cilik (waca Topik 1.2 — Segitiga Strategis: Legitimasi, Nilai, lan Kapasitas).
6. **Lindhungi manajer madya sing njupuk risiko wirausaha sing sah, kalebu nalika taruhan tartamtu ora kasil.** Bédakna kanthi cetha, ing cara kegagalan dirembug sawisé iku, antarané pilot sing diprakirakaké kanthi apik nanging ora kasil lan kekeliruan pertimbangan utawa proses sing asli; ngukum loro-lorone kanthi cara padha mulangi saben wong mandheg ngusulaké.
7. **Bangun jaringan sepadhan formal ing antarané yurisdiksi, ora mung studi kasus sing diterbitaké.** Akèh sing ndadèkaké inovasi bisa dipindhah iku tacit — kepriyé panitia dewan sing skeptis pancèn dibujuk, klausa pengadaan endi sing dadi alangan nyata — lan kawruh iku pindhah liwat kontak langsung antarpraktisi luwih apik tinimbang liwat laporan.
8. **Sadurungé ngadopsi inovasi saka papan liya, priksa wewenang hukum lan dhukungan politik panjenengan dhisik sadurungé mriksa anggaran.** Dhuwit kerep dadi sing paling gampang dirampungaké saka telung kondisi; wewenang statutori sing ilang utawa lingkungan otorisasi sing nentang bisa dadi sing pancèn nyegah adopsi, lan nemokaké iku awal luwih murah tinimbang nemokaké sawisé nyanggupi.
9. **Terbitna asil negatif lan ora konklusif kanthi visibilitas sing padha karo kasil.** Sektor sing mung krungu bab pilot sing kasil sacara sistematis ngira kakehan sepira kerep eksperimen jinis iki kasil, lan kurang nandur modal ing evaluasi jujur sing bakal ningkataké rata-rata.
10. **Pisahna pitakonan "apa ide iku sehat" saka "apa iku diimplementasi kanthi apik" nalika pilot ngecewakaké.** Akèh ide sing janjèkaké ditinggal amarga kegagalan implementasi sing ora ngandhani apa-apa bab proposisi nilai dhasar, lan akèh ide sing ringkih tahan amarga tim trampil ngimplementasi kanthi cakap preduli.
11. **Anggepen dalan pilot sing kasil menyang kepermanenan minangka masalah desain sing béda saka pilot dhéwé.** Tim sing apik nemokaké ora kanthi otomatis apik ngelembagakaké, lan serah-terima saka lab sing diinsulasi menyang jalur layanan arus utama pantes duwé rencana, pemilik, lan pos anggaran dhéwé sing eksplisit.

## Pitakon kanggo Diskusi karo Tim

**Ing ngendi ing organisasi kita prilaku wirausaha saiki diganjar, ditolèrir, utawa dihukum kanthi meneng?** Akèh organisasi duwé wangsulan ora resmi kanggo pitakon iki suwé sadurungé duwé sing tertulis, katon ing sapa sing dipromosiaké sawisé ide wani gagal lan sapa sing disisihaké. Gunakna diskusi iki kanggo ngetokaké conto nyata sing anyar, ora abstraksi — manajer tartamtu, usulan tartamtu, asil tartamtu. Pikiren apa pola sing panjenengan temokaké cocog karo pola sing diandhakaké pimpinan panjenengan pengin. Yen prilaku wirausaha dihukum ing praktik nalika dipuji ing kabijakan, celah iku pantes dijenengi sadurungé pantes dicoba didandani.

**Pilot kita endi saiki sing bakal pancèn nyukupi legitimasi lan dhukungan yen kita nyoba ngskalaaké sesuk, lan endi sing mlaku ing kesabaran pinjaman?** Pilot bisa slamet ing karsa becik siji sponsor kanggo wektu sing nggumunaké tanpa tau oleh otorisasi sing luwih jembar. Gunakna pitakon iki kanggo nelusuri pilot panjenengan sing lagi mlaku siji-siji lan takon sapa, kanthi khusus, sing kudu ngomong ya supaya saben dadi permanèn, lan apa wong utawa badan iku wis pancèn ditakoni. Bédakna pilot sing meneng-menengan mbangun dhukungan nyata saka sing mung durung cukup katon kanggo narik oposisi. Rembugen apa sing kudu panjenengan tindakaké béda kanggo saben sadurungé keputusan skala-munggah dipeksa siklus anggaran utawa pergantian pimpinan.

**Yen yurisdiksi utawa organisasi liya pengin ngadopsi inovasi paling apik kita saiki, apa sing bakal dibutuhaké sing mung kita sing nduweni saiki?** Pitakon iki mbalik rembugan difusi sing biasané, sing fokus ing mbujuk wong liya tinimbang apa sing pilot sejatiné gumantung sacara lokal. Gunakna kanggo ndhaptar kuwasa hukum khusus, kondisi politik, sumber pendanaan, lan katrampilan staf sing dianggep pilot panjenengan, misahaké apa sing pancèn bisa dipindhah saka apa sing pesenan kanggo kahanan panjenengan. Rembugen apa panjenengan tau ndokumentasiaké dependensi iki ing ngendi wae sing bisa ditemokaké tim liya. Iki uga pamriksan sing migunani marang pangerten panjenengan dhéwé kenapa pilot kasil, amarga tim kerep nemokaké ing tengah diskusi yen ora bisa nerangaké kasilé dhéwé kanthi lengkap.

**Apa kita tau ngadopsi inovasi saka papan liya tanpa mriksa dhisik apa wewenang hukum, kondisi politik, lan kapasitas pangiriman kita pancèn cocog karo panggonan asalé?** Nyalin wujud pilot sing kasil sing katon — branding, diagram alur kerja, model staffing — luwih gampang tinimbang nirokaké kondisi sing ndadèkaké mlaku, lan organisasi sing ditekan kanggo "nindakaké apa sing kasil ing kana" kerep nglewati pamriksan. Gunakna diskusi iki kanggo ngéling adopsi kepungkur tartamtu, kasil utawa ora, lan nelusuri apa kondisi dhasar pancèn diverifikasi sadurungé. Rembugen kaya apa pamriksan pra-adopsi sing bener kanggo organisasi panjenengan khususé, lan sapa sing bakal nduweni nglakoni.

**Apa sing kelakon karo ide-ide lab inovasi sawisé mandat, pendanaan, utawa pelopor lab dhéwé pindhah?** Lab kerep dibangun ngubengi siklus anggaran tartamtu, pimpinan sponsor tartamtu, utawa pendanaan njaba tartamtu, lan memori institusionalé bisa lunga bareng salah siji saka iku. Gunakna pitakon iki kanggo nelusuri apa sing nyatané kelakon marang output lab utawa program pilot organisasi panjenengan sing pungkasan mungkasi, kasil utawa ora. Rembugen apa lab panjenengan saiki duwé rencana eksplisit kanggo apa sing slamet sawisé iku, utawa apa kelangsungan gumantung kabèh marang sapa wae sing kebeneran isih ing jabatan nalika mandat lapse.

**Sapa sing nglakoni peran wirausahawan publik ing organisasi kita saiki, lan apa dheweke duwé perlindungan nyata kanggo gagal?** Saben organisasi sing wis ngasilaké inovasi sing asli biasané bisa nyebut wong utawa tim cilik tartamtu sing nggerakaké, apa peran iku ana ing bagan organisasi utawa ora. Gunakna diskusi iki kanggo nyebut wong utawa tim iku kanthi jujur, lan takon apa sing bakal kelakon marang kedudukané yen taruhan candhaké ora kasil. Pikiren apa kapasitas wirausaha ing organisasi panjenengan saiki gumantung marang toleransi risiko pribadi siji utawa loro individu tinimbang marang perlindungan struktural apa wae. Rembugen apa sing dibutuhaké supaya kapasitas iku slamet saka kepergian sapa wae sing saiki nyekel.

## Ing Praktik: Conto Nilai Publik

Otoritas transportasi saka wilayah metropolitan ukuran menengah — fiktif, gambaran pola, dudu crita babagan badan nyata — nglayani inti kutha sing padhet kanthi apik nganggo rute bis tetep nanging wis pirang-pirang taun kangelan karo sawetara pinggiran kutha kapadhetan luwih endhek ing ngendi ora ana rute sing bisa narik penumpang cukup kanggo mbenerake biayané. Perencana layanan junior, frustrasi karo usulan bola-bali kanggo mung motong rute pinggiran kutha sing kurang kinerjané, ngusulaké gantiné ngganti karo layanan minibus miturut panjaluk: penumpang njaluk dijupuk liwat saluran telpon utawa aplikasi, lan armada cilik dialurake kanthi dinamis, ora nuruti jadwal tetep.

Pimpinan otoritas ora mbiayai iki minangka layanan lengkap; padha nggawé tim inovasi cilik, maringi perencana cuti resmi kanggo nglakokaké, lan ngidinake pilot nem sasi ing siji pinggiran kutha, didanai saka anggaran inovasi diskrésioner, ora anggaran operasi utama, kanthi syarat eksplisit yen pilot bakal dievaluasi marang jumlah penumpang, biaya saben lelungan, lan kepuasan penumpang, lan bakal mungkasi kanthi otomatis kajaba dianyari adhedhasar bukti. Pilot nyukupi kasus nilai sajrone patang sasi — jumlah penumpang ing pinggiran kutha pilot tikel telu dibandhingaké angka rute tetep lawas, kanthi biaya saben lelungan sing sebanding — nanging uga gumantung marang bab sing ora wis dingerteni perencana kanthi lengkap nalika mbangun: statuta regional sepuluh taun sing maringi otoritas keleluasaan sing ora lumrah jembar kanggo ngowahi pola layanan tanpa konsultasi publik lengkap kanggo apa wae ing sangisoré ambang anggaran tartamtu, lan anggota dewan kutha sing bener-bener semangat sing wardé kalebu pinggiran kutha pilot lan sing pribadi nyengkuyung marang kolega sing skeptis.

Otoritas transportasi tanggi, ing yurisdiksi jejer kanthi dewan pamarentahan dhéwé, njaluk ngadopsi model sawisé maca evaluasi pilot sing diterbitaké. Teknologi lan model operasional pindhah kanthi gampang. Sing ora pindhah yaiku dalan cendhak hukum: otoritas tanggi makarya miturut statuta regional beda sing mbutuhaké konsultasi publik lengkap lan voting dewan kanggo owah-owahan layanan apa wae ing ndhuwur ambang sing luwih endhek banget, nambahaké sangang sasi sadurungé pilot bisa diwiwiti. Dhukungan politik uga ora pindhah — ketua dewan tanggi kanthi terbuka skeptis marang moda sing dikaitaké, saka subsidi ride-share swasta sing gagal sadurungé ing yurisdiksiné, karo layanan ora andal sing pungkasané bakal dianggep gagal lan dienggo nglawan dheweke ing pemilihan candhaké. Otoritas kapindho pungkasané ngadopsi versi layanan, kira-kira wolulas sasi sawisé iku, nanging mung sawisé mbangun koalisi politik dhéwé saka nol lan rundhingan ruang lingkup pilot sing luwih sempit sing diidinaké statutané tanpa syarat konsultasi lengkap — dalan sing luwih alon lan disesuaikan sacara lokal sing kasil otoritas pisanan ndadèkaké bisa nanging ora ndadèkaké otomatis.

## Papat Sudut Pandang Sektor

### Pamarentah Lokal

Pamarentah lokal biasané panggonan inovasi sektor publik paling gampang diwiwiti lan paling angel dijaga: kedekatan karo warga ndadèkaké masalah lan solusi calon katon banget, lan siji dewan utawa kepala departemen kerep bisa ngidinake pilot cilik tanpa lapisan persetujuan sing dibutuhaké kementerian nasional. Kendalané yaiku kapasitas, dudu wewenang — otoritas lokal cilik bisa duwé ruang hukum kanggo berinovasi nanging ora duwé tim khusus, anggaran diskrésioner, utawa wektu staf kanggo nglakokaké pilot sing bener, sing dadi salah sijiné alesan akèh inovasi lokal asalé sacara ora resmi kaya pilot transportasi fiktif ing ndhuwur, dipelopori siji karyawan sing semangat, dudu ditugasaké saka ndhuwur.

### Pamarentah Nasional

Pamarentah nasional biasané duwé sumber daya paling jero kanggo lab inovasi formal — unit digital arm's-length, lab kabijakan, lan dana inovasi kanthi staf khusus — nanging ngadhepi masalah difusi paling angel sacara internal, amarga pilot sing kasil ing siji wilayah utawa siji lengan pangiriman isih kudu nyabrang celah hukum, politik, lan kapasitas sing padha kanggo nggayuh saben wilayah utawa lengan liyané, saiki dikaliaké ing saindhenging lingkungan otorisasi sing luwih gedhé lan luwih heterogen (waca Topik 3.9 — Hubungan Antarpamarentah lan Federalisme). Risiko utama lab nasional yaiku ngasilaké pilot sing dievaluasi kanthi apik sing ora tau ninggalaké ibukutha, amarga ora ana sing nduweni karya sing luwih angel nyesuaikan karo kondisi ing papan liya ing negara.

### Sektor Sosial lan Nirlaba

Sektor sosial kerep dadi titik asal sejati inovasi sektor publik, bisa nguji model ing skala cilik nganggo pendanaan filantropi utawa pendapatan usaha lan paparan politik luwih sithik tinimbang sing bakal ditolèrir departemen pamarentah kanggo eksperimen sing padha, lan lembaga pamarentah banjur nyerep, mbiayai skala gedhé, utawa nulis menyang statuta apa sing dibuktèkaké dhisik sektor nirlaba (waca Topik 3.8 — Manajemen Sektor Sosial lan Organisasi Nirlaba kanggo model pendanaan sing ndadèkaké iki bisa). Kegagalan khas ing kene iku kosok baliné saka sektor publik: pilot nirlaba bisa gumantung banget marang prioritas siji pamodal lan energi pribadi pendiri supaya bisa slamet saka transisi menyang layanan sing dilakokaké pamarentah lan adhedhasar statuta, sanajan sawisé ide dhasar wis kabukti kanthi tuntas.

### Tingkat Multilateral lan Internasional

Badan multilateral lan internasional ora bisa meksa difusi babar pisan — dheweke ora duwé wewenang kanggo meksa pamarentah berdaulat ngadopsi apa wae — mula peran dheweke meh kabèh yaiku makelar kawruh: ngumpulaké, mbandhingaké, lan nyebaraké inovasi saka akèh yurisdiksi supaya pamarentah sing nimbang siji duwé bukti lan kontak sepadhan, ora mung tawaran sing mbujuk. Observatory of Public Sector Innovation saka Organisation for Economic Co-operation and Development (OECD) nglakoni persis peran iki, nglacak inovasi ing negara anggota lan mitra lan mbangun jaringan sepadhan sing ngidinake praktisi ing siji pamarentah sinau langsung saka mitra ing liyané, tanpa salah siji pamarentah bisa meksa liyané ngadopsi apa wae.

## Cara-Cara Kegagalan sing Umum

**Pilotitis.** Organisasi nglakokaké urutan dawa pilot, saben dirancang kanthi apik dhéwé-dhéwé, ora ana sing tau resmi diskalaaké, dipungkasi, utawa dievaluasi marang keputusan nglakoni salah siji. Biayané yaiku reputasi kanggo kegiatan terus-terusan sing ora tau dadi kapabilitas langgeng, lan tenaga kerja sing sinau ora nganggep serius pilot anyar amarga sawetara pungkasan ora nggawa menyang ngendi-endi.

**Insulasi minangka teater.** Lab utawa unit digawé kanthi peluncuran umum lan merek khas nanging tanpa mandat, anggaran, utawa pangayoman nyata saka proses persetujuan biasa organisasi, mula "inovasi"-né, ing praktik, ora luwih cepet utawa luwih bébas tinimbang apa wae liyané. Biayané yaiku sinisme, loro ing njero organisasi lan ing antarané pengamat njaba sing nampa pengumuman apa anané.

**Difusi salin-tempel.** Organisasi sing ngadopsi nirokaké wujud pilot sing kasil sing katon — alur kerja, branding, model staffing — tanpa mriksa apa wewenang hukum, dhukungan politik, lan kapasitas operasional sing ndadèkaké mlaku ing yurisdiksi asal pancèn ana ing sing anyar. Biayané yaiku peluncuran sing katon padha karo asli lan banjur gagal amarga alasan sing ora tau didiagnosis tim sing ngadopsi, amarga dheweke ndeleng desain, dudu kondisi ing ngisor.

**Wirausahawan sing ora dilindhungi.** Individu utawa tim cilik njupuk risiko sing asli lan diprakirakaké kanthi apik kanggo organisasi, lan nalika taruhan tartamtu ora kasil, dheweke dihukum kanthi cara padha karo wong sing nggawé kesalahan pertimbangan utawa proses sing asli. Biayané nglumpuk saka wektu menyang wektu: saben calon wirausahawan publik ing organisasi iku ing tembe mburi wis ndeleng apa sing kelakon, lan mandheg ngusulaké.

**Inovasi sing pisah saka kasus nilai.** Pilot diupayakaké amarga metodené lagi tren — teknologi anyar, pendekatan sing disebaraké kanthi luas saka sektor liya — dudu amarga proposisi nilai publik sing cetha diuji dhisik. Biayané yaiku pilot sing dilakokaké kanthi apik sing lulus saben gerbang proses nanging isih gagal ngasilaké apa sing bakal dianggep warga pantes karo biayané, ngrusak kredibilitas pilot candhaké sing luwih beralasan amarga gegandhèngan.

Mode-mode kegagalan iki dudu risiko khusus inovasi; iku mode kegagalan biasa segitiga strategis, teka nganggo busana sing luwih anyar (waca Topik 1.2 — Segitiga Strategis: Legitimasi, Nilai, lan Kapasitas). Iku pantes kanggo topik bernomer pungkasan buku iki: nilai publik ora tau rampung digawé, mung digawé maneh, dening wirausahawan publik candhaké sing gelem nyadari apa sing kurang.

## Dhaptar Pariksa

- [ ] Pastèkna saben lab utawa pilot aktif duwé mandat kadokumentasi, sumber anggaran, lan tanggal pembaruan utawa pungkasan.
- [ ] Pastèkna insulasi saka proses rutin ora uga tegesé insulasi saka legitimasi lan akuntabilitas.
- [ ] Nyatakna sadurungé asil apa sing bakal ndadèkaké pilot dihentekaké, ora mung asil apa sing bakal ngidinake nerusaké.
- [ ] Dokumentasi wewenang hukum, dhukungan politik, lan kapasitas operasional sing saiki dienggo saben pilot sing lagi mlaku.
- [ ] Ujinen saben usulan wirausaha marang katelu sikil segitiga strategis sadurungé nyanggupi sumber daya sing signifikan.
- [ ] Kenali sapa ing organisasi sing saiki nglakoni peran wirausahawan publik, lan apa dheweke duwé perlindungan nyata kanggo gagal.
- [ ] Gawéa utawa melu jaringan sepadhan praktisi kanggo nuker kawruh tacit, ora mung studi kasus sing diterbitaké.
- [ ] Sadurungé ngadopsi inovasi saka papan liya, verifikasi wewenang hukum lan dhukungan politik sadurungé verifikasi anggaran.
- [ ] Terbitna asil pilot negatif utawa ora konklusif kanthi visibilitas sing padha karo kasil.
- [ ] Tunjuk pemilik lan rencana eksplisit kanggo ngelembagakaké pilot apa wae sing lulus evaluasi, kapisah saka tim sing mbangun.
