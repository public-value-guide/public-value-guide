# Topik 2.4 — Ékonometrika Sektor Publik lan Evaluasi Program

**Program sing ngasilake asil sing luwih becik tinimbang wong-wong sing ora tau melu ora padha karo klaim yen program kuwi sing nyebabake asil sing luwih becik, lan dhuwit publik ora kena dibela nganggo klaim sing kapisan nalika saben wong meneng-menengan ateges sing kapindho.**

## Apa Sebabe Iki Wigati kanggo Nilai Publik

Saben taun, lembaga publik nganyari, nggedhekake, utawa mbatalake program adhedhasar perbandingan asil: peserta program pegawean luwih cepet entuk pagaweyan tinimbang sing ora melu; murid ing skema bimbingan skore luwih dhuwur tinimbang murid sing ora dibimbing. Saben perbandingan iku bener minangka katrangan lan mbebayani minangka argumentasi, amarga ora ana siji-sijia sing ngandhani apa program kuwi sing nyebabake bedane. Wong sing ndaftar ing program pegawean asring luwih bersemangat tinimbang sing ora, lan murid sing dipilih kanggo bimbingan asring dipilih amarga guru wis ngarep-arep dheweke bakal nanggapi kanthi apik. Jurang antarane "kelompok sing dilayani luwih becik" lan "layanan kuwi sing ndadekake dheweke luwih becik" iku persis jurang sing arep ditutup dening inferensi kausal.

Iki dudu kehalusan akademik. Panitia keuangan sing dijaluk nganyari pendanaan program kanthi implisit dijaluk menehi wewenang mbelanjakake dhuwit publik adhedhasar klaim sebab-akibat, apa ana wong ing ruangan sing nyebut tembung kuwi utawa ora. Topik 2.1 menehi sampeyan kerangka asil sing nyatakake apa sing dikarepake program kanggo diowahi (waca Topik 2.1 — Kartu Skor Nilai Publik lan Kerangka Asil); topik iki menehi sampeyan metode sing nguji apa dheweke tenan ngowahi, lan sepira. Analisis biaya-manfaat lan efektivitas biaya (waca Topik 2.2 — Analisis Biaya-Manfaat Sosial lan Analisis Efektivitas Biaya) lan pangasilan sosial saka investasi (waca Topik 2.3 — Pangasilan Sosial saka Investasi lan Pangukuran Dampak) kekarone mbutuhake ukuran efek sing bisa dibela; topik iki papan ukuran efek kuwi asale, utawa papan sampeyan sinau yen angka sing wis dikarepake ora bisa nanggung beban sing dilebokake marang dheweke.

Taruhane ora mung finansial. Pamarentah sing nggedhekake program ora efektif amarga evaluasi cacat ndadekake dheweke katon efektif wis mbuwang dhuwit lan, asring luwih parah, nggeser alternatif sing tenan efektif sing ora tau entuk kesempatan; pamarentah sing mbatalake program efektif amarga perbandingan lugu ndadekake dheweke katon ora ana gunane wis ngrusak nilai sing bisa dilindhungi evaluasi sing dirancang luwih apik. Nggawe identifikasi kausal kanthi bener, lan ngerti nalika ora bisa nggawene bener, dhewe kompetensi nilai publik, dudu minat sampingan spesialis.

## Konsep-Konsep Utama

**Inferensi kausal** yaiku cabang statistika sing gegayutan karo nemtokake apa, lan sepira, owah-owahan siji variabel ngasilake owah-owahan ing variabel liya, beda karo kekarone mung obah bebarengan. Dheweke nyuplai dhasar konseptual — nalar kontrafaktual, basa perlakuan lan kontrol, katalog ancaman tartamtu marang klaim kausal — sing dienggo saben metode ing topik iki. Wikipedia: [Causal inference](https://en.wikipedia.org/wiki/Causal_inference).

**Kontrafaktual** yaiku asil sing bakal dialami wong utawa unit yen ora nampa program, lan dheweke jumlah sentral sing ora bisa diamati sing dicoba didhekati saben metode kausal: sampeyan bisa ndeleng apa sing kedadeyan marang peserta, nanging ora tau apa sing bakal kedadeyan marang wong sing padha tanpa bantuan. Saben metode ing ngisor iki yaiku strategi beda kanggo mbangun pengganti sing bisa dipercaya kanggo pengamatan sing ilang kuwi. **Model kausal Rubin**, dikembangake utamane dening ahli statistika Donald Rubin, ngformalisasikan iki minangka kerangka "asil potensial": saben unit nduweni asil potensial ing perlakuan lan siji ing kontrol, lan efek kausal yaiku bedane ing antarane, sing mung siji sing tau diamati. Wikipedia: [Rubin causal model](https://en.wikipedia.org/wiki/Rubin_causal_model).

**Confounding** kedadeyan nalika faktor katelu ngaruhi apa unit nampa program lan asil sing arep diowahi program, ndadekake katon kaya-kaya program nyebabake efek sing sejatine diasilake confounder. Motivasi, kemampuan sadurunge, kahanan ekonomi lokal, lan kekayaan kulawarga yaiku confounder sing bola-bali ing evaluasi program publik, amarga rutin ngaruhi sapa sing nggunakake layanan lan kepriye wong utawa panggonan kuwi sawise iku. Wikipedia: [Confounding](https://en.wikipedia.org/wiki/Confounding).

**Bias seleksi** yaiku kasus khusus confounding sing muncul saka cara peserta bisa mlebu ing kelompok perlakuan — seleksi dhewe, rujukan staf, utawa aturan kelayakan — saengga kelompok sing dilayani lan sing ora dilayani beda kanthi sistematis sadurunge program ndemek dheweke. Program pegawean sing mung ditindakake dening pencari kerja sing paling bersemangat bakal katon efektif sanajan ora nindakake apa-apa, amarga kelompok pembanding ora tau dadi pengganti adil kanggo apa sing bakal ditindakake peserta tanpa bantuan. Wikipedia: [Selection bias](https://en.wikipedia.org/wiki/Selection_bias).

**Korelasi ora ateges kausalitas** yaiku peringatan umum sing dioperasionalake topik iki: rong variabel sing obah bebarengan konsisten karo siji nyebabake liyane, karo kosok baline, karo sebab umum sing dienggo bareng, utawa karo kebetulan, lan pola piyambak ora bisa mbedakake antarane iki. Dodolan es krim lan pati keslep banyu kekarone munggah saben mangsa panas tanpa salah siji nyebabake liyane, amarga cuaca anget nyebabake kekarone; evaluasi program publik kebak versi luwih alus saka jebakan sing padha. Wikipedia: [Correlation does not imply causation](https://en.wikipedia.org/wiki/Correlation_does_not_imply_causation).

**Uji coba terkontrol acak (randomized controlled trial, RCT)**, diarani **evaluasi acak** ing literatur evaluasi kabijakan, nugasake unit sing layak kanthi acak menyang kelompok perlakuan sing nampa program lan kelompok kontrol sing ora, supaya rata-rata kelompok loro kuwi mung beda ing apa dheweke dilayani. Pengacakan kuwat amarga ngatasi confounding sakabehe: dheweke ngimbangi confounder sing bisa diukur lan sing ora, tanpa kudu nyebut dheweke sadurunge. Wikipedia: [Randomized controlled trial](https://en.wikipedia.org/wiki/Randomized_controlled_trial).

**Difference-in-differences (DiD)** mbandhingake owah-owahan asil saka wektu menyang wektu kanggo kelompok sing dilayani karo owah-owahan sajrone periode sing padha kanggo kelompok pembanding sing ora nampa program, kanthi nganggep yen, tanpa program, kelompok loro bakal ngetutake tren paralel. Dheweke metode andalan nalika program tekan siji yurisdiksi sadurunge liyane lan pengacakan ora tau dadi pilihan, amarga bisa nggunakake data administratif sing rutin dikumpulake tinimbang uji coba sing dirancang khusus. Wikipedia: [Difference in differences](https://en.wikipedia.org/wiki/Difference_in_differences).

**Desain diskontinuitas regresi (regression discontinuity design, RDD)** nggunakake aturan program sing nugasake perlakuan adhedhasar skor sing diukur nglewati wates tetep — manfaat sing diwiwiti persis ing ambang penghasilan, kelas remedial sing ditugasake marang murid sing skore mung ing ngisor nilai lulus — lan mbandhingake asil kanggo unit sing mung ing ndhuwur lan ing ngisor, sing liyane padha. Amarga ing sisih endi unit tiba saka ambang kuwi sakbenere sewenang-wenang ing pita sempit ing sakubenge, perbandingan nyedhaki eksperimen acak lokal tanpa ana sing ngacak apa-apa. Wikipedia: [Regression discontinuity design](https://en.wikipedia.org/wiki/Regression_discontinuity_design).

**Estimasi variabel instrumental (instrumental variables, IV)** nggunakake variabel katelu, "instrumen", sing ngaruhi panggunaan program nanging ora duwe efek langsung marang asil kajaba liwat panggunaan kuwi, kanggo nyingkirake bagean hubungan perlakuan-asil sing bakal dicemari confounding. Instrumen kabijakan publik klasik yaiku jarak menyang fasilitas, utawa panggonan sing dialokasikan liwat undhian, sing ngowahi partisipasi tanpa nyebabake asil kanthi mandiri; umume kangelan metode iki dumunung ing mbela yen instrumen mung ngaruhi asil liwat program. Wikipedia: [Instrumental variables estimation](https://en.wikipedia.org/wiki/Instrumental_variables_estimation).

**Eksperimen alami** yaiku kahanan, sing muncul saka kabijakan, geografi, utawa kahanan tinimbang rancangan peneliti, ing ngendi sawetara wong kena program lan wong liya sing sepadan ora, kaya-kaya eksperimen wis dilakokake tanpa ana sing nglakokake. Owah-owahan kabijakan sing ditrapake ing wates tanggal lair, wates sing nglebokake kulawarga meh padha ing yurisdiksi beda, utawa undhian sing mbatesi panggonan sing kakehan peminat yaiku eksperimen alami sing banjur bisa dianalisis RDD, IV, utawa DiD. Wikipedia: [Natural experiment](https://en.wikipedia.org/wiki/Natural_experiment).

**Efek Hawthorne** nyebutake risiko yen wong ngowahi prilakune mung amarga ngerti lagi diamati, ora gumantung isi program sing sejatine, sing bisa nggedhekake efek sing diprakirakake yen kelompok kontrol ora diamati kanthi intensitas padha — tumindak ngukur dhewe bisa dadi bagean perlakuan. Wikipedia: [Hawthorne effect](https://en.wikipedia.org/wiki/Hawthorne_effect).

**Daya statistik** yaiku kemungkinan evaluasi bakal ndeteksi efek nyata ukuran tartamtu yen ana, gumantung utamane marang ukuran sampel, ukuran efek sing digoleki, lan sepira asil beda-beda ing njero kelompok. Evaluasi sing kurang daya sing nemokake "ora ana efek signifikan" asring ora mbuktekake program ora nindakake apa-apa; dheweke mbuktekake evaluasi kekecilan kanggo ngandhani salah siji, bedane sing asring dilalekake pimpinan ing tekanan kanggo tekan putusan. Wikipedia: [Power (statistics)](https://en.wikipedia.org/wiki/Power_(statistics)).

## Praktik Paling Apik

1. **Putusna desain evaluasi sadurunge program diluncurake, aja sawise.** Evaluasi acak, peluncuran bertahap sing cocog kanggo difference-in-differences, utawa ambang kelayakan sing cocog kanggo desain diskontinuitas regresi kabeh luwih gampang dibangun wiwit awal tinimbang ditambahake mengko nalika panyedhiyan layanan wis diwiwiti kanthi ad hoc.
2. **Nyatakna kontrafaktual kanthi eksplisit ing saben ringkesan evaluasi.** Tulisen, ing siji ukara, apa sing sampeyan bandhingake peserta karo — ora ana program babar pisan, program sadurunge, intervensi beda — amarga kontrafaktual sing ora dinyatakake yaiku papan sing biasane didhelikake perselisihan evaluasi sing paling cetha.
3. **Anggepen perbandingan sederhana sadurunge-lan-sawise minangka hipotesis wiwitan, ora tau minangka temuan.** Asil obah amarga akeh sebab sing ora gegayutan karo programmu — siklus ekonomi, efek musiman, owah-owahan kabijakan liya sing dibarengi — lan desain sadurunge-lan-sawise ora bisa misahake kontribusi programmu saka kontribusi kuwi.
4. **Cocogna metode karo aturan sing sejatine nugasake program, ora karo metode sing paling sampeyan kenal.** Program sing dibatesi nganggo undhian mbutuhake logika evaluasi acak sanajan sampeyan ora nyebut dheweke uji coba; program sing ditugasake dening ambang skor mbutuhake desain diskontinuitas regresi; program sing diluncurake menyang sawetara wilayah sadurunge liyane mbutuhake difference-in-differences.
5. **Daftarna ukuran asil lan rencana analisis sadurunge ndeleng asil.** Mutusake asil endi sing diitung minangka "kasil" sawise ndeleng endi sing obah yaiku dalan sing wis kadokumentasi menyang positif palsu, lan pra-registrasi yaiku pertahanan standar marang kuwi.
6. **Daya evaluasi kanggo ukuran efek paling cilik sing isih mbenerake biaya program, ora kanggo kepenak.** Evaluasi sing kekecilan kanggo ndeteksi efek sing wigati kanggo kabijakan bakal ngasilake asil "ora ana beda signifikan" sing ora informatif sing disalahwaca minangka bukti kegagalan.
7. **Laporna karakteristik kelompok pembanding bebarengan karo kelompok perlakuan, ora mung efek utama.** Evaluasi sing bisa dipercaya ngidini pamaca skeptis mriksa yen kelompok loro padha sadurunge perlakuan; evaluasi sing ndhelikake iki meksa pamaca percaya keseimbangan tanpa bukti.
8. **Komisikna evaluasi saka sumber sing mandiri saka tim panyedhiya layanan, utawa pisahna analisis yen ora bisa.** Tim sing nduweni kepentingan ing kasil program nduweni insentif struktural, asring ora sadar, kanggo nafsirake bukti ambigu kanthi nguntungake program.
9. **Pisahna signifikansi statistik saka signifikansi praktis lan fiskal ing saben laporan.** Efek cilik sing diprakirakake kanthi tepat lan efek gedhe sing diprakirakake kanthi ora tepat yaiku temuan beda sing mbutuhake keputusan beda, lan nggabungake kekarone dadi "signifikan" utawa "ora signifikan" mbusak bedane sing dibutuhake keputusan pendanaan.
10. **Anggarna evaluasi minangka bagean tetep saka biaya program ing tahap desain, ora minangka apa sing kari.** Program sing cukup gedhe kanggo wigati kanggo nilai publik biasane cukup gedhe kanggo mbiayai evaluasi dampak sing bisa dipercaya, lan nganggep evaluasi minangka opsional yaiku cara bukti lemah dadi rutin.
11. **Terbitna asil nol lan negatif kanthi visibilitas sing padha karo asil positif.** Lingkungan komisioning sing mung ngumumake evaluasi sing kasil nggawe bias seleksi ing dhasar bukti sing diterbitake dhewe, ngarahake penilaian "apa sing kasil" saben wong mengko marang optimisme.
12. **Lebokna saben evaluasi sing wis rampung menyang dhasar bukti sing luwih amba sing dijaga sektormu, ora mung arsipmu dhewe.** Siji evaluasi, sepira apike rancangane, mung siji titik data; sintesis sistematis ing akeh evaluasi sing ngowahi temuan program dadi kawruh sing bisa dipindhah (waca Topik 2.6 — Sintesis Bukti lan Apa sing Kasil).

## Pitakon kanggo Diskusi karo Tim

**Kontrafaktual apa sing sejatine kita enggo mbandhingake program iki, lan apa kita wis ngandhakake kanthi cetha?** Saben klaim dampak nuduhake perbandingan, nanging tim asring ninggalake dheweke implisit, ngidini "iki kasil" meneng-menengan gleser antarane "luwih becik tinimbang ora ana apa-apa", "luwih becik tinimbang apa sing wis kita tindakake", lan "luwih becik tinimbang alternatif paling apik sing bisa kita danai". Takonen pimpinan evaluasimu kanggo nyatakake kontrafaktual minangka ukara tunggal ing basa sederhana, banjur priksa apa bukti sing kasedhiya tenan ndhukung klaim bab perbandingan khusus kuwi. Yen kontrafaktual jujure yaiku "kita ora ngerti apa sing bakal kedadeyan yen ora", anggepen klaim dampak saiki minangka hipotesis, dudu temuan, lan rembugen apa sing dibutuhake kanggo nutup jurang kuwi.

**Apa wong utawa panggonan sing nggunakake program iki bisa beda kanthi sistematis saka sing ora, kanthi cara sing uga bakal ngaruhi asil?** Iki pitakon bias seleksi, lan pantes ditakoni sanajan — apamaneh nalika — wangsulane katon cetha "ora". Motivasi, kahanan sadurunge, kapasitas lokal, lan pola rujukan staf yaiku sumber beda sing didhelikake sing ngasilake perkiraan dampak sing nyasarake sanajan kanthi sampel gedhe lan katon teliti. Yen tim ora bisa nerangake kepriye peserta bisa mlebu ing program, dheweke ora bisa nyingkirake iki, lan jurang kuwi kudu luwih nggugupake sampeyan tinimbang ukuran sampel cilik.

**Apa desain evaluasi kita dibangun menyang program, utawa ditempelake sawise, lan apa biayane marang kita?** Evaluasi acak, peluncuran bertahap, utawa ambang kelayakan sing diskor kabeh luwih murah lan luwih bisa dipercaya nalika direncanakake sadurunge peluncuran tinimbang nalika direkonstruksi saka data administratif apa wae sing kebeneran slamet. Takonen opsi desain evaluasi apa sing dipertimbangake ing tahap desain program, lan yen ora ana, anggepen kuwi jurang proses sing kudu ditutup sadurunge program sabanjure, ora mung watesan program iki. Rembugen data apa sing kudu ana wiwit dina pisanan supaya program utama sabanjure bisa ndhukung perkiraan kausal sing bisa dipercaya.

**Apa sampel kita cukup gedhe kanggo ndeteksi efek sing pantes dingerteni, lan apa kita bakal ngenali temuan "ora ana efek" sing kurang daya yen ndeleng?** Evaluasi sing nglaporake ora ana efek signifikan sacara statistik kadhang bener ngandhani yen program ora makarya, lan kadhang mung ngandhani yen evaluasi kekecilan kanggo ndeleng efek sing tenan ana. Takonen analismu kanggo nyatakake ukuran efek minimum sing dikuasai evaluasi kanggo dideteksi, lan bandhingna karo ukuran efek sing tenan mbenerake biaya program. Yen angka loro iku adoh banget, temuan "ora ana efek" bisa ora informatif tinimbang ngukum, lan tim kudu ngomong kanthi cetha tinimbang ngidini sepi diwaca minangka kegagalan.

**Sapa sing entuk bathi, sacara profesional utawa reputasi, yen evaluasi iki bali positif, lan apa kuwi ngowahi sepira pamriksa mandiri sing dibutuhake?** Iki dudu tuduhan ketidakjujuran; iki pangenalan yen wong sing ngrancang utawa nglakokake program luwih mungkin sacara struktural nafsirake asil ambigu kanthi loma, asring tanpa nyadari. Rembugen apa evaluasi dikomisikan, dianalisis, utawa ditinjau dening sapa wae sing mandiri saka tim panyedhiya layanan, lan yen ora, kepriye pemisahan sing sepadan kanggo program ukuran iki. Tujuane yaiku asil sing uga bakal dipercaya penyandang dana sing paling skeptis, ora mung sing nyaman dibela timmu dhewe.

**Yen temuan evaluasi iki kuwat, apa sing bakal kita tindakake kanthi beda, lan apa kita siap nindakake?** Evaluasi sing dikomisikan nanging ora tau dimaksudake ngowahi keputusan yaiku biaya mubazir sing dikalungi uji tuntas, lan pantes nyebut risiko kuwi sadurunge asil teka, ora sawise. Rembugen, ing advance, apa temuan positif sing kuwat bakal mbenerake (nggedhekake, lan sepira) lan apa temuan nol utawa negatif bakal micu (desain ulang, utawa pembatalan, lan ing garis wektu apa). Yen ora ana wong ing ruangan sing bisa njawab iki sadurunge ndeleng asil, evaluasi bisa nglayani fungsi legitimasi tinimbang fungsi keputusan, lan pantes jujur bab iku (waca Topik 2.1 — Kartu Skor Nilai Publik lan Kerangka Asil).

## Ing Praktik: Conto Nilai Publik

Ilustrasi fiktif. Kementerian Layanan Ketenagakerjaan ing negara ukuran sedheng sing ora dijenengi nglakokake pilot setaun layanan pelatihan intensif kanggo pencari kerja sing nganggur dangu, bebarengan karo layanan standar sing wis ana. Ing pungkasane pilot, laporan internal mbandhingake kelompok sing nampa pelatihan intensif karo kabeh wong liya sing metu saka pengangguran sajrone periode sing padha: kelompok sing dilatih nduweni tingkat panempatan kerja 38% sajrone enem sasi, dibandhingake 24% kanggo sisa beban kasus. Menteri-menteri dikandhani yen program "kasil" lan kasus bisnis diterusake kanggo diluncurake sacara nasional.

Sadurunge nyetujoni pendanaan, panitia keuangan ngajokake pitakon sing lugas: kepriye pencari kerja bisa mlebu ing kelompok sing dilatih ing wiwitan? Wangsulane dadi wigati banget. Petugas kasus wis ngrujuk pencari kerja sing dianggep "paling kemungkinan entuk manfaat" menyang pilot pelatihan, keputusan triase sing becik niyate sing, sakbenere, wis milih kelompok sing luwih siap kerja menyang perlakuan wiwit awal. Perbandingan 38% lawan 24% dicemari persis bias seleksi sing diperingatake topik iki: sanget mungkin kelompok sing dilatih bakal ngungguli sisa beban kasus sanajan tanpa pelatihan babar pisan.

Tinimbang nyetujoni utawa nolak peluncuran adhedhasar perbandingan kuwi, unit evaluasi kementerian ngusulake tahap kapindho nganggo undhian. Permintaan layanan pelatihan wis ngluwihi panggonan sing kasedhiya, mula unit ngalokasikan panggonan kanthi acak ing antarane pelamar sing padha layak lan mbandhingake tingkat panempatan kerja antarane pemenang undhian lan sing kalah, penerapan logika evaluasi acak tanpa kudu nahan layanan saka sapa wae sing ora bakal nampa. Rolas sasi sabanjure, perbandingan undhian nuduhake efek sing luwih cilik nanging nyata: peningkatan 9 poin persentase ing panempatan enem sasi, dudu jurang 14 poin sing diarahake perbandingan asli. Kementerian nggunakake perkiraan adhedhasar undhian, bebarengan karo data biayane dhewe, kanggo nggawe kasus efektivitas biaya sing bisa dibela (waca Topik 2.2 — Analisis Biaya-Manfaat Sosial lan Analisis Efektivitas Biaya) kanggo peluncuran sing diskalakake nanging dibatesi sumber daya, ora ekspansi sing luwih gedhe lan ora bisa dikirimake sing bakal dibenerake perbandingan awal sing cacat.

## Papat Sudut Pandang Sektor

### Pamarentah Lokal

Otoritas lokal biasane nglakokake akeh program cilik lan sedheng tinimbang sawetara program gedhe banget, sing ndadekake evaluasi acak sing dirancang khusus larang dibandhingake ukuran program lan nyurung evaluator lokal menyang metode kuasi-eksperimental sing nggunakake maneh data administratif sing wis dikumpulake — difference-in-differences ing wilayah layanan sing ngadopsi owah-owahan ing wektu beda, utawa desain diskontinuitas regresi ing sakubenge ambang kelayakan lokal. Bedane wates lan yurisdiksi sing bakal dadi gangguan ing papan liya asring dadi eksperimen alami paling apik kanggo evaluator lokal, amarga rong kelurahan utawa distrik jejer bisa beda ing kabijakan nalika tetep padha ing umume bab liyane.

### Pamarentah Nasional

Pamarentah nasional nduweni skala kanggo mbiayai evaluasi acak sing dirancang khusus lan set data administratif, asring disambungake ing antarane cathetan pajak, tunjangan, kesehatan, lan pendhidhikan, kanggo nglakokake desain kuasi-eksperimental sing bisa dipercaya kanthi biaya marginal endhek. Skala iki uga papan satuan tugas evaluasi "apa sing kasil" lan panuntun evaluasi sentral, kayata buku pedoman evaluasi standar departemen keuangan, condhong dumunung, amarga mung pamarentah nasional sing bisa mbenerake biaya tetep njaga infrastruktur evaluasi permanen lan standar metodologis bebarengan ing antarane akeh departemen.

### Sektor Sosial lan Nirlaba

Organisasi nirlaba lan organisasi non-pamarentah arang nduweni ukuran sampel utawa anggaran sing dibutuhake evaluasi acak sing dayane cukup, lan programe asring owah sacara adaptif nanggapi apa sing diamati staf garis ngarep, sing ngrumitake desain apa wae sing nganggep perlakuan sing stabil lan ditemtokake kanthi cetha. Kemitraan karo kelompok riset akademik utawa perantara evaluasi spesialis, saka jinis sing tuwuh ing sakubenge gerakan evaluasi acak ing pembangunan internasional, asring dadi siji-sijine dalan realistis menyang perkiraan kausal sing ketat, lan penyandang dana saya kerep nyuwun kemitraan eksternal kaya ngono sadurunge nggawe komitmen hibah pirang-pirang taun.

### Tingkat Multilateral lan Internasional

Lembaga multilateral mbiayai program ing akeh negara kanthi sistem data, kapasitas administratif, lan norma tinjauan etika sing beda, sing ndadekake metode kausal standar luwih angel ditrapake kanthi seragam nanging uga nggawe variasi lintas negara alami sing bisa dadi eksperimen alami nalika kabijakan diadopsi ing sawetara negara anggota sadurunge liyane. Evaluasi acak ing ekonomi pembangunan wis utamane berpengaruh ing skala iki, ngasilake bukti sing mbentuk kepriye pendanaan pembangunan internasional dialokasikan, nanging uga nggawa risiko kegagalan validitas eksternal sing wis didokumentasi: asil sing bener ing negara lan konteks sing diteliti ora otomatis pindhah menyang konteks beda, peringatan sing asring dilewati desain program multilateral.

## Cara-Cara Kegagalan sing Umum

**Sadurunge-lan-sawise sing lugu.** Program dinilai mung kanthi mbandhingake asil sadurunge diwiwiti karo asil sawise, tanpa kelompok pembanding babar pisan, saengga tren apa wae sing wis mlaku — pemulihan ekonomi, pergeseran demografi, owah-owahan kabijakan sing kapisah — salah diatribusekake marang program. Biayane yaiku crita kausal sing yakin sing dibangun ing desain sing sakbenere ora bisa mbedakake efek program saka kabeh liyane sing kedadeyan ing wektu sing padha.

**Bias seleksi sing dianggep efek program.** Peserta sing milih melu, utawa dirujuk amarga katon kemungkinan kasil, dibandhingake karo kabeh wong liya, ngasilake perkiraan dampak sing sejatine ukuran sapa sing ditarik program, dudu apa sing ditindakake marang dheweke. Biayane yaiku program sing diskalakake sing katon luwih ora efektif, kadhang luwih akeh, sawise tekan populasi sing kurang seleksi dhewe.

**Evaluasi kurang daya sing dilaporake minangka temuan nol.** Pilot cilik nemokake "ora ana efek signifikan sacara statistik" lan diwaca minangka bukti program ora makarya, nalika sampel sakbenere kekecilan kanggo ndeteksi efek ukuran sing bakal wigati. Biayane mlaku ing loro arah: program sing tenan efektif bisa dibatalake adhedhasar bukti sing ora tau bisa nuduhake dheweke kasil, utawa sumber daya pindhah kanggo mbiayai uji coba sing luwih gedhe sing ora perlu yen ringkesan asli diprodhuksi kanthi daya sing bener.

**Ngekstrapolasi perkiraan lokal ngluwihi konteks.** Desain diskontinuitas regresi kanthi bener ngira efek kanggo unit cedhak wates kelayakan, lan perkiraan variabel instrumental kanthi bener ngira efek kanggo unit sing status perlakuane sakbenere diowahi instrumen, nanging kekarone temuan banjur ditrapake marang kabeh populasi kaya-kaya perkiraan lumaku ing ngendi-ngendi. Biayane yaiku kabijakan sing diskalakake adhedhasar angka sing mung bener sacara lokal.

**Evaluasi minangka sandiwara.** Evaluasi dikomisikan kanggo nggawe tampilan pengambilan keputusan adhedhasar bukti, nanging keputusan wis dijupuk sacara efektif, lan ora ana temuan sing bisa dipercaya bakal ngowahi. Biayane yaiku anggaran evaluasi sing mubazir lan, sing luwih ngrusak, erosi alon-alon kapercayan marang evaluasi dhewe nalika staf nyadari yen asil ora tau ngowahi apa-apa.

## Dhaptar Pariksa

- [ ] Nyatakna kontrafaktual kanggo saben evaluasi program utama ing siji ukara basa sederhana.
- [ ] Pastekna kepriye peserta bisa mlebu ing kelompok perlakuan, lan netepna apa proses kuwi dhewe bisa nerangake bedane asil.
- [ ] Pilihen metode evaluasi (evaluasi acak, difference-in-differences, desain diskontinuitas regresi, variabel instrumental, utawa eksperimen alami) sing cocog karo aturan penugasan sing sejatine, sadurunge panyedhiyan layanan diwiwiti kapan wae bisa.
- [ ] Itungen daya statistik sing dibutuhake kanggo ndeteksi ukuran efek paling cilik sing bakal mbenerake biaya program.
- [ ] Daftarna ukuran asil lan rencana analisis sadurunge asil katon.
- [ ] Laporna kemampuan dibandhingake kelompok perlakuan lan pembanding bebarengan karo efek utama.
- [ ] Komisikna utawa tinjaunen evaluasi liwat fungsi sing mandiri saka tim panyedhiya layanan.
- [ ] Pisahna signifikansi statistik saka signifikansi fiskal lan praktis ing saben laporan marang pangambil keputusan.
- [ ] Anggarna evaluasi minangka bagean tetep saka biaya program ing tahap desain.
- [ ] Terbitna temuan nol lan negatif kanthi visibilitas sing padha karo sing positif.
- [ ] Priksanen apa perkiraan lokal positif (saka desain diskontinuitas regresi utawa variabel instrumental) diekstrapolasi ngluwihi populasi sing sejatine dicakup.
- [ ] Alurna evaluasi sing wis rampung menyang dhasar bukti sing luwih amba sing dijaga sektormu, ora mung arsipmu dhewe.

## Sumber Utama

Inti metodologis topik iki nggambar tradhisi ékonometrika terapan sing gegayutan karo Joshua D. Angrist lan Jörn-Steffen Pischke, lan kerangka asil potensial sing diformalisasikan Donald Rubin. Gerakan evaluasi acak ing kabijakan publik lan ekonomi pembangunan, sing gegayutan karo Abdul Latif Jameel Poverty Action Lab (J-PAL) lan jaringan akademike, nyuplai akeh praktik terapan sing dirujuk ing sudut pandang sektor. Standar evaluasi pamarentah nggambar panuntun Magenta Book saka Perbendaharaan Britania Raya, lan praktik sintesis bukti nggambar standar Campbell Collaboration kanggo tinjauan sistematis ing kabijakan sosial (waca Topik 2.6 — Sintesis Bukti lan Apa sing Kasil).
