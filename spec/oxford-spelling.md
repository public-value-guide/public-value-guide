# Oxford spelling contract

Applies to the canonical locale, `en-gb-oxendict`. The other English locales adapt from it: `en-gb` uses the same vocabulary but `-ise` endings; `en-us` and `en-001` follow their own conventions per `spec/index.md` §4a.

- **-ize, not -ise**, for the Oxford-preferred verb ending: organize, recognize, prioritize, standardize. Exception: verbs that are always `-ise` regardless of dictionary (advertise, comprise, compromise, devise, exercise, improvise, revise, supervise, surprise) — these never take `-ize` because they are not `-ize/-ise` pairs at all.
- **-yze is American; Oxford British uses -yse is wrong for this convention** — Oxford spelling keeps `-yse` for analyse, paralyse (unlike `-ize` verbs, `-yse` verbs are not part of the `-ize` pattern).
- **-our, not -or**: behaviour, favour, labour, neighbour, rigour.
- **-re, not -er**: centre, metre, theatre.
- **-ogue, not -og** (where a variant exists): dialogue, catalogue.
- **Double consonant before a suffix** (British pattern): travelling, modelling, labelled.
- **programme** for a plan of action or policy initiative; **program** only for software.
- **judgement** with the middle *e*, except **judgment** in a strict legal-ruling sense if quoting a court.
- Dates as **day month year** (22 September 2026), never month/day/year.
- Currency: symbol before the amount, ISO code or country named on first use in a topic if ambiguous (£45,000; US$45,000).
- Quotation marks: single quotes primary, double quotes for a quotation within a quotation.
- Oxford (serial) comma used throughout.

When in doubt, prefer the spelling in the *Oxford English Dictionary* over the New Oxford American, Merriam-Webster, or Collins.
